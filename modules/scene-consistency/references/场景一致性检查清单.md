# 场景一致性检查清单（scene-consistency 第 3/4 步工具）

> 用途：交付前的三份可验证产物制作规范 + 独立空间审核问题清单。
> 纪律：禁止出现任何具体项目数据，示例用占位符。

## 一、产物① 原文-场景对照表（模板）

| 镜号 | scene（资产名） | 场景类型 | 依据 | 依据类型 |
|---|---|---|---|---|
| 001 | 场景X | 内景 | 「…入目是斑驳的墙、屋顶挂着干鱼…」 | 原文（第1段） |
| 002 | 场景Y | 外景 | 角色B从里屋追出 → 揪耳冲突 | 推断（图注A） |
| 003 | 场景X | 内景 | 同上场（无换景） | 连续 |

- 依据类型：`原文（出处）` / `推断（图注编号）` / `连续（与上镜同场景）`。
- **整表不允许出现"无依据"**——无依据的镜 = 未过闸门，退回第 1 步。

## 二、产物② 场景连续性折线图（做法）

把全片镜序 × 场景画成折线（可用文本字符画或表格），目的：**跳变可视化，肉眼扫合理性**。

```
镜序: 001 002 003 004 005 006 007 008 009 010 ...
场景X(内) ████▒▒▒▒▒▒████████████▒▒▒▒▒▒▒▒████
场景Y(外) ▒▒▒▒████▒▒▒▒▒▒▒▒▒▒▒▒████▒▒▒▒▒▒
         └──①──┘└──────②──────┘└──③─┘
```

- ① 首次换景（X→Y）：有没有转场依据？
- ② 长时间停驻：内容是否真的发生在该场景（对照原文）？
- ③ 反复横跳 X→Y→X：是否有叙事理由？没有 = 换景滥用。

**必问**：每一处"锯齿跳变"，在原文-场景对照表里必须有对应依据；没有 → 报警。

## 三、产物③ 矛盾扫描（check-scenes.py）

跑 `scripts/check-scenes.py`（见脚本头注释的用法），输出三类问题：

1. **矛盾词**：画面文本（visual/action/dialogue/narrative）含内景信号词但 scene 是外景（或反之）。
2. **资产缺失**：scene 不在场景资产清单中。
3. **换景无据**：相邻镜 scene 变化但 narrative 无转场词。

**边界（诚实声明）**：脚本只抓"内部矛盾"（画面词 vs scene / 资产存在性 / 换景无据），**抓不到"与原文事实不符"**——那是语义判断，靠产物①对照表 + 第 4 步人工审核。脚本是兜底，不是裁判。

## 四、第 4 步 独立空间审核问题清单（只审空间，不看剧情）

对**每一镜**依次回答：

1. **可拍性反问**：画面里的人物动作/台词/道具，在标的场景里**物理上拍得出来吗**？（躺床上睁眼 → 场景必须是卧房；在院里煮食 → 场景必须有灶/火塘）
2. **换景反问**：换到另一个场景是否更合理？如果"换到场景Z更合理"成立 → 说明原 scene 选错了。
3. **位置姿态**：人物此刻站/坐/躺/走动、屋内/院中/门槛/窗边，visual/action 写清了吗？
4. **相邻连续性**：与上一镜的位置/姿态是否漂移？（上一镜在床边，这一镜在院中 → 必须有移动转场）
5. **时间线**：同一场戏时间（日/夜）是否跳变？跳变有转场依据吗？

**全片级**：

6. 折线图上每一处场景跳变，对照表里都有依据？
7. 本集场景资产是否齐全？缺的是否已补建或已显式上报？

## 五、内景/外景信号词参考（check-scenes.py 词表来源）

| 内景信号词（scene 应为内景） | 外景信号词（scene 应为外景） |
|---|---|
| 屋顶 / 房梁 / 墙内 / 窗 / 床 / 炕 / 灶 / 火塘 / 堂屋 / 卧房 / 里屋 / 屋内 / 厅 / 帘 / 门槛内 | 院子 / 院中 / 门外 / 石阶 / 墙头 / 晒架 / 空地 / 露天 / 海风 / 巷道 / 街 / 码头 / 田 |

> **特判（合法例外，不报警）**：`屋外 / 窗外 / 门外 / 墙外` = "从内景看外部"，scene 为内景时合法（如"望向屋外大海"是内景镜）。
> 词表可按剧本语境增补，增补词需同步进 check-scenes.py。

## 六、场景资产图一致性检查（★ 2026-08-31 新增 · scene-consistency 第 6 步）

> 拓扑图定了空间真相后，**场景资产图必须与它对齐**——"通用空镜"不能替代"剧本特定场景"。

**逐场景核对清单**（每个本集用到的场景资产图）：

| 检查项 | 判定 |
|---|---|
| 朝向要素（院门/屋门朝哪、窗朝哪、海/街在哪侧）是否在图中体现 | 缺失=重生成 |
| 剧本原文明确的关键道具（<按原文逐项列出>）是否入图 | 缺失=重生成 |
| 空间结构（院子围墙 vs 栅栏、屋与院相对位置）是否与拓扑图一致 | 不符=重生成 |

**处理流程**：发现缺失/不符 → 按剧本特定信息重写该场景资产 prompt（融入拓扑图锚点+原文道具）→ 重生成 → 核对通过前不用旧图做首帧/视频。

**★ 实例教训（抽象化，2026-08-31）**：某场景旧资产图为通用空镜（generic stove / a few pots / generic fence），与拓扑图多处对不上——关键地标缺失、灶台位置形态不符、标志性道具缺失、朝向特征缺失、围合方式不符。已重写为拓扑图对齐版 prompt（按拓扑图锚点逐项写入）。


## 七、引用行完整性检查（★ 2026-09-01 新增，check-scenes.py D 类自动执行）

- 适用：分镜数据带 `video_prompt` 字段时（听风等数据死存型），check-scenes.py 自动校验每段提示词首行引用行。
- 三条规则：
  1. 首行含「空间拓扑图」引用（空间锚不缺席）；
  2. **空间拓扑图在最后一位**（引用顺序铁律：角色 → 场景 → 道具 → 空间拓扑图）；
  3. 首行含本段场景图引用（单条提示词自包含场景锚，连续同场景段逐段带，不省略）。
- 报警格式：`[D引用行] 镜X ...`；处理：补引用 / 调顺序 / 修正场景归属，问题清零后报告通过。
- 反面教材：创作时手写引用资产行漏了连续同场景段的场景引用（某集连续 8 段缺场景）→ 已由 D 类检查兜住。
