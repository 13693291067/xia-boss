# 写作标准：场景 / 画面 / 动作 / 台词 / 冲突 / 爆点 / 人物逻辑 / 剧情丰富度

## 一、场景数量与空间要求

每集90秒，原则上控制在1至2个主要场景。

允许：
- 一个主要场景完成整集
- 两个场景形成前后升级
- 同一空间内改变人物位置和关系
- 通过门内门外、走廊与房间形成连续调度

禁止：
- 为了丰富画面频繁切换地点
- 90秒内出现大量无关场景
- 场景切换后重新解释人物关系
- 每个情绪点都换一个场地
- 用回忆镜头代替当前冲突

场景变化必须有明确作用：转移主动权 / 进入更私密或更公开的空间 / 增加羞辱感 / 暴露证据 / 切断退路 / 迫使人物作出选择。

场景2不能重新平静开始，必须承接场景1的情绪惯性。例如：场景1结束时主角被赶走，场景2开始时主角已经堵住关键人物；场景1证据被夺走，场景2直接进入抢救或追索；场景1关系破裂，场景2立即呈现破裂后的现实后果。禁止场景切换后情绪归零。

## 二、画面细化要求

不能只写"他们发生争吵""主角很生气""反派很震惊""现场气氛紧张"——必须写成可以直接拍摄的行为。

正确示例：
- △ 她伸手去拿桌上的协议，对方先一步用两根手指压住纸角。
- △ 他听完没有反驳，只把手机屏幕朝下扣在桌面上。
- △ 母亲避开她的视线，反复整理已经摆齐的筷子。
- △ 男人还在笑，手却悄悄把门反锁。
- △ 她把已经签好的名字划掉，笔尖划破了纸。
- △ 空调出风口发出轻微的嗡鸣，屋里没有一个人替她说话。

画面描写必须包含：人物位置 / 手部动作 / 目光变化 / 停顿 / 呼吸变化 / 道具使用 / 人物之间的距离变化 / 环境对情绪的衬托 / 对他人台词的即时反应。

## 三、动作与微表情要求

每个主要人物在每场中都必须有主动行为和即时反应，人物不能站着轮流说台词。

优先使用：手指停顿 / 递出又收回 / 眼神避开 / 呼吸压住 / 称呼改变 / 肩膀绷紧 / 咬住后半句话 / 把物品放回原处 / 替某人挡住视线 / 下意识护住伤口 / 表面整理东西实际拖延时间 / 说话前确认门是否关紧 / 听见某个名字后动作停住 / 试图维持体面却暴露真实情绪。

禁止高频使用：瞳孔地震 / 浑身颤抖 / 不敢置信地后退 / 嘶吼 / 崩溃大哭 / 邪魅一笑 / 嘴角勾起 / 眼神冰冷 / 气场全开 / 霸气侧漏。

这些表达只有在极少数真正适合的场面中才能使用。

## 四、台词要求

台词必须：短 / 准 / 有身份感 / 有关系感 / 有潜台词 / 能推动动作 / 能改变现场情绪 / 符合当下处境。

优先使用：半句话 / 被打断的话 / 答非所问 / 表面客气实际施压 / 用生活细节刺痛对方 / 重复对方某个词进行反击 / 改变称呼表现关系变化 / 用极轻的语气说最重的话 / 不直接表达情绪，让动作暴露情绪。

改写示例：

| 不要写 | 改为 |
|--------|------|
| "你们没有良心，我一定会揭露你们。" | "床明明空着。""你再说一遍，谁不能救？" |
| "我不会放过你。" | "这份字，你最好别签。""签了呢？""那就别叫我姐了。" |
| "你背叛了我，我很失望。" | "刚才他们问你的时候，你低头了。" |
| "你以为你赢了吗？" | "你是不是忘了，监控有声音？" |

禁止出现：
- "你终将付出代价。"
- "这就是你背叛我的下场。"
- "我不会再任人宰割。"
- "我要让所有人知道真相。"
- "正义也许会迟到，但不会缺席。"
- "你根本不知道我经历了什么。"
- "从今天开始，我要夺回属于我的一切。"
- "游戏才刚刚开始。"
- "真正的好戏还在后面。"
- "这一次，我不会再退缩。"
- "命运掌握在自己手中。"

## 五、冲突设计要求

冲突不能只靠语言对骂。每场冲突必须至少包含两种力量：人物对人物 / 人物对规则 / 人物对身份 / 人物对利益 / 人物对亲情 / 人物对承诺 / 人物对现实困境 / 人物对自己的秘密 / 人物对选择代价。

冲突升级时，必须改变现场状态。例如：门被锁上 / 手机被夺走 / 证据被撕毁 / 亲人被带走 / 围观者开始录像 / 某人改变站位 / 某人不再称呼主角原来的身份 / 保安或工作人员开始执行命令 / 主角失去合法申辩资格 / 关键人物拒绝作证 / 某项决定已经进入不可撤销状态。

## 六、短剧爆点要求

每集至少自然包含3项：当众羞辱 / 身份压迫 / 规则不公 / 亲情撕裂 / 爱情背叛 / 关键证据 / 反派设局 / 主角反击 / 信息反转 / 现实困境 / 情绪爆发 / 物证打脸 / 选择代价 / 关系破裂 / 强视觉场面 / 强冲突对峙 / 希望出现后再次破灭。

爆点必须服务主线和人物。禁止为了爆点临时制造：无铺垫出轨 / 无铺垫怀孕 / 无铺垫血缘反转 / 无铺垫绝症 / 无铺垫车祸 / 无铺垫失忆 / 无铺垫死亡 / 无铺垫豪门身份 / 无铺垫神秘大人物救场。

## 七、人物逻辑要求

所有人物的行为都必须有动机：主角做选择要有理由；反派出手要有利益；配角沉默要有压力；亲人站队要有现实顾虑；人物情绪改变要有具体触发点。

禁止：
1. 为推进剧情强行误会
2. 为制造爽点让反派变蠢
3. 为反转临时修改设定
4. 为煽情让人物说不符合身份的话
5. 为结尾悬念硬塞新人物
6. 主角明明有证据却故意不说
7. 反派明明可以处理却当众自曝
8. 配角无缘无故突然倒戈
9. 人物因为一句话立刻彻底原谅
10. 人物刚受重大伤害，下一秒恢复正常

## 八、剧情丰富度要求

允许增加：
- 原大纲范围内的合理阻碍
- 人物之间更具体的对峙
- 关键物证
- 小型信息差
- 场景中的压迫细节
- 人物选择的现实代价
- 配角态度的渐进变化
- 反派合理的反制手段
- 已有关系中的旧伤
- 能强化核心情绪的生活细节

禁止增加：
- 与主线无关的支线
- 无意义闲聊
- 重复解释
- 强行煽情的哭戏
- 大段回忆
- 过度旁白
- 空喊口号
- 机械式爽文打脸
- 没有后果的小反转
- 只为拖时长存在的角色

## 九、输出长度要求

**核心：90 秒 = 一个情绪循环单元，不是每集固定时长。** 一集由 1~N 个 90 秒循环拼成，循环数由本集剧情量决定（关键事件估算时长 ÷ 90 向上取整）；循环与循环之间用更高一级的冲突硬接，禁止软着陆。

每个 90 秒循环默认：按每 10 秒情绪节拍展开 / 前 3 秒直接爆发强冲突 / 中段至少一次希望与反压 / 后段必须出现有代价的选择 / 循环结尾达到该循环最高情绪点 / 台词精炼 / 动作和画面细节充足 / 不通过增加废话填满时长。

**可拍性红线**（按段落时长换算）：

| 段落时长 | 实拍镜头数 | AI 生视频镜头数 | VFX 长镜 |
|----------|-----------|----------------|----------|
| 7—10 秒 | 4~8 镜 | 2~4 镜 | 最多 1 个，2~3 秒 |
| 13—15 秒 | 6~12 镜 | 3~6 镜 | 1~2 个，3~4 秒完整展示 |

每段台词不超过 2 短句；VFX 大场面单镜需完整展示时间，不可用快剪稀释；逐段复核，超载段落砍掉最后一个可有可无的动作、或把该段换到更宽的颗粒度档位（10 秒档 → 混合颗粒度中段 15 秒）。

用户另行指定单循环时长时重新规划情绪节拍：60 秒循环每 8—10 秒一次情绪变化；90 秒循环每 10 秒一次；120 秒循环每 10—15 秒一次。无论时长多少，开场 3 秒强冲突规则不变。
