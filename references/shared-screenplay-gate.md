# 剧本五阶门控 · 可执行规格（横切单源）

> 适用：xia-boss 一切**创作/改写剧本**的环节——小说入口写第一章（§0.6 步骤⑥）、小说改编分集剧本、剧本修订。
> 性质：通用方法论，禁止出现任何具体项目数据；示例一律占位符。
> 来源：从《工业级五阶门控剧本引擎》蒸馏（漫剧老李 V6.5 规范体系，已通用化改写，2026-09-04 采纳）。
> 上下游：虾料（摄入/世界观/生产事实）管"已有设定梳理"，本规范管"动笔创作时的结构门禁"；Gate 4 与虾料 docs 设定互查。

## 〇 核心原则

**剧本即唯一真理源**——所有角色、场景、道具资产从剧本文本双向绑定派生；动笔写正文前必须依次通过五道门禁，**严禁跳过结构直接写大段台词**。

## 一、五阶门控（顺序锁死，每道门产出可核对的交付物）

### Gate 1 · Premise（核心前提与黄金 3 秒钩子）
- **30 字前提公式**：`[主角] + [核心欲望] + [不可抗力阻碍] + [失败的致命代价]`——四要素缺一不可，超 30 字说明前提没想清；
- **黄金 3 秒钩子**（必须明确选定其一）：
  1. 极端悬念钩——直接把刀尖对准主角咽喉，生死悬于一瞬；
  2. 认知反差钩——看似最弱的身份（杂役/赘婿/小贩），展现出颠覆常理的实力特权；
  3. 情绪爆发钩——至亲受辱/婚约撕毁/绝境背叛，怒气值瞬间拉满；
  4. 视觉奇观钩——天雷裂空/法相降临/超维异象爆发。

### Gate 2 · Structure（宏观三幕比例与分集卡点）
- **单集三幕时间比例**（以单集总时长为基）：铺垫建立 ≈30% → 核心冲突危机 ≈50% → 转折爆发与卡点 ≈20%；
- **结尾卡点钩子（Cliffhanger）**：必须停留在决策关头、身份暴露瞬间、援兵突现或攻击命中的**前一帧**——与听风线"退场钩子"同源，卡点帧即退场钩子的画面化。

### Gate 3 · Beat Sheet（场景因果节拍表）
- **场次存在性法则**：一场戏删掉后不影响后续剧情 → 立即删除（与时长控制"砍三无镜"同构，砍在剧本层更便宜）；
- **每场戏必须包含完整因果链**：`场景目标 → 遭遇阻碍 → 升级行动 → 意外转折 → 产生不可逆新局面`——五环缺一即该场未完成。

### Gate 4 · Worldview & Entity Bounds（世界观与实体边界约束）
- **时代法则**：明确时代背景（古代/民国/现代/赛博未来），锁定法律、战力天花板与技术极限——与虾格"题材时代感校验"（§1.2）同一口径；
- **人际关系网络**：明确上下级、仇恨、盟友关系，杜绝无动机叛变——与虾料生产事实"主要人物关系"互查（虾料梳理的设定是本门的输入，不是并列重复劳动）。

### Gate 5 · Professional Script Page（语义化工业标准排版）
```text
[场景序号] [内景/外景] · [具体地点] - [日景/夜景]
出场人物：@角色A、@角色B
环境氛围：[空间构图、天气、主导光源与声音质感]

[动作描述]（反形容词法则：只写摄像机能拍到的物理动作与空间位移）

@角色A（微动作指示：咬紧后槽牙，指节因用力而泛白）
"（台词内容，遵循冰山法则与潜台词）"

@角色B（冷笑，眼神下瞥避开对视）
"（台词内容）"
```
- 排版产出的场景头信息直接喂虾料 scene_blocks（内景外景/地点/时段），角色清单直接喂虾塘——**一份排版两处消费**。

## 二、去 AI 机械感三大法则（写正文全程生效）

1. **角色压力与筹码追踪**：对话不是客气的问答，而是权力、信息与立场的隐秘博弈——每句对话必须有一方施压、另一方掩饰/反击，杜绝毫无立场的解释性闲聊；
2. **承重场景识别**：区分"承重戏"（生死抉择/秘密揭穿/高手死斗——投入最高视听与微表情密度）与"过场戏"（果断视听省略，一镜带过）——与时长控制"组间非均匀分配"（燃点给满/过渡给 10s）同源；
3. **冰山对白（反灌输）**：严禁角色向已知情同伴解释世界观设定（"你明知道这功法是天下第一……"）；双方已知信息一律转入潜台词、眼神与道具动作。

## 三、输入 → 输出契约

**输入**：故事想法/小说原文/既有剧本（改写）。
**输出**（缺一即未过门）：

| # | 交付物 | 验收 |
|---|---|---|
| 1 | 前提卡 | 30 字公式四要素齐 + 钩子类型明确选定其一 |
| 2 | 结构卡 | 单集三幕比例落位 + 每集结尾卡点钩子写明停在哪一帧 |
| 3 | 节拍表 | 每场戏五环因果链完整；删场测试通过（无"删了不影响"的场） |
| 4 | 边界卡 | 时代/战力天花板/技术极限声明 + 人物关系图（与虾料 docs 一致） |
| 5 | 剧本页 | Gate 5 排版模板逐项合规；动作描述无反形容词 |

**验收 checklist**：□四要素前提 ≤30 字 □钩子类型已选定 □三幕比例落位 □每集卡点帧写明 □删场测试通过 □每场五环因果链 □时代边界与虾料 docs 一致 □无角色向知情者解释设定 □动作描述可拍摄。
