# 空间真理图模板（scene-consistency 第 1 步产物）

> 用途：分镜规划阶段产出的《本集空间真理图》（文字版布局权威源）——**一集一张**，是**本集场景归属的唯一权威源**。所有分镜的 scene 从这张图取，不再逐镜独立猜。（★ 2026-09-04 分工注：机位调度拓扑图——站位/轴线/CAM/越轴——是另一层，**每场一张**，规范单源 = `../../../references/shared-spatial-blocking.md`；两图分工见 §0.5。）
> 纪律：禁止出现任何具体项目数据，示例用占位符（角色A / 角色B / 场景X / 场景Y）。

## 0. 空间拓扑图怎么生成（★ 四步法，2026-08-31 固化）

> 图不是凭空画的，是从原文证据一步步推出来的。四步缺一不可。
> **★ 2026-08-31 输入源补充（用户拍板）**：画拓扑图前，先看**对应场景资产图**（外观/结构/道具——锚点要与场景图一致），再看**分镜内容**（哪些镜头用什么空间——移动路径/分区要覆盖拍摄需求）。三者互参：小说 → 场景图；小说+场景图+分镜 → 拓扑图。

**第 1 步：圈定空间范围（只靠原文证据）**
- 通读本集原文，逐条标出空间线索（行号+原句）→ 指向哪个空间（屋内/院子/门口/窗边…）。
- 规则：原文有空间词 → 引用原句；原文沉默 → 标「推断」+ 依据（动作语义/相邻锚点）。

**第 1.5 步：对照场景资产图与分镜（★ 2026-08-31 新增）**
- 打开本集用到的每个场景资产图，核对：锚点（灶台/鱼筐/门/窗/晒架）在场景图里的位置与形态 → 拓扑图对应标注与之一致。
- 打开分镜草稿/11 字段，列出哪些镜头用哪个空间（移动路径/站位需求）→ 拓扑图的路径箭头与分区覆盖这些使用。
- 三者不一致 → 停下修正（场景图按小说重生成 / 拓扑图改锚点），不许带错继续。

**第 2 步：提取锚点物**
- 列出本集出现在原文的关键空间物：床/窗/门/门槛/灶台/桌/缸/晒架/鱼筐…（谁在哪里出现，标出处）。

**第 3 步：确定拓扑关系（谁和谁怎么连）**
- **空间链**：卧房→堂屋→屋门→门槛→院子（按人物移动路径推出）。
- **视线关系**：窗朝哪看（决定"看海/看街"是内景镜还是外景镜）。
- **关键物位置**：灶台在院（露天）还是屋（灶房）？鱼筐在哪个角落？——由原文动作地点判定。
- **人物初始位**：本集开始时各角色在哪（床上/堂屋/院中…）。

**第 3.5 步：确定四面朝向（★ 2026-08-31 补充，必做）**
- 画前先定**四面方位**（建议：上=北/内陆、下=南/海、左=西、右=东 或按实际调整），整张图按统一朝向画。
- **每面墙开什么**逐一定：朝海面=开窗/开门（透出）；朝山面=实墙；朝院面=开门通院子。**窗/门必须挂对房间**（卧房的窗不能开到堂屋墙上）。
- 关键视线/通路用箭头标方向（窗→外部景观、屋门→院、院门→远处地标），让生图模型明确"谁朝哪开"。
- 缺失朝向 = 模型自由发挥，窗乱开、门乱装（★ 某集实例教训）。

**第 4 步：画成图（固定绘制规范）**
1. 每个场景 = 一个方框（区域边界，标内外景）。
2. 框内列锚点物（带位置词：左/右/墙角/床边/窗边）。
3. 方框之间用通路标注连接（门/门槛），移动路径沿通路。
4. 视线用箭头（窗 → 外部）。
5. 每个锚点标注来源（原文行号 或 推断依据）。
6. 真理图**一集一张**（布局层），随检查点 A 交用户确认后才生效；机位调度拓扑图按**每场一张**另出（分工见 §0.5）。

**自检**：图里每个锚点都能答出「原文行号 or 推断依据」；画完先自查"哪条移动路径在原文有依据"，没有的路径就是隐患。

## 0.5 空间拓扑图生图提示词（★ 2026-09-04 升级：黑白简笔机位调度图，规范单源）

> **★ 2026-09-04 用户裁决（替代旧彩色分区版）**：对外生图/垫图一律使用**黑白简笔机位调度图**规范，旧"浅暖纸色矢量线稿 + 柔和色块 + 中文标签"彩色版式**废止不再产出**。本模板的文字版（§0 四步法 + §二 ASCII 图 + §三~五各表）保留不变，仍是**布局层权威源**（原文证据链/四面朝向/锚点物出处）。
>
> **两图分工**：空间真理图（文字版，人看）回答"在哪里"——场景归属/门窗朝向/换景路径；**机位调度拓扑图**（黑白简笔，垫图投喂模型）回答"怎么拍"——站位/朝向/轴线/机位/越轴。拓扑图的锚点带必须与本图锚点一致。

**生图提示词规范单源**：`../../../references/shared-spatial-blocking.md` §十——每场一条（每场一张铁律），固定版式：

```text
16:9 横屏白底简笔示意图，手绘风格平面俯视机位调度图：以细黑线俯视平面绘制
[固定锚点带：本场不动参照物（方块示意，与空间真理图锚点一致）]；
[站位：左侧圆点+特征小图标=主角方，右侧圆点+标识=对手方]；
两点间一条红色虚线直线 = 180° 动作轴线；
轴线同侧布置四个小相机图标 CAM1~CAM4，细弧线示意调度弧；
[下方纵深边界：远景要素点线]。
仅黑白灰 + 一处红色轴线虚线，线条干净简洁，无写实渲染、无人物、无照片质感
（blueprint sketch style），no photorealism, no text labels other than CAM1-CAM4 numbers。
```

三条硬规则（详见单源 §十）：①文字仅允许 CAM1~CAM4 与"主轴"二字；②必须含 `blueprint sketch style` + `no photorealism`；③站位图标带可区分特征。

**配套四表（同场产出）**：空间坐标描述 / 站位表 / 机位部署表 / 轴线与越轴预案表——格式与验收见单源 §九；虾镜线的四表落在本图交付文档，听风线落在 Stage 1 表 2/表 3。

> 历史注：旧彩色版的两轮修正教训（四面朝向缺失 → 窗画错分区；"无乱码文字"杀伤力过大 → 模型不画标签）已内化为通用经验：**布局约束必须在提示词里显式正向声明，禁止只靠 FORBIDDEN 负向兜底**——该经验同样适用于黑白版。

## 1. 产出时机与确认

- **产出**：checkpoint A / 规划阶段（拆镜前）。
- **确认**：随检查点 A 一并给用户确认；用户确认后生效，未确认不得进入拆镜。
- **存放**：项目 outputs 目录（如 `outputs/<episode>/space-map.md`），随分镜交付物存档。

## 2. 模板骨架

```
# <集名> 空间真理图

## 一、原文空间证据清单（逐段提取，行号+原句）

| # | 原文空间描写（原句） | 出处（章节/段落） | 指向场景 |
|---|---|---|---|
| 1 | 「…睁眼入目是斑驳的墙、**屋顶**挂着干鱼…」 | 第1段 | 场景X（卧房/内景） |
| 2 | 「…看向**屋外**那片海…」 | 第N段 | 场景X（窗边·内景看外） |
| 3 | （原文沉默，推断） | 第M段 推断依据：角色从里屋追出 | 场景Y（堂屋） |

> 规则：有原文词 → 引用原句；原文沉默 → 标「推断」+ 一句依据（动作语义/相邻镜锚点）。

## 二、空间拓扑图（ASCII 俯视示意）

```
场景X（屋·内景）
┌──────────────────────────────┐
│  堂屋区(逼问/冲突发生地)      │
│     灶台/火塘 ── 窗 ──→(看向场景Z·海) │
│  卧房区(床=角色A苏醒处)        │
│                          ┌门┐ │
└──────────────────────────┴─┬─┘
                             │ 门槛
  场景Y（院·外景）
     石阶 · 晒架 · 角落杂物(煮食区)
```

- 画清：各场景相对位置、门/窗/床/灶等关键锚点、角色初始位置。
- 一个镜头对应图上哪个机位，一目了然。

## 三、角色初始位置表

| 角色 | 初始位置 | 依据 |
|---|---|---|
| 角色A | 卧房·床上（苏醒） | 原文第1段 |
| 角色B | 堂屋→追入卧房（揪耳） | 推断：从里屋追出 |
| 群像 | 院墙外探头 | 原文第N段 |

## 四、场景资产比对与补建清单

| 本集所需场景 | 资产库是否存在 | 结论 |
|---|---|---|
| 场景X（屋·内景） | 存在（资产N） | 可用 |
| 场景Y（院·外景） | 存在（资产M） | 可用 |
| 场景W（卧房·内景） | **不存在** | ⚠️ **待补建**（append 尾部，不动旧图号） |

- 补建清单随检查点 A 给用户确认；确认后回 xiatang 补资产，资产就位后回填 scene 图号。
- 补建受阻 → 显式上报"本集空间不完整"，禁止静默硬压到近似场景。

## 五、换景清单（本集所有场景切换点 + 叙事依据）

| 镜段 | 场景切换 | 转场依据（narrative 要写明） |
|---|---|---|
| 镜N→镜N+1 | 场景X → 场景Y | 角色A起身推开屋门，迈过门槛走到院中 |
| 镜K→镜K+1 | 场景Y → 场景X | 角色B追着角色A退回屋内 |

> 每处换景必须能在图上找到"移动路径"，并在分镜 narrative 写清。
