# 影片基调方向池（三步向导·第三步推荐源）

> 用途：虾格三步向导「③ 影片基调」的推荐来源。用户完成风格类型 + 视觉参考两步后，基于前两步 + 核心矛盾与情绪曲线推荐 3-5 种基调。
> 性质：**通用方法论**（纯方向知识，零项目数据）。本池为推荐池，用户可自定义；选定结果写入项目 `meta.tonal_direction`，不写回本文件。

## 使用规则（强制）

1. 推荐 **3-5 种**基调，基于**核心矛盾 + 情绪曲线 + 已定风格/参考**给出推荐排序（推荐项排第一）。
2. 每种 = 名称 + 一句说明；方案之间必须差异明显。
3. 基调选定后写入项目（handoff-xiage.md 的 `tonal_direction`），并指导虾镜镜头语言（运镜/光影/节奏倾向见下）。
4. 基调是"表演与叙事调性"，与视觉风格解耦：同一风格可配不同基调（如国漫幻想 × 轻喜反差 / 国漫幻想 × 热血燃向）。

## 基调池（6 种通用方向，可扩展）

### ① 轻喜反差喜剧
- **说明**：以错位、反差为笑点引擎，节奏明快，表演松弛，重视"反应镜头"的荒诞感。
- **适用题材**：沙雕文、穿书炮灰、搞笑日常、反套路设定。
- **镜头语言倾向**：固定机位 + 快速正反打、轻微手持呼吸感、夸张定格反应、明快剪辑节奏；亮度整体偏通透，避免大面积死黑。

### ② 正剧史诗
- **说明**：宏大叙事、庄重调度、留白克制，用空间与沉默建立分量。
- **适用题材**：权谋、战争、历史、宏大世界观、家国叙事。
- **镜头语言倾向**：大远景建立、缓慢推拉镜、对称构图、长镜头；低饱和庄重色、高反差但层次分明。

### ③ 暗黑悬疑
- **说明**：压抑氛围、冷调光影、信息逐步释放，观众保持不安与猜疑。
- **适用题材**：悬疑、惊悚、阴谋、黑化成长。
- **镜头语言倾向**：低光高反差、手持不安微晃、前景遮挡构图、冷蓝/墨绿调；慢节奏留白 + 突发硬切。

### ④ 热血燃向
- **说明**：高能战斗、激昂节奏、逆袭爽感，情绪曲线持续上扬。
- **适用题材**：升级流、战斗、逆袭打脸、竞技。
- **镜头语言倾向**：快切、动态运镜（跟拍/甩镜）、能量色高饱和（红/金）、慢动作点缀大招；BGM 强节拍。

### ⑤ 温情治愈
- **说明**：暖调、慢节奏、生活流，靠细节与日常积累情感。
- **适用题材**：种田、日常、治愈、家庭、师生。
- **镜头语言倾向**：柔光、慢镜头、暖色调（琥珀/奶白）、浅景深近景多、生活道具特写；节奏舒缓。

### ⑥ 荒诞讽刺
- **说明**：黑色幽默、夸张反差、戏剧化表演，用荒诞解构严肃命题。
- **适用题材**：讽刺喜剧、荒诞设定、黑色幽默、群像闹剧。
- **镜头语言倾向**：广角畸变、非对称构图、高反差硬光、跳切；表演夸张化、反应镜头极致化。

## 与情绪曲线的联动（★ 第三步入虾镜的依据）

基调选定后，情绪曲线（平缓/升温/高潮/回落）与基调共同决定景别与运镜力度：

| 情绪段 | 基调倾向 | 景别/运镜倾向 |
|---|---|---|
| 平缓 | 建立空间 | 远景/全景，缓慢推拉，固定 |
| 升温 | 推进互动 | 中景，跟拍/横移，节奏加快 |
| 高潮 | 情绪爆发 | 近景/特写，手持晃动/快切，能量色加强 |
| 回落 | 消化余韵 | 中景/远景，缓慢拉镜，留白淡出 |

## 扩展规则

- 用户指定新基调 → 按同格式（名称 + 一句说明 + 镜头语言倾向）加入推荐列表，经确认后随 handoff 写入项目；**不固化回本文件**（保持通用性）。
- 基调池可扩展，但必须保持"通用方向"性质，禁止写入任何项目私有设定。
