# 影片基调吸收（横切纪律 · 单一规范源）

> ★ 2026-09-02 用户拍板设立；★ 2026-09-03 P0-2 单源化——虾镜与听风两线**共用本文件**，禁止在各自 SKILL.md 里复制本规范正文（防双写漂移）；各线只保留自己的差异点（见 §7 对照表）。

## 1. 设计总纲

基调（tonal_direction）是「**导演表演指令**」：管节奏快慢/情绪松紧/镜头力度，不管画面长什么样（那是风格三要素）。基调**不作为独立段外挂**进视频提示词，而是先变成节拍/分镜文本的具体描述，随各线的保真机制自然流入提示词。

## 2. 输入契约（开工必读，Stage 0/1 或拆章前强制）

读项目 `outputs/creation-direction.json` 与 `outputs/spectacle-plan.md`：

| 输入 | 用法 | 缺失处理 |
|---|---|---|
| `tonal_direction` | 基调轨定义（复合基调须识别轨道） | **向用户索要或补拍板，禁止默认单轨静默开工** |
| `spectacle-plan.md` | 奇观/克制清单——决定哪些段落走哪条轨 | 同上 |
| `emotion_curve`（★ 2026-09-03） | 全片情绪曲线节点表——情绪段标注按曲线强度分段（平缓/升温/高潮/回落=绝对值与斜率），段边界优先对齐曲线节点；**BGM 重点节点 → 该段声音设计/音乐取舍（其余留白）**；全片原则作节奏仲裁依据 | 降级为文字判断流程，不阻塞 |
| `p1_cinematic_baseline`（★ 2026-09-03） | 写实线基线：声音设计受环境声原则+音乐圣经约束；风格段以其锁定段为母本（分镜提示词组装细则归各线） | 不启用则跳过相关约束 |
| `production_facts`（★ 2026-09-03） | 生产事实六项，分镜线消费规范见 `shared-production-facts.md` | 降级为原文判断，不阻塞 |

## 3. 节拍/段落标注（两列扩列，核心动作）

节拍/拆镜方案每行增加——**情绪段**（平缓/升温/高潮/回落，对齐 emotion_curve）+ **基调轨**（复合基调时，如悬疑/燃向）+ 镜头语言倾向（按基调池联动表查：`modules/xiage-styles/references/tonal-directions.md`）。**轨道切换点必须落在段边界**。

## 4. 镜头语言按轨推导（默认倾向，非硬约束）

- **悬疑轨默认**：低光高反差、前景遮挡构图、手持微晃、慢节奏留白、音效=环境低鸣/寂静、信息逐步释放；
- **燃向轨默认**：快切、跟拍/甩镜、能量色高饱和、慢动作点缀大招、音效=强节拍；
- 段时长按轨分配：悬疑/情绪段 12-15s、燃向动作段 8-10s；
- **偏离须注理由**：任何偏离默认的决策必须在基调追踪表显式写明——错误拦在纸面，不埋进成片。

## 5. 基调追踪表（验收产物）

`段号 | 情绪段 | 基调轨 | 关键镜头语言体现 | 偏离及理由`。用途：① 用户复核偏离点 ② 成片复盘——观感不对回查本表，区分「设计标错」（修轨道划分）vs「执行走样」（重做该段）。

## 6. 纪律

1. 禁止默认单轨静默开工（tonal_direction 缺失必须补拍板）；
2. 情绪段/基调轨两列与追踪表缺一不可；
3. 轨道切换点落段边界；
4. BGM 只在 emotion_curve 的 BGM 重点节点铺，其余留白（不铺满全片）。
