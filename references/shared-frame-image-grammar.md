## 一、一句话内核与构建顺序

**电影感 = 一个有前因后果的瞬间 + 一台站在世界里的摄像机 + 一组说得清来源的光。**
三者缺一，贴再多"电影级 / cinematic / 8K / masterpiece"标签也不会成立。

固定构建顺序（不建议跳步）：

```
场景母版(这是什么)  →  创作语法(可选增强层)  →  编译表达(写成目标模型语法)  →  结果修复(诊断产出再回改)
Scene Master        →  Creative Grammar       →  Model Compiler            →  Result Repair
```

先决定"画面是什么"（含它被谁、在哪、怎么看），再决定要不要叠加创作语法（风格卡 / 摄影卡，见 §六），最后才决定"怎么喂给某个模型"。一个场景母版可编译成多份不同模型的原生提示词。创作语法层是可选的：不选卡时，直接由场景母版进编译。

## 二、场景母版不变量与五条成画原理

### 2.0 场景母版不变量（Scene Master Invariants）

下游任何适配（改结构、改词序、改密度、换原生语法、加/减排除项、换参考图写法、换参数形式）都**不得**悄悄改动以下事实：

- 角色身份、场景、时间、天气、故事节拍、当前动作；
- 视觉中心、摄像机目击位置、空间分层、构图逻辑；
- 主光源、核心道具、画幅比例、用户的显式限制。

**转模型 / 多模型输出时先锁定：`SYNTAX MAY CHANGE. SCENE LOGIC MAY NOT.`**（语法可改，画面逻辑不可改。）
虾系落点：首帧图→视频提示词、资产图→分镜引用、H3 双产、Seedance 语法适配等**每次提示词形态转换**，转换前后逐项核对本清单，缺项即转写事故。

### 2.1 从故事切入，不从主体标签切入

写序列里的一个瞬间，留上一件事的痕迹，暗示下一步。
- 弱：`角色A站在街边`
- 强：`最后一辆巡逻车开走后，角色A仍站在那家拉下卷帘门的杂货店外，手里握着一杯凉掉的咖啡`
优先"等待 / 余波 / 犹豫 / 被打断的日常 / 离开 / 被窥视的私人动作"，除非需求依赖高潮才用动作爆点。

### 2.2 给摄像机一个物理目击位置

摄像机必须站在与角色同一个空间里，而非空中的漂亮机位。可用：半开的门后、公交最后一排、街对面站台挡板后、停靠车后座、贴地靠湿路面、透过有划痕的玻璃 / 合理反射。
**遮挡不自动等于电影感**——只有当所选位置本就会产生遮挡时才加。
（与老白课 §六视高的关系：视高管"摄像机相对人物平面多高"，本条管"摄像机物理上站在场景里的哪个立足点"，先定立足点再看视高。）

### 2.3 让环境携带证据

挑少量"有因果"的细节，交代地点 / 年代 / 刚发生过什么 / 角色状态，而不是堆杂物：雨后湿外套+椅子下的水、对话草草结束后的凉饮+翻倒小票、久用公交的磨旧座椅+旧广告+保养痕。
**判据：若人物全部消失，这个空间仍能暗示刚才发生了什么。**
虾系落点：虾塘场景（空镜）资产图按剧情状态选证据细节；虾镜/听风画面描述里环境细节须有因果，不写"漂亮但没故事"的陈设清单。

### 2.4 为"观察"构图，不为"宣传"构图

让主体大小与位置变化；允许留白、局部可见、不对称、环境压过人物。脸不必永远正面、完整、全清。
不要机械地把所有缺陷一次加满——构图要"有理由"，而非"随机化"。（操作法仍按老白课构图四规则执行。）

### 2.5 光是被合理化的，不是装饰

先点名真实光源，再谈氛围。光描述必须能回答：主光源？辅助/间歇光源？影子聚在哪？哪些面反光？由此推出的克制冷暖关系。
蓝轮廓光 / 金光束 / 体积雾 / 眩光 / 浅景深——只有场景里真有对应来源时才允许出现，不能当风格徽章贴。

## 三、摄像机决策顺序（按序定，不越级）

> 执行位次：老白课定完机位/轴向/景别后，本节定单帧内摄像机行为。

1. 目击位置：摄像机物理上能站哪？（§2.2）
2. 距离：大远景 / 全景 / 中景 / 近景 / 细节。
3. 高度与角度：平视 / 坐姿平视 / 齐腰 / 贴地 / 俯高。
4. 边界遮挡：门框、座椅、玻璃、车流、帘，或无遮挡。
5. 焦段行为：空间开阔 / 中性 / 压缩 / 私密。
6. 运动：固定 / 克制手持 / 载具震动 / 缓慢观察漂移 / 不动。（**这一镜具体选哪种运镜、三轴辨误，见 `shared-camera-movement.md`**；本步只定单帧内运动取向）

焦段参考（仅当场景/模型需要时才写，别用焦段替代机位）：

| 焦段 | 典型行为 | 适合 |
|---|---|---|
| 24–32mm | 展示空间与贴近，夸大远近关系 | 狭小室内、建筑、环境压迫 |
| 35–50mm | 自然观察，适度环境 | 街景、双人镜、日常室内 |
| 65–85mm | 压缩距离，安静隔离 | 窥视、私人动作、隔层取景 |
| 100mm+ | 远、压缩、疏离 | 长焦观察、人群、不可触及的主体 |

画幅比例按叙事选，别一律默认超宽变形：1.33:1 / 4:3 档案感或年代感；1.66:1 / 1.85:1 均衡剧情；2.00:1 / 2.35:1 / 2.39:1 强调横向关系或环境留白。**始终以用户/项目指定比例为准**（P1 基线或项目配置已锁画幅时从其规定）。

## 四、光的构建清单（光源地图 · 母法）

先画光源地图再描述：

```
主光源：来源、方向、软硬、色温倾向
辅助光源：来源、出现时机或强度
阴影区：光被自然挡住的位置
高光面：皮肤、湿布、玻璃、金属、灰尘、油漆
曝光行为：正常 / 轻微欠曝 / 保护高光
```

可复用的"合理化光源"示例：
老式绿色荧光灯 + 间歇琥珀路灯；阴天窗光 + 一盏低矮暖光台灯；日出前蓝调环境光 + 上方砖墙微弱暖光；钠灯路灯 + 便利店渗出的冷光；桌面实用灯 + 走廊微弱溢光。

捕获质感最多选几项兼容项（当成"拍摄行为"而非装饰叠加层）：自然/细颗粒、真实强光源周围的轻微光晕、柔和高光过渡、轻微镜头衰减、微小对焦不完美、物理合理的运动模糊、低饱和/老化色彩、可读但不 HDR 的阴影。

### 附 · 六大现成光型速查（★ 2026-09-09 补入，来源：《AI视频做电影感》P3 蒸馏）

**定位（务必看清边界）**：本表**只回答"这种光叫什么、往脸上放什么效果、传达什么情绪"**，是命名与选型菜单；**光的合理化一律回上面光源地图五项**——每一型都必须先答得出"光源是什么、在哪、为什么在这里"。命名词不豁免动机场：`shared-quality-gate.md` 写实线"光源必须有物理来源"对本表六型**全部适用**（小房间/家居/日常场景禁无动机的硬质侧顶光）。

| 光型 | 英文关键词 | 脸上发生什么 | 情绪/适用 | 光源动机常例 |
|---|---|---|---|---|
| **顶光** | `top lighting` / `overhead lighting` | 眼窝向下投阴影、眉骨压暗、颧骨下方起影 | 压迫、阴郁、审讯感、凶相外溢 | 头顶吊灯/裸灯泡、洞口天光、车内顶灯、正上方实用灯 |
| **侧光（正侧光）** | `side lighting` / `frontal side light` | 脸一半清晰、暗侧**近乎全黑** | 坚毅、不好惹、悬念、强故事感 | 侧向窗、门口溢光、街面橱窗光、侧向火光 |
| **逆光 / 轮廓光** | `back lighting` / `rim light` / `silhouette` | 面部欠曝，边缘起一圈亮 | 唯美、梦幻、神秘、剪影 | 日落/窗/灯牌/车灯位于人物后方 |
| **伦勃朗光** | `Rembrandt lighting` | 暗侧颊部**保留一个小三角亮区** | 经典、均衡、"标准电影感"人物像 | 45° 侧前主光 + 暗侧微弱补光或墙面反弹 |
| **硬光** | `hard light` | 阴影边界锐利、明暗对比拉满 | 肃杀、危险、黑色电影 | 直射日光、裸露灯泡、无柔光扩散的实用灯 |
| **体积光 / 丁达尔** | `volumetric lighting` / `god rays` / `tyndall effect` | 光柱可见、尘埃浮出 | 神圣、废土、破败、时间凝滞 | **有介质**（尘/烟/雾/水汽）**+ 有方向开口**（高窗/破顶/门缝） |

- **最易混的一组辨析（本表唯一必须记住的差别）**：**正侧光 vs 伦勃朗光**——差别只在暗侧那一面：正侧光暗侧**几乎全黑**，伦勃朗暗侧**留一个三角形亮区**（由对侧颧骨上方的一点补光/反弹形成）。两者混写时出图会卡在"半黑脸"上下不去，故提示词里要**显式声明暗侧行为**（如 `the shadow side falls nearly black` 或 `a small triangle of light remains on the shadow-side cheek`）。
- **使用口径**：一次**只选一型作主导光**（与 §六 选卡同律——风格卡/摄影卡各一张，不堆叠）；色温、曝光、材质反应仍由所选卡的"光与对比 / 色彩与曝光 / 材质表现"字段推导，**光型词只补"方向 + 软硬"这一层**，不得反过来覆盖卡片。
- **不采纳项（★ 用户拍板 2026-09-09）**：原课程把"全局青橙（teal & orange）调色"当商业片首选——与本单源"色彩由光源与材质推导、不做无因的全局调色"直接冲突，**按造梦师口径不收**（见各卡"色彩与曝光"字段与 §七 无因不造）。情绪用色需求请走选卡 + 光源色温，不靠整片染色。

## 六、创作语法层（可选增强 / Creative Grammar）

**总规则**：卡片是"决策系统"，不是关键词包。只把真正会改变场景母版的维度落到母版上，禁止把整张卡原样粘进最终提示词；编译仍走目标模型适配。默认一张风格卡 + 一张摄影卡；不冲突且用户要求时才叠加更多。内部分清分工：风格卡管"故事/世界观语法"，摄影卡管"机位/光语法"。本层永远不能覆盖 §2.0 的场景母版不变量。
**卡片与虾系三件套的关系**：风格卡是"这场戏"粒度的决策，服务但不替代虾格拍板的全片风格三件套与基调（tonal_direction）；卡片选择结果不得与已拍板三件套冲突，冲突时以三件套为准并提示用户。

### 6.1 风格卡 Style Card（全 16 张，逐卡十字段）

每张卡：选一张翻译进母版即可，不要堆叠。字段——适用 / 故事引擎 / 首选时刻 / 调度 / 机位角色 / 光与对比 / 色彩与曝光 / 空间逻辑 / 材质表现 / 反套路。

**① 观察式社会现实 Observational Social Realism**
- 适用：劳动、公共空间、家庭压力、普通机构。
- 故事引擎：社会处境通过日常而非解释显现。
- 首选时刻：等待、程式化劳作、或未解决的余波。
- 调度：人占据实用位置，很少外放情绪。
- 机位角色：以人类距离耐心目击，有时被建筑限制。
- 光与对比：现有光源，覆盖不均，有未加保护的死区。
- 色彩与曝光：克制的局部色彩；皮肤与墙面接受不完美的曝光。
- 空间逻辑：环境与机构几何与人同等重要。
- 材质表现：磨损跟随重复使用、维护、天气与阶层条件。
- 反套路：苦难奇观、煽情贫困、英雄工人像、美化的破败。

**② 家庭余波 Domestic Aftermath**
- 适用：争吵、离别、秘密、疲惫、被改变的家庭日常。
- 故事引擎：事件已过；被移位的物件和未完成的任务承载后果。
- 首选时刻：某人离开或停止说话后的几秒或几小时。
- 调度：身体分到不同区域；手继续一件无必要的小事。
- 机位角色：从门口、走廊或就座的房间位置安静观察。
- 光与对比：窗光或实用灯不均衡地落在有人居住的房间上。
- 色彩与曝光：熟悉的家居色彩在阴影或暮光里失去饱和。
- 空间逻辑：门槛、空椅、台面、相连的房间揭示关系。
- 材质表现：杯子变凉、织物起皱、食物变干、水渍残留。
- 反套路：含泪特写、完美室内布景、符号物件堆砌、狗血逆光。

**③ 夜间程序 Nocturnal Procedure**
- 适用：维护、调查、运输、医护、安保的例行。
- 故事引擎：重复任务在疲惫或隐藏风险累积中继续。
- 首选时刻：工作中的一次检查、交接、停顿或小异常。
- 调度：工具与工作顺序决定姿势与距离。
- 机位角色：从一个有用但非特权的工作位置观察。
- 光与对比：被阴影隔开的实用光斑；间歇的外部溢光是次要的。
- 色彩与曝光：随光源特定的污染色，不做全局青橙调色。
- 空间逻辑：走廊、工位、载具、台面、通行边界组织画面。
- 材质表现：油、玻璃、金属、反光条、皮肤、制服各自反应不同。
- 反套路：泛霓虹黑色、战术英雄姿势、装饰烟雾、一尘不染的设备。

**④ 旅途记忆 Memory in Transit**
- 适用：巴士、火车、汽车、渡轮、车站、临时分离。
- 故事引擎：窗外的移动对比内心固定在刚发生的事上。
- 首选时刻：出发与到达之间，对话结束之后。
- 调度：坐或站的身体经由过道、车窗、空座发生关系。
- 机位角色：同车乘客或站台目击者，绝不是全知的怀旧。
- 光与对比：掠过的光源、车窗反射、站台溢光或黎明过渡。
- 色彩与曝光：混合的旅途光，因移动带来的轻微曝光漂移。
- 空间逻辑：层叠的玻璃与重复的座椅压缩私密与公共空间。
- 材质表现：冷凝、震动、磨旧的软垫、车票、行李都保持因果。
- 反套路：到处梦幻虚化、旅游广告美、随意镜头眩光、完美的怅望姿势。

**⑤ 历史材质现实 Historical Material Realism**
- 适用：时代劳作、家庭生活、机构、旅行、非英雄化的历史。
- 故事引擎：历史通过人必须对时代物件实际做什么来显现。
- 首选时刻：准备、维护、等待或后果，而非排场。
- 调度：服装结构、工具、家具、礼仪约束动作。
- 机位角色：时代建筑内可信的目击者，不是博物馆展陈。
- 光与对比：只有该时代可用的光源；阴影保持材质性的厚重。
- 色彩与曝光：染料、油漆、金属、烟、日光保留时代特定的限度。
- 空间逻辑：门、灶、街道、作坊、交通仍可使用且拓扑清晰。
- 材质表现：包浆跟随年代与使用，而非装饰性的"复古"处理。
- 反套路：古装游行的摆拍、奇幻式洁净、泛黄滤镜、时代错置的器件。

**⑥ 静默悬念 Quiet Suspense**
- 适用：被藏起的信息、接近的遭遇、延迟的发现、含糊的威胁。
- 故事引擎：一个日常动作继续，而第二个事实改变了它的意义。
- 首选时刻：认出之前，或一个几乎没被察觉的扰动刚发生后。
- 调度：角色面对不同的信息区；视线交代不完所有信息。
- 机位角色：从一个可信的边界知道得比角色略多或略少。
- 光与对比：光源层级藏起一个相关区域，但不做成戏剧性全黑。
- 色彩与曝光：克制，靠曝光而非强调色控制注意力。
- 空间逻辑：走廊、反射、门、纵深制造延迟的信息。
- 材质表现：帘、液体、灰尘或松动物件里的微小动作提示后果。
- 反套路：荷兰角、明显的反派剪影、恐怖片蓝光、惊吓式取景。

**⑦ 天气承载的亲密 Weather-Borne Intimacy**
- 适用：由雨、雪、热、风、湿度塑造的克制关系。
- 故事引擎：天气改变人们如何共享遮蔽、距离、衣物、物件。
- 首选时刻：进入遮蔽前、停顿中、或天气过去后。
- 调度：身体围绕伞、外套、热度、湿座、有限的遮挡去协调。
- 机位角色：待在同一种天气条件里，而非从绝对安全处旁观。
- 光与对比：天气改变真实光源、能见度、表面高光。
- 色彩与曝光：大气衰减与色彩污染跟随距离和湿度。
- 空间逻辑：遮蔽边界与暴露区结构化情感距离。
- 材质表现：织物重量、皮肤、玻璃、路面、呼吸、头发都做物理反应。
- 反套路：造雨机式浪漫、通体油亮的湿、装饰雾、MV 式拥抱。

**⑧ 职责之地 Landscape of Duty**
- 适用：远程作业、巡逻、农业、基础设施、大空间里的照护。
- 故事引擎：尽管有尺度、孤立或缓慢的环境变化，义务仍在继续。
- 首选时刻：巡查、返回、准备，或两次任务之间的停顿。
- 调度：人相对路线与设备保持渺小而有目的地放置。
- 机位角色：尊重地形与通行的远方目击者。
- 光与对比：大范围环境光源，合理时才有有限的局部实用光。
- 色彩与曝光：风景主导色彩；人不做广告式的主客体分离。
- 空间逻辑：路径、屏障、地平线、作业区解释运动。
- 材质表现：风、尘、水、锈、植被、衣物显示长期暴露。
- 反套路：旅游全景、默认的无人机奇观、孤胆英雄剪影、史诗调色。

**⑨ 偶发时尚感 Accidental Editorial**
- 适用：偶然形成视觉紧张排布的普通行为。
- 故事引擎：一个非摆拍事件偶然对齐了服装、手势、建筑。
- 首选时刻：整理到一半、等待、穿过、或拿取物件时。
- 调度：不对称与身体角度来自动作，绝不是走秀式展示。
- 机位角色：从一个可信的路过位置捕捉到这次对齐。
- 光与对比：现有光制造图形化分离，但不带大片精修。
- 色彩与曝光：服装色彩可主导一次，皮肤与环境保持自然。
- 空间逻辑：线条与负空间从场地涌现，而非搭景。
- 材质表现：布料的褶皱、重量、天气、运动都保持可见。
- 反套路：时尚摆姿势、广告大片布光、奢侈品商业精修、完美的衣柜展示。

**⑩ 都市异物现实主义 Urban Intrusion**
- 适用：当代普通城市里的一个异常人 / 衣物 / 物件。
- 故事引擎：只有一样东西异常；日常系统照常在它周围运转。
- 首选时刻：通勤、停车、等待、维护、或不被注意的经过。
- 调度：异常元素遵循与其他一切相同的重力、通行、社交距离。
- 机位角色：像一个可信的路人或边缘目击者那样观察。
- 光与对比：现有城市光源照亮异常物，不做"揭示式"布光。
- 色彩与曝光：城市保持普通；异常物不会给世界重新上色。
- 空间逻辑：停车位、电梯、办公室、道路、屏障完全写实。
- 材质表现：异常材质对混凝土、雨、尘、荧光灯做物理反应。
- 反套路：完整的奇幻世界、赛博朋克改造、戏剧化人群反应、全球性视觉异常。

**⑪ 基础设施崇高 Infrastructural Sublime**
- 适用：隧道、雨水系统、电站、机场、港口、大坝、工业设施。
- 故事引擎：人的流程在一个太大而无法一眼感知的系统里继续。
- 首选时刻：巡查、延误、交接，或以尺度感呈现的远方移动。
- 调度：人保持渺小，系于走道、载具、控制台、安全区。
- 机位角色：站在可达的检修位置，而非不可能的航拍视角。
- 光与对比：工业实用灯与环境溢光只揭示系统的一部分。
- 色彩与曝光：功能性油漆、混凝土、金属、天气、安全色主导。
- 空间逻辑：重复的结构单元与通行路线建立尺度。
- 材质表现：体量、湿度、腐蚀、尘、震动、热都有物理后果。
- 反套路：泛科幻巨构、不可能的建筑、默认的无人机奇观、渺小英雄崇拜。

**⑫ 边缘目击 Peripheral Witness**
- 适用：私人动作、社交距离、不确定、没有通路看到的事件。
- 故事引擎：有限的通路迫使观者重建真正重要的东西。
- 首选时刻：被察觉之前、安静交流的当下、或刚分离之后。
- 调度：动作经由局部遮挡与离轴关系保持可读。
- 机位角色：车后、玻璃后、柱旁、门内、帘后、或拐过走廊转角。
- 光与对比：那层边界有它自己的曝光与反射行为。
- 色彩与曝光：前景遮挡不会变成装饰性色彩画框。
- 空间逻辑：遮挡跟随真实目击位置并保留拓扑。
- 材质表现：玻璃、油漆、织物、车面以可信方式影响清晰度。
- 反套路：完美的正机位、干净的英雄调度、硬贴上去的遮挡、主事件不可读。

**⑬ 静默灾变 Quiet Catastrophe**
- 适用：通过被改变的常规与小后果来表现的大事件。
- 故事引擎：灾变已发生；日常行为揭示它的规模。
- 首选时刻：余波、返回、清理、清点、或等消息。
- 调度：人做有限的任务，而不是表现恐慌。
- 机位角色：在地面与人类尺度观察后果。
- 光与对比：天气与残余的实用光源定义能见度。
- 色彩与曝光：避免海报级的危险色；让环境变化承载调性。
- 空间逻辑：一条被封的路、一个缺席的物件、一片受损区或被改变的流程锚定事件。
- 材质表现：碎片、水、尘、灰烬或破损遵循可信的原因。
- 反套路：爆炸、英雄奔跑、大规模恐慌、灾难海报式构图。

**⑭ 现实仪式感 Ritual Realism**
- 适用：穿戴装备、检查机械、关店、卸甲、收拾工具、备食。
- 故事引擎：重复的秩序揭示关怀、职责、疲惫或转变。
- 首选时刻：完成前的一个精确步骤。
- 调度：手、工具、表面、顺序决定姿势。
- 机位角色：尊重作业区，观看而不把它纪念碑化。
- 光与对比：作业光或现有光源优先照亮当前这一步。
- 色彩与曝光：功能性色彩与受控高光澄清材质状态。
- 空间逻辑：物件占据已知位置；缺席或移位有意义。
- 材质表现：触摸、重量、热、残留、磨损显示重复。
- 反套路：无正当理由的仪式奇幻、英雄姿势、把慢动作俗套刻进静帧、圣物符号堆砌。

**⑮ 材质冲突 Material Tension**
- 适用：视觉中心是某种物理关系，如金属/湿混凝土、丝绸/石、皮肤/玻璃、瓷/雾、油/布。
- 故事引擎：动作让两种材质发生接触或对比。
- 首选时刻：触碰、清洁、撞击之后、转移、或分离。
- 调度：手与物件显示重量、温度、摩擦、风险。
- 机位角色：近到能读出这层关系，同时保留它的空间成因。
- 光与对比：光源角度揭示不同的反射、吸收或透光。
- 色彩与曝光：色彩跟随材质与光源，不做装饰性调色。
- 空间逻辑：周围空间解释这层关系为什么会相遇。
- 材质表现：每个表面服从自己的粗糙度、湿度、形变、热状态。
- 反套路：随意的质感形容词、一切油亮、不可能的反射、材质属性与光矛盾。

**⑯ 过渡时刻 Transitional Light**
- 适用：日出前、日落后、雨刚停、警报刚停、门刚开、灯刚关、云层裂开。
- 故事引擎：光源状态改变，而动作继续。
- 首选时刻：过渡的头几秒或最后几秒。
- 调度：角色对变化的能见度或温度做实际反应。
- 机位角色：占据一个新旧两种光源状态都空间可读的位置。
- 光与对比：一个主导的过渡，带因果的阴影与高光移动。
- 色彩与曝光：混合色只在重叠光源够得到的地方存在。
- 空间逻辑：门、窗、云、灯具、移动的遮蔽解释这次变化。
- 材质表现：湿气、玻璃、皮肤、织物、金属以不同速率反应。
- 反套路：永久的黄金时刻感、多个装饰光源、无因的轮廓光、万物发光。

### 6.2 摄影卡 Cinematography Card（全 8 张，逐卡十二字段）

卡片必须真的改变目击角色、机位行为、光源行为或空间语法；相机品牌、焦段徽章、胶片型号、颗粒本身都不算"用了卡"。字段——适用 / 目击位置 / 距离 / 焦段行为 / 运动 / 景深与合焦 / 光源行为 / 曝光 / 材质反应 / 构图倾向 / 失败风险 / 勿混淆为。

**① 自然光源精准控制 Natural Source Precision**
- 适用：克制的室内、真实空间里的人像、日光与实用灯混合的场景。
- 目击位置：光源方向与主体调度都清晰可读之处。
- 距离：中广到近，由光源覆盖范围决定。
- 焦段行为：中性；透视保持空间诚实。
- 运动：固定或极小调整。
- 景深与合焦：有足够的纵深把主体、光源、受光面连接起来。
- 光源行为：一个主光源；副光源只影响它们够得着的区域。
- 曝光：保护主高光，同时允许自然衰减。
- 材质反应：指明哪些表面吸收、散射、反射或透光。
- 构图倾向：光源方向组织视觉中心，而非居中的脸。
- 失败风险：装饰性补光、脸部均匀曝光、光源增殖。
- 勿混淆为：没有光源地图的"唯美自然光"。

**② 现有光手持观察 Available-Light Handheld**
- 适用：公共生活、家庭张力、外业、不稳的贴近。
- 目击位置：站在动作边缘、坐或站的一个人参与者。
- 距离：近到能感到"在场"，远到保留空间成因。
- 焦段行为：中等开阔或中性；无化妆品式畸变。
- 运动：克制的手持漂移，或物理合理的微不稳定。
- 景深与合焦：当运动能解释时，允许选择性的失焦。
- 光源行为：只用现成的日光、实用灯、偶然溢光。
- 曝光：接受短暂的欠曝、爆掉的实用灯、由光源驱动的波动。
- 材质反应：皮肤、织物、墙、玻璃保持不均匀的可读性。
- 构图倾向：响应的取景、局部出画、不完美的时机。
- 失败风险：假的纪录片抖动、随机糊、混乱取景。
- 勿混淆为：低画质、监控画面、噪声滤镜。

**③ 环境宽景目击 Wide Environmental Witness**
- 适用：劳作、孤立、建筑、基础设施、风景中的职责。
- 目击位置：一个能解释路线与尺度的可达固定点。
- 距离：全景或大远景；人经由动作仍叙事可读。
- 焦段行为：空间开阔，但不做不可能的扩张。
- 运动：固定或缓慢的观察漂移。
- 景深与合焦：分层纵深，含前景、作业区、远方系统。
- 光源行为：大范围环境光源；局部实用灯保持次要。
- 曝光：空间连续性优先于脸部曝光。
- 材质反应：地形、混凝土、水、金属、天气建立尺度。
- 构图倾向：小主体、路线线、功能性的负空间。
- 失败风险：旅游全景、无人机奇观、小到不可读的动作。
- 勿混淆为："史诗广角镜头"或泛泛的定场镜。

**④ 夜间压缩观察 Compressed Nocturnal Observation**
- 适用：远方监视、车流、人群、够不到的私人动作、夜间交通。
- 目击位置：隔着一条街、站台、车道或深层内部空间层。
- 距离：长的观察距离。
- 焦段行为：压缩的纵深与多层光源重叠。
- 运动：固定、支撑，或从真实平台的缓慢跟移。
- 景深与合焦：选择性平面；掠过的车流或玻璃可能打断清晰度。
- 光源行为：实用光斑重叠但不糊成霓虹一片。
- 曝光：保护明亮的招牌与灯；接受深沉的非活动区。
- 材质反应：湿面、玻璃、油漆、金属有选择地捕捉光源。
- 构图倾向：堆叠的空间平面与被藏起的通路。
- 失败风险：狗仔队套路、霓虹黑色、随意的散景、被压平的拓扑。
- 勿混淆为：一张被标成"夜晚 85mm"的人像而已。

**⑤ 现场硬直闪 Hard Direct Flash**
- 适用：突然的记录、夜场出门、证据、拥挤的室内、令人不适的直接感。
- 目击位置：近、正面或斜侧，在人手持相机的高度。
- 距离：近到中；闪光的落差点必须可见。
- 焦段行为：中性到中等开阔。
- 运动：瞬间抓拍；闪光冻结区之后仍可残留环境运动。
- 景深与合焦：活动平面清晰，背景迅速落入环境暗部。
- 光源行为：一个同轴或近轴的闪光主导；环境光源在曝光允许处存活。
- 曝光：硬的前景高光、快速落差、有限的背景覆盖。
- 材质反应：皮肤、玻璃、反光织物、油漆、灰尘尖锐且各异地反应。
- 构图倾向：突然的裁切、人群的贴近、不完美的社交距离。
- 失败风险：时尚广告、均匀的白光轰炸、红毯精修。
- 勿混淆为：影室闪光灯塑形或柔和的美容补光。

**⑥ 深焦空间调度 Deep-Focus Spatial Blocking**
- 适用：群戏、程式化空间、社会层级、同时发生的多个动作。
- 目击位置：前景、中段动作、背景后果对齐而不欺骗拓扑之处。
- 距离：中广到全景。
- 焦段行为：空间开阔或中性，透视受控。
- 运动：固定或有动机的横向 / 揭示式运动。
- 景深与合焦：多个动作平面刻意保持可读。
- 光源行为：光源分隔区域，而不只孤立一张脸。
- 曝光：在保留真实落差的同时，跨纵深维持可读的中间调。
- 材质反应：大气的距离与表面反差防止画面扁平。
- 构图倾向：视线、门、家具、路线连接同时发生的事件。
- 失败风险：舞台式摆拍、处处同权重、不可能的合焦、杂乱。
- 勿混淆为：在居中的群戏上简单加个"深焦"。

**⑦ 实景灯低照度室内 Low-Key Practical Interior**
- 适用：深夜房间、办公室、作坊、载具、私人的余波。
- 目击位置：站在实用灯真实的溢光里，而非不可能的全黑洞间。
- 距离：中或近，且保留周围的黑暗。
- 焦段行为：中性或轻微压缩。
- 运动：固定或谨慎的手持。
- 景深与合焦：一到两个可读区；非活动的纵深可以消失。
- 光源行为：台灯、灯具、屏幕、走廊溢光的覆盖有限。
- 曝光：保护实用灯的灯芯与皮肤高光；保留不可读的阴影。
- 材质反应：哑光面下沉；玻璃、眼睛、金属、磨旧的边缘捕捉窄高光。
- 构图倾向：被功能性黑暗隔开的发光孤岛。
- 失败风险：压成一片的无特征黑、凭空轮廓光、油亮的黑色片质感。
- 勿混淆为：单纯的欠曝或青橙夜调。

**⑧ 阴天材质写实 Overcast Material Realism**
- 适用：街道、工地、历史外景、湿冷天气、内敛的人像。
- 目击位置：地面高度，表面与空间纵深仍可观察之处。
- 距离：从广角到近，取决于材质关系。
- 焦段行为：中性；不需要光学奇观。
- 运动：固定、缓慢或克制手持。
- 景深与合焦：中等纵深；大气透视跟随湿度与距离。
- 光源行为：大面积天光，方向线索微弱，带局部遮挡。
- 曝光：保护苍白的天空与湿高光，而非到处做 HDR 找回。
- 材质反应：石、金属、织物、皮肤、油漆、水靠粗糙度与饱和度分离。
- 构图倾向：色调层次、柔和的平面、小色块锚点。
- 失败风险：灰泥一团、假的湿亮、剪贴板式主体剥离、忧郁滤镜。
- 勿混淆为：处处低对比、把降饱和当风格。

## 七、反 AI 味清理 + 克制度检验（交付前门禁）

生成后、输出前必过：

- **删词仍能成立检验**：删掉所有相机品牌、胶片型号、分辨率、`masterpiece / epic / stunning / award-winning / 8K / highly detailed`，剩下的文字仍须描述出具体故事、动作、地点、机位关系、有来源的光。删完就空 = 本来只是堆装饰词。
- **优先具体名词、物理动作、因果痕迹、有来源的光**，而非形容词堆砌。
- **无因不造**：不得凭空发明轮廓光、霓虹、雾、眩光、浅景深、破损、污渍、遮挡、不完美——除非有物理或叙事理由。
- **避免海报 / 时尚大片 / 游戏 CG / 概念原画 / 广告逻辑**，除非明确要求（项目风格即此类介质时按其介质规范执行，不适用本条）。
- 表面不得一律油亮、全清、干净、等权可读。
- **不得虚构模型版本、API 字段、参数值、参考图数量、强度范围、分辨率上限**；前端表现可能与底层模型不同。
- 排除项（负面）要精简、场景特定、与目标模型兼容、不互相矛盾——不贴通用负面清单。
- 尊重项目已锁定的语言、格式、目标模型、画幅比例与输出简洁度要求。
- 若成片读起来像广告/海报/时尚人像/设定图/游戏渲染，先改动作、主体尺度、目击位置、光源层级，而不是补更多风格词修结构。

> 虾系落点：本节两条口径（无因不造 / 删词仍能成立）已同步登记进 `shared-quality-gate.md` 作为 P1 质检口径；首帧/视频提示词交付自检时逐条过。
