# 生产事实六项 + 四级事实标注 + 空间链（独立调度文件）

> 来源：前半程创作基准方法论蒸馏（★ 2026-09-03 集成）。**虾料完成世界观/知识图谱梳理后、交给虾格前，加载本文件补齐生产事实。** 目的：把会影响视觉、表演、声音与连续性的隐含前提，变成用户确认过的"项目真相"——不让下游（虾格三步向导 / 虾塘提示词 / 虾镜镜头设计）各自臆造。

## 0. 定位（与既有流程的关系）

- 虾料既有产出（章节/场景块/世界观/知识图谱）回答"**有什么**"；本文件补的是"**按什么坐标拍**"——国家年代、季节时间轴、语言声音、威胁规则、人物小传、状态母题。
- 不改写剧情、不加角色、不加台词；只补足制作所需的世界坐标。
- 六项与既有 docs/ 设定库**合并落盘**（补进对应文件），不另起炉灶；唯一新增产物是空间链表（`outputs/scene-chain.md`）。

## 1. 四级事实标注（★ 每条生产事实必须带等级）

| 等级 | 定义 | 处理 |
|---|---|---|
| **剧本事实** | 原文明确写出 | 直接登记 |
| **强推断** | 多条原文线索共同支持 | 登记 + 写明依据 |
| **导演提案** | 原文未写，但国家/年代/职业/建筑/世界规则必须具体化 | 给 1 套最合适方案 + 理由，**禁止伪装成原文事实** |
| **待定冲突** | 不同选择会实质改变剧情或资产 | 最多提出 1 个阻塞问题，等用户拍板 |

- 用户确认后，提案升级为项目真相，后续全链路（虾格/虾塘/虾镜）以其为准。
- 与虾料既有【推断】标注习惯兼容：强推断/提案条目在 docs/ 中保留标注，禁止确认后仍挂"推断"字样造成下游不敢引用。

## 2. 六项生产事实（★ 逐项登记，缺一须说明原因）

1. **国家、地域与年代**：具体国家，必要时到州/省/城市或地貌带；年代给具体年份或不超过 10 年的范围；同步锁定技术、建筑、服装、交通与通讯边界（这些直接约束虾塘资产与场景提示词的时代正确性）。
2. **季节与剧情时间轴**：季节、天气、昼夜比例；故事经历多久（几天/几月/几年）；光线状态如何随剧情变化（供虾格 FS 库与分镜光照参考）。
3. **语言与声音文化**：对白语言、口音/方言、角色教育/阶层造成的语速与措辞差异——写入对应角色小传，供虾塘声线配置与视频提示词声音设计消费。
4. **世界与威胁规则**：超自然/力量体系是否客观存在、传播或变异机制、能力边界、死亡与伤害规则、哪些保持主观暧昧——防止分镜与资产阶段规则漂移（如"能力突然超标""伤势莫名自愈"）。
5. **人物小传（生产向）**：主要人物每人一小段，必须足以约束后续角色提示词与表演——年龄段/国籍族裔/成长地域；家庭关系与血缘传递线索；外在目标与内在缺口；本片人物弧与关键转折；身体/皮肤/姿态/服装磨损/随身物的生活痕迹；**声音音色/口音/语速/压力下的说话方式**；健康、受伤、换装、年龄、亲属等资产依赖登记（供虾塘依赖图，见 xiatang `references/character-dependency.md`）。外貌细节此时只定方向，不提前写完整五官提示词。
6. **状态链与视觉母题**：换装、伤势、变异、道具转手、灯光/空间破坏等**会改变外观的状态变化**（登记为连续性检查项）；反复出现并承担叙事意义的物件或颜色（母题，供分镜与关键场景素材参考）。

**落盘**：按 DramaClaw 设定库结构合并写入 `docs/`——①②④进 `02-world`（或 `08-bible`），③⑤进 `03-characters` 对应人物卡，⑥进 `08-bible`（连续性/母题节）。禁止写入 skill。

## 3. 空间链表（★ 新增产物，scene-consistency 的上游输入）

世界观与场景块确定后，输出一份**空间链表**：只列剧情会穿越的主要空间、方向与因果衔接——不做地图、不做场景图。

```markdown
# 空间链表（outputs/scene-chain.md）

| 序 | 空间（规范名） | 剧情作用 | 与前后空间的衔接/方向 | 依据（事实等级） |
|---|---|---|---|---|
| S1 | 场景X | 主角日常活动地 | 出后门→场景Y（向东穿巷） | 剧本事实 |
| S2 | 场景Y | 关键冲突发生地 | 接受 S1 逃入；反面角色从街口来 | 强推断（依据：…） |
```

- 空间命名必须使用（或提议）**场景资产规范名**，与虾塘 scenes 对齐，禁止一名多写。
- 方向与因果写"谁从哪到哪、为什么"，不写室内布局（室内布局归 scene-consistency 空间真理图）。
- **消费方**：scene-consistency 第 1 步建空间真理图前先读本表（跨场景走向/衔接关系直接引用，不必从原文重推）；场景资产库比对补建时，链上出现而库中缺失的空间进补建清单。

## 4. 交接与门禁

- 六项中**国家年代、主要人物关系、核心世界规则、人物小传**未确认前，虾格不得输出正式创作方向三件套、虾塘不得输出正式角色确认稿；只有不影响造型的细节可登记为待定，延后到真正相关阶段再问。
- 交接字段（handoff / 6.2 表）新增：`production_facts`（六项登记状态：confirmed/partial + docs 路径）、`scene_chain`（outputs/scene-chain.md 路径）。
