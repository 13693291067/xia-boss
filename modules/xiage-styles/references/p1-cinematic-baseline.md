# P1 写实线风格锁定深化（摄影·色彩·声音创作基准 · 独立调度文件）

> 来源：前半程创作基准方法论蒸馏（★ 2026-09-03 集成）。**三步向导①风格类型拍板后，若所选风格的渲染介质为真人实拍/写实 CG，加载本文件执行一次深化交付**；动画、风格化 3D、二维自动跳过（**明文禁止**把胶片、真人皮肤和实拍光源规则套到 UE5、风格化 3D 或二维动画）。

## 1. 定位

- 虾格三要素（style_tag / instructions / avoid）解决"画面长什么样"；本深化解决"**用什么摄影系统、怎么曝光、色彩怎么管理、声音怎么设计**"——把视觉参考翻译成**可执行参数**。
- 只给 **1 套完整推荐**，用户整体确认或指出冲突；不让用户填空表，不同时倾倒多套互斥方案。
- 不在此阶段预写具体分镜机位（那是分镜线的职责）；不生成色卡图片、声音文件或 BGM。

## 2. 推导顺序（★ 先读剧本，再选系统）

先判断：类型/子类型、年代与地域（引用虾料生产事实）、现实程度、情绪温度（引用情绪曲线）、空间规模、叙事速度、主要视觉矛盾——**再**选择摄影与声音系统。禁止先选喜欢的电影再强套剧本。

## 3. 交付六件（顺序固定）

1. **主要影视参考**：默认 1 部，必要时最多加 1 部补充；片名后必须写明借鉴维度（光线/色调/空间压迫/尺度/材质/大气/表演距离/镜头调度）；主要参考决定全片摄影母语，补充参考只解决 1 个清楚维度；没有准确参考时用摄影语言描述，不强行列片名；**参考必须立即翻译成可见参数，禁止只写"某导演式氛围"**。
2. **摄影系统（二选一，禁止混搭）**：胶片实拍（35mm/16mm + 具体胶片型号 + 匹配镜头系统）或数字实拍（具体数字摄影机 + 传感器/高光特征 + 镜头系统）；需要胶片感时写胶片印片模拟，不得伪装成实体胶片。锁定摄影机、镜头家族、**画幅与帧率**。
3. **全片风格锁定段**：一段中文自然语言（逗号/分号组织，不用加号标签），六部分——①拍摄介质（摄影机/胶片、镜头家族、画幅、帧率）②光线曝光（实际光源、方向/弥散、反射、曝光、高光与暗部）③色彩反差（环境主色/辅助色、冷暖、饱和度、黑位、中间调、肤色保护）④成像纹理（颗粒、阴影噪点、光晕、锐度、镜头缺陷与印片质感）⑤大气材质（雪/雨/雾/尘、呼吸、皮肤、布料、木材、金属受光）⑥禁用项（数字洁净感、游戏 CG、塑料表面、过度锐化、HDR 光晕、无来源轮廓光）。**每个短语必须能改变可见结果；删除"高级感、电影感、压迫而克制"等无法渲染的空词。**
4. **环境色彩策略**：环境冷暖关系、曝光、黑位、中间调、主要环境色、允许的局部强调色、肤色保护与禁用色。**无已确认环境图时不凭文字臆造 HEX 值**（HEX 属于 FS 库/场景阶段）。角色资产确认稿继承全片写实材质语言，但使用中性影棚光，不让戏剧环境色覆盖人物/服装/道具固有色（与虾塘既有规范一致）。
5. **主要人物声音气质基准**：逐主要人物锁定音色、口音、语速、语调与压力下的说话方式（与虾料人物小传声音条目对齐），作为虾塘声线配置与后续声音资产设计依据。
6. **全片环境声原则 + 音乐圣经**：声音与音乐**分开**建立——每场戏应有环境声与同步动作音效，喘息/痛哼/哭泣/笑声/低吼属非语言人声；**BGM 只承担推动、反转、连接、积蓄或释放情绪，不默认铺满全片**（结合情绪曲线 BGM 重点节点取用）；锁定主要乐器、节奏材质、低中高频倾向、核心动机、动态范围、留白与禁用声音；写实惊悚/剧情向优先少乐器、少旋律、多空隙，避免高音金属"叮叮"、无依据人声和声、宏大预告片铜管与每场更换乐器。

```json

  "main_reference": {"title": "示例作品", "aspects": "光线、空间压迫"},
  "supplementary_reference": null,
  "camera_system": "数字实拍：示例摄影机 + 示例镜头家族",
  "format_framerate": "2.39:1 / 24fps",
  "style_lock_paragraph": "一段中文可执行风格锁定（六部分）",
  "env_color_strategy": "冷暖/曝光/黑位/中间调/主环境色/强调色/肤色保护/禁用色",

  "ambient_sound_principles": "环境声与动作音效原则",
```

- 非写实项目：`enabled=false`，其余字段省略。
- 确认方式：三件套拍板后（虾格 §0.2.4 时点）随落地批一并交付，用户整体确认或指出冲突；确认前不得进入虾塘建资产。

## 6. 纪律

1. 非写实线**强制跳过**本深化，且不得把锁定段词句混进动画/CG 提示词。
2. 锁定段中每个短语必须通过"**换个写法画面会变吗**"检验；空词一律删除。
3. 摄影系统二选一后全片锁定；中途更换 = 重跑本深化并通知下游。
4. **光线防假铁律（★ 2026-09-04 采纳，横切来源）**：锁定段②"光线曝光"必须给**明确物理发光源**——日景：侧面窗棂天光/林间丁达尔斑驳阳光/天空自然散射；夜景室内：暖黄钨丝灯/日光灯管频闪/烛火微光/霓虹反射；阴影呈青灰/暗棕环境漫反射色阶，**禁死黑、禁全脸漂浮发白**。**日景防冷光**：日景/白天场景严禁"冷白光/冰冷蓝光/刺眼冷光"——肃杀凄清氛围转译为"低饱和度影调，青灰色自然漫射阴影，背光面与高光形成自然明暗阶梯，逆光边缘光勾勒轮廓"。违反 = 质检 P1（口径见 `../../../references/shared-quality-gate.md`）。**★ 光源决策母法挂接（★ 2026-09-08）**：光源描述的完整决策框架以 `../../../references/shared-frame-image-grammar.md` §四光构建清单为准（主光源/辅助光源/阴影区/高光面/曝光行为五项光源地图）——本铁律是其在写实线的强制裁量体现（日景防冷光等口径原样保留，不废不改）。
