## 一、总纲：两条工作流 + 一条体感标准

任何一场戏，自上而下按"决策影响越大越靠前"排序：

```
①故事/内容 → 实际上发生了什么（分格剧本）
②主镜选择 → 想让观众看到什么（每段"必不可少"的画面）——§二
③机位与轴 → 用正反打/轴向接顺、不跳轴——§四
④景别      → 内容+渐松渐紧+视角+插入+节奏——§五
⑤视高      → 默认一人高，需要时主观视线/正反打/构图/节奏变化——§六
⑥构图      → 层次/疏密/带/视觉焦点——§七
⑦空间感    → 露更多面+更多远近层次——§十
⑧运动      → 动势（色块方向）做衔接与节奏——§十一
⑨审查      → 三原则检验（观众真的看到了吗）——§三
```

**两条工作流**（按戏的性质二选一或混用）：
- **工作流 A · 从机位推出画面**（多人对话戏，先搭框架再定稿）：排布人物走位 → 拉出轴向 → 排标准机位（正反打×双人/单人）→ 编号 → 按内容做机位变种（松紧/角度微调）→ 补插入镜头 → 有机组合。
- **工作流 B · 从画面推出机位**（情绪戏/主镜戏，先有画面再反推）：读通剧本 → 归纳段落 → 用"必不可少"的画面概括每段=主镜 → 细化主镜构图 → **反推**轴向与机位（保证不跳轴、接得顺）→ 补连接镜 → 检查衔接 → 强调与弱化。

**体感总标准一句话**：顺畅=观众舒服；不顺畅=水箱/节奏出问题。轴呼不呼应、目光往哪落、地平线在哪、色块往哪走，全服务于"顺畅"。
**哲理**：简单的原理才能做复杂的应用；靠画面讲故事，不靠机位/轴向——机位和轴是理性工具，画面是感性，最被观众记住。

## 二、主镜工作法（★ 虾系此前缺失，本节为新增决策层）

- **主镜**：讲述一段故事"必不可少"的所有画面的集合；连接镜=主镜之间用于顺畅衔接的镜头；插入镜头=特写空间某局部（道具/反应），**不算新主镜**。
- **五步**：①通读剧本、理解本场在全片的作用 → ②用一个画面概括"核心瞬间" → ③把冗长对白**归纳提炼**为一条条可放映的画面内容（无具体内容的对白删除，一条内容=一个画面）→ ④每条归纳配一个必不可少的画面 → ⑤全部主镜合起来=本场主镜。
- **执行纪律**：主镜阶段只画草图，只求大略取景与元素排布，**不纠结左右角度**（左右才影响轴向，属下一步）；精力聚焦十几张主镜而非几十个镜头；主镜定稿后再反推轴向与机位（工作流 B 下半段）。
- **景别/视角选择要点**（主镜层）：进入新空间=全景+角色视角；关键道具=标记性特写；动作大=较松景别；情绪反应=特写；"最伤感/最关键的瞬间"=主镜中的主镜，单独精雕（留点东西比空无一物更伤感——如人消失后只剩一件遗物的特写）。

## 三、叙事三原则与四步流程

**三原则（大白话）**：①实际上发生了什么（剧本写了谁干什么）②想让观众看到什么（同一瞬间发生很多事，只能切其中一个元素=如何选择画面）③观众实际上看到了什么（检验是否真的被看到——看到画面≠接收到信息）。

**四步流程**：①**分格**（把剧本内容一格一格分开，谁说话一格、谁反应一格）→ ②**选画面**（谁说话切谁、谁反应切谁且多为特写、大动作切较全画面）→ ③**接顺**（衔接检查：跳轴/衔接问题）→ ④**强调重点/弱化非重点**。

- **强调=镜头变多**：全场重点反复强调（事件本体→A 反应→B 反应→事件更强化→结果特写→C 反应→收束），镜头越多观众越接收"这里是重点"；铺垫型重点（如某角色隐藏技能）在揭晓前逐层切反应铺垫。
- **弱化=做减法**：非重点过程删反应镜、对白掐头去尾一长段全景带过，突然切特写反衬真正重点。
- **避免流水账**：普通剧情用自然克制易理解的常规镜头，不强行炫技——与虾镜 4 问不冲突（4 问管"切不切"，本节管"切了怎么让观众看见"）。

## 四、轴向体系与跳轴（何时可跳 + 怎么补救）

**五机位公式**（一轴两角色）：双人正反打×2 + 单人×2 + 侧面全景（正面拍双人）。每场都套五机位=一个味儿，要**基于体系做变化**（冷一点=机位远/侧/长焦压缩；正一点=压着轴拍取对称；无互动过渡直接省略切镜）。

**形状分类**：**i 型**（两角色一线，机位同侧正反打，最基础）→ **l 型**（三角色 1+2 分组，两组间拉轴，机位四类；**换轴借"同时在两轴正确一侧"的机位衔接**）→ **a 型**（三方对峙不分组；选轴侧取"与另一轴正确一侧交叠尽可能大"的一侧，扩大机位自由区）→ **a2 型**（所有机位放进三方中间三角区，自动全轴正确侧；须补一个侧面全景交代方位）→ u/o 型（会议室延伸，少用）。**实际主力=i 型与 l 型**。

**判断跳不跳（核心）**：跳到某机位是跳轴与否，**看这条轴上有没有呼应关系**——落到"具体这条轴的呼应"判断，不笼统看位置。

**三类可接受的跳轴（学习期守死，创作期按需牺牲轴向）**：
1. **照顾故事**：人设不允许过渡（如面瘫角色无反应镜可加）、视角/节奏需要——用"**对联**"补救：让切出镜的脸朝向与切入镜的脸朝向形成视线呼应（像正反打），生硬感即消；
2. **构图好看**：守轴拍到的背景难看时，宁可跳轴保画面（小津式跳轴，观众可适应）；
3. **故意做效果**：氛围/光线变化对应剧情转折；段落感（跳一下=另起一段）；制造混乱提速（追逐戏）；强调关系特殊性（跳轴+亲密构图=暗流涌动）。

**与 shared-spatial-blocking 的接法**：决定跳轴后，越轴的**几何执行**（机内过轴/中立镜过渡/剧烈反弹重立轴）与拓扑图登记仍按该单源走——本节回答"该不该跳"，那边回答"怎么越不出错"。

## 五、景别六点（决定景别的六个方面）

1. **基于内容**：看表情反应→特写；大身段动态→较全镜头（此条主要作用于主镜景别）。
2. **避免两坑**：**同景别构图**（正反打两镜景别角度几乎一样=像没切、人瞬移；解法：插"远处来的东西"、或把一方切近、或让两镜角度/环境差异明显）；**拉抽屉**（全→特→全反复不顺滑）。
3. **渐松渐紧（渐进）**：默认连接主镜的手法——收获顺畅+情绪变化（渐紧=紧张升级）。
4. **视角**：机位跟定一个角色（该角色近景+其所见多为远景），以某角色视角切换**不算拉抽屉**。
5. **插入镜头**：全→特→全看似拉抽屉，中间插的是插入镜头（桌上枪/盒中宝石/旁观者反应）其实就是"渐进+插不同类型镜头"的设计体系；旁观者反应镜=重要提示手法（"那边要出事"）。
6. **节奏**：用景别给段落做节奏——渐进到某点突然切全景松下来=观众感到"新段落"；声音也可做节奏（不切镜，用一声大喊换挡）。

## 六、视高六点（取代俯/仰/平三分法的决策依据）

**视高=摄像机相对人物所站平面的高度**（连续变量，非三档）。六个决定依据：
1. **正反打**：双人同框要两人脑袋都在画内（身高不等时自然带出俯仰）；
2. **主观视线 POV**：机位贴角色眼睛高度（往上看=仰拍素材）；
3. **观众视角**：想让观众代入谁，就把机位架在谁的睑高（＝观众的眼睛）；
4. **好看的构图**：要前景丰富选高视高；要辽阔感降视高、地平线压低、上方留天空；
5. **切镜顺畅**：相连镜头地平线位置（天空/地面比例）不要差太多（色块跳动=不顺），但**也不要完全一样**（观众感觉没切镜、人瞬移）；
6. **节奏变化**：整场平拍突然一记仰/俯=告诉观众"要出事了"。

**默认律（★ 重要）**：画面未被其他规则约束时，视高统一定在**"一人高"**（观众站在场景地面用自己的眼睛看）——先定全剧/全场的"一人高"基准，只逐个分析偏离它的镜头。

## 七、构图四规则（元素有序排布）

> 构图目标：①好看 ②用图形心理感受表达含义。形状思路（三分法/黄金螺旋/三角形/S/Z 型）仅适用静态画且自由度低，作了解。

1. **层次（纵深）**：前景→近景→中景→远景→超远景，用平面表现立体；不一定要远近，有空间感即可。
2. **疏密（=对比）**：大小对比（海面/冰川/小船）、松紧对比（三棵树挨近第四棵远开——"咚-咚-咚-（顿）"比"咚咚咚咚"有趣）、画面节奏（整齐中放一个异类）。
3. **带（上/中/下三带）**：人脸稳定放**中带**（人眼横长，上下跳宽容度低、左右跳宽容度高）；强调某角色可让其独占一条中带偏上；人人各占一带=散乱无重点。
4. **视觉焦点**：用引导线把视线引到焦点；切镜时控制眼睛停留位置保证顺畅；遇避不开的强引导线（把视线引向画外）→用前景形状挡一下让视线折回。

## 八、视觉焦点与眼线（顺畅的技术底座）

- **视觉焦点=观众第一眼盯住的位置**。四类形成元素：①**运动**（动的东西）②**人脸（核心是眼睛区域）**③**被引导**（引导线指过去的东西）④**镜头时长**（过长焦点游走失控，过短内容不清）。
- **眼线=眼睛在画面中的高度**。三用途：①判断构图/控制焦点（相连镜头眼线高度差不能忽高忽低）；②暗示身高（切入时视线要往下找眼=此角色矮/坐）；③暗示身份高低（现代观众渐失效，慎用）。强元素会抢焦点（前景小猫抢后景戏），布景时让其他元素让位。
- **顺畅原理**：观众眼睛停在中带，切镜后横向微移即看到新内容=顺。
- **焦点惯性衔接（★ 打戏/动作戏利器）**：焦点随运动快速移向画右，切下一镜时观众眼动有**惯性**——让新镜头的人物**先不入画，等焦点到达右侧后再从右侧入画**，接得极顺。
- **打戏的热闹节奏**：流畅靠焦点控制，热闹靠元素（微震/火花/亮光）；元素不够热闹就让视觉焦点"跳"（观众跟不上=眼花缭乱=好酷）。**铁律：先有顺畅底盘，只在顺畅段落中个别瞬间跳**——整场都跳观众没耐心；个别跳点形成段落感与节奏感。切出时焦点在左，切入镜主体也放偏左——分镜是逐帧对接的，不是随手画的。

## 九、透视两原则

1. **地平线等高原则**：地平线穿过画面中所有站立者的**同一身体高度**（都穿脖子=都等高）；穿一人腰穿另一人膝=观众误判小矮人；一排人穿同一高度怎么加人都不乱；**最易错的是平着拍的多人镜头**（大仰大俯反而安全）；高处/低处人物的地平线要按相应身体高度对齐。
2. **透视大小=视距×开角**：透视大（近大远小明显、压迫感）=近视距+大开角（广角）；透视小（空间压缩）=远视距+小开角（长焦）。视距与开角通常反向联动以保持构图不变，但空间感已变。
3. **希区柯克变焦**：同时拉远视距+缩小开角，主体大小不变、背景透视骤变=内心冲击/眩晕。

## 十、空间感公式

**空间感=立体感（露更多面）+纵深（远近层次）**。判定：数画面露了几个面、有几层远近。
操作：把房间当立方体——正对只拍到一面，机位侧挪/抬高/压低露两三面；用大开角把门推远多露地面侧墙；"面前只有一堵墙"时改机位角度挂相邻两面（仰拍带屋顶/俯拍带地面）；用装饰物（挂画/锅瓢/吊顶）强调面的关系；前景加物体**稍加模糊**示前层，中景加物件（炉子/鞋柜）建参照系补层次。

## 十一、动势（运动的方向化设计）

- **动势=把复杂运动眯眼抽象成色块在画框中的方向运动**（上下左右）。
- **衔接法则**：前镜色块向右、后镜也向右=顺；右接左=咯噔。**衔接的是方向不是主体**——中间镜头不必同一主体，方向顺即可。
- **节奏法则**：剧情转紧张时不再完整展示动作，**让相邻镜头动势反向**=节奏感（"完整展示+剪短"未必有节奏，反向才出）。
- **创作两层法**：①先把整段动作当色块规划移动方向（跑近→交会→分开→追逐）→ ②再叠加每个角色的具体 pose/动作——拆层后复杂打斗难度大降。
- 与 `shared-transitions.md` 的关系：六式标注"式别名"，动势方向是判断"这一式接得顺不顺"的底层依据；与虾镜锚点纪律不冲突（锚点管位置名词，动势管方向规划）。
- 与 `shared-camera-movement.md` 的分工：**动势管"镜头间的方向化衔接"（色块往哪走、接得顺不顺），单镜本身选哪种运镜（推拉摇移环绕…）归中立运镜层**——二者正交，本层不定义运镜类型。

## 十二、视角（POV · 拍摄层面）

- **视角=反复使用【角色的反应】+【角色看到的画面】两类镜头**，左右穿插即可把观众按进该角色内心——即使零表演（豆豆眼）观众也能脑补情绪。
- **关键纪律**：进入某角色视角后，**开场不能拍该角色看不到的东西**（如从门外者视角进入，不能先拍屋内坐着的人）。
- 一场戏可多视角分段（前段带 A、中段带 B、末段全客观）；不是所有戏都要视角，这只是手法之一；拍摄视角≠故事视角（两回事）。

## 十三、蒙太奇

- **底层原理：两个镜头（或两元素）并置，产生单独观看都没有的新含义**（库列肖夫效应：同一张中性脸+汤=饿、+死者=悲、+女人=欲望）。
- **前提铁律：并置的基础镜头必须中性**——镜头自身含义太强会污染并置效果。
- 应用维度：画面×画面（动作/尖叫/刀/局部特写拼出"惨"）、两条故事线并置（洗礼交叉剪辑，张力靠声音积累）、声音×画面（正配/反配/对位法——反配=画面残酷配轻快音乐+歌词第二层；对位=音乐与画面平行各自成立）、声音×声音（两段声音并置出第三重含义）。镜内蒙太奇（同画面两元素并置）作了解。
- **总纲句**：手法只是手法，重要的是用手法来说些什么——先有要说的内容，再选手法。

## 十四、交付自检（老白手艺清单，拆镜/分镜设计完成后过一遍）
