# 全片质检门禁 P0~P2 · 口径总纲（横切单源）

> **★ 定位**：全部交付物（分镜/视频提示词/资产/合成）的**三档分级口径总纲**——各环节专项审计引用本文件的定义，本文件不替代专项审计。
> 来源：从 P0~P2 独立审查门禁与声音三层架构蒸馏并适配 xia-boss 体系（2026-09-04 采纳）。
> 分工：P0 机械项已由 `scripts/check-fidelity.py`/`check-assets.py`/`check-scenes.py` 覆盖的，以脚本输出为准；本纲管**口径统一**（什么错算什么档）与**无脚本覆盖的人工语义项**。

## 一、三档分级定义（全片通用）

| 档 | 定义 | 处置 | 通用违规项 |
|---|---|---|---|
| **P0 致命缺陷** | 阻断交付 | 修复后重新过全检 | 单组时长 >15s；台词被篡改/删减（逐字保真破约）；严重跳轴或空间方位无故反转；角色核心五官/服装跨镜漂移；引用行悬空（引用了不存在/未生成的资产图）；混入乱码或后台字样；组间接续状态断裂 |
| **P1 结构缺陷** | 交付前必须处置 | 重构对应镜/段 | 镜头时长全篇雷同无快慢节奏；打斗缺受力过程（光污染对波——纯光球互撞无接触/因果）；光源无物理来源或日景假冷光；缺 2~3 秒近景对招（高速档）；金句后无气口；衔接式缺式名或动机 |
| **P2 审美缺陷** | 记录留痕，用户取舍 | 优化建议 | 空镜过多或无戏剧任务；形容词空泛未转译物理事实（"极具压迫感"类）；声音层次不分明；装饰抢主视觉 |

## 二、声音三层架构与混音电平（写进音效设计字段 / H3 overall_soundscape）

$$\text{第一层：对白清晰度 (0 dB)} > \text{第二层：动作音效 SFX (-6 dB)} > \text{第三层：环境声与 BGM (-14 dB \sim -18 dB)}$$

- 对白永远最高清晰度优先级；动作音效（骨裂/破风/撞击）不得遮盖人声；
- BGM 在激烈打斗或对白爆发时**自动避让（Ducking）**——提示词写法："BGM 随对白自动压低避让"或 H3 soundscape 中注明 ducking 行为；
- P2 判定口径：音效设计字段里三层混写不分、或出现"BGM 盖过台词"类描述。

## 三、光随动作互动（★ 2026-09-05 新增）

光不是静态布景。**画面里有运动时，光必须参与运动**，否则即为 P2「装饰未服务动作」类缺陷：

1. **有运动就有光影变化**：窗光/门缝/车灯/手机屏/云/雨/尘埃/草/布料/呼吸，随人物动作产生移动的高光、阴影、粒子与明暗过渡——**禁止**人物穿过光束而光影纹丝不动；
2. **光变绑定声变**：光与声的变化由**同一个动作**触发（见 `shared-performance-realism.md` §十二「动作-光-声绑定」）——一次接触 = 一个可见后果 + 一个可听后果，禁止同一动作拆成三条无关描述；
3. **光源必须有物理来源**：与既有 P1「光源无物理来源或日景假冷光」同律——小房间/家居/日常场景**禁止**强行使用硬质侧顶光，除非存在可信光源（裸灯泡/高窗/台灯/门缝/霓虹/车灯/手机屏/手电）。夜景与年代院落的可读人脸须来自有动机的灯笼、烛火、门窗溢光、地面反弹或弱实用光（详 `shared-performance-realism.md` §六 摄影条件一致）。

## 四、画面语法质检口径（★ 2026-09-08 新增，横切单源挂接）

> 决策框架全文见 `shared-frame-image-grammar.md` §七；本节只登记质检口径与定档。适用于所有资产类/首帧/视频提示词的交付与投喂质检。

1. **无因不造（P1 处置）**：提示词不得凭空发明轮廓光、霓虹、雾、眩光、浅景深、破损、污渍、遮挡、不完美——每项须有物理或叙事理由；检出的无因装饰项 = P1，要求补来源或删除。
2. **删词仍能成立（P1 处置）**：删掉相机品牌、胶片型号、分辨率、`masterpiece / epic / stunning / award-winning / 8K / highly detailed` 类词后，剩余文字仍须描述出具体故事、动作、地点、机位关系、有来源的光；删完即空 = 提示词只是装饰词堆，P1 退回重写。
3. 本期**只做人工口径**（交付自检逐条过），暂不写入 check-fidelity.py 机械检查（拍板点 C：先口径后脚本，口径验证稳定后下期固化进脚本）。

## 附录 A · 场景声音锚点库（★ 2026-09-05 新增）

> 来源：从「影词精磨」style_patterns.md Sound Design Library 蒸馏，通用化改写。
> **分工**：§二 声音三层架构管「**怎么混**」（电平与避让），本附录管「**选什么声**」（场景锚点素材）。两者并行：先按本附录选 2~4 个锚点，再按 §二 分配电平层次。
> 通用规则：**默认无配乐**（用户明确要求或剧情必需源音乐除外）；优先具体有源声，禁 `dramatic music`/`史诗BGM`/`悲伤钢琴` 类空泛配乐词；用声音标记转折（手机振动/杯响/门锁/监护仪滴声/雷/引擎启动）；震惊时声场可发闷后突出一声；结尾留声音尾巴；若确需音乐，写角色（低沉大提琴持续音/远处收音机歌声/单音延音）而非类型标签。

| 场景 | 声音锚点（选 2~4 个） | 典型写法（占位符） |
|---|---|---|
| **医院/医疗走廊**（死亡通知/等待/诊断/克制悲伤） | 荧光灯电流声、远处心电监护仪滴声、护士鞋底擦过抛光地面、轮椅轮轴轻响、帘轨或金属托盘、空调低鸣。**噩耗后声场发闷，只剩呼吸与一声监护仪** | 环境声只有医院空调低鸣、远处心电监护仪规律滴声、护士鞋底掠过地面的轻响；噩耗落下后，走廊声场瞬间发闷，只剩他的呼吸。 |
| **雨夜车内**（分手/表白/压迫/孤独） | 雨打车窗与车顶、雨刷胶条刮玻璃、发动机怠速低频、转向灯或双闪咔哒、被雨柔化的远处车流、安全带或手机摩擦、**熄火后的突然安静** | 声音以雨刷刮过挡风玻璃的低哑摩擦声为节拍，发动机怠速在车厢里低频震动，台词间隙只剩雨水敲打车顶。 |
| **深夜家居/公寓**（电话/悲伤/悬疑/孤立） | 冰箱低频、手机听筒电流底噪或木面振动、隔墙邻居脚步、远处电梯或楼道声、（需时间压力时）钟摆、衣料摩擦与赤脚触地、**坏消息后房间突然空掉** | 电话里的声音带着轻微电流底噪，房间里只有冰箱低频声和远处电梯运行声；挂断后，空间忽然空下来，只剩她压在掌心里的破碎鼻息。 |
| **厨房/居家亲密**（尴尬亲密/家庭张力/安静分手） | 咖啡机滴落、陶瓷杯轻碰台面、水管低鸣、筷子碰碗、刀触砧板、冰箱门封开启、蒸汽与餐具细响 | 无配乐，只有咖啡机一滴一滴落下、陶瓷杯轻碰台面的细响，以及两人刻意压轻的呼吸。 |

| **灾难/大场面人群**（群体压力/恐慌/公共危机） | 警报、应急广播、金属扭曲、玻璃或餐具滑落摔碎、**人群声作为质感而非糊墙**、**主角声音必须穿透人群**；主角看见关键人/物时人群声短暂退出 | 警报和广播交叠，金属船体发出低沉扭曲声，盘子沿倾斜地面滑落摔碎；当她看见孩子时，人群声短暂发闷，只剩她的呼吸和舱门警报。 |
| **产品/车/质感物件**（品牌质感，非广告） | 车门厚重关闭的共振、点火由短促转稳定低吼、皮革座椅摩擦、纸张折叠或笔尖刮擦、轮胎压过碎石、表冠咔哒/金属表带位移/快门 | 车门关闭声厚重而干净，外界风声被瞬间切断；点火时机械启动声由短促转为稳定低吼，皮革座椅发出细微摩擦。 |
| **无鬼怪悬疑**（空间与暗示制造的恐惧） | 门锁落下、另一个房间的手机震动、地板轻响、冰箱低频、远处电梯、**呼吸变得过响**；**禁用突脸惊吓与响亮惊吓音**（用户明确要求除外） | 门锁落下后楼道声被切断，屋里只剩冰箱低频声；卧室深处忽然传来极轻的手机震动，嗡的一声后又停住。 |
| **武侠/动作**（谨慎使用，动作本体规则见打戏外协模块） | 雨打竹叶、衣袖破风、**金属碰撞须对应清晰接触点**、踏水或落木的脚步、出鞘摩擦、闪电后延迟的雷声 | 雨打竹叶声铺满背景，每一次金属碰撞都对应清晰接触点；剑锋出鞘半寸时只有一声干净鞘响，雷声延迟半秒炸开。 |

**主观声音透视弧**（专注/认出/悲伤/震惊/亲密时，同一空间的声音感知发生变化）：

```text
客观环境 -> 感知收窄 -> 近景细节（呼吸/衣料/接触/吞咽/克制的人声） -> 破裂或屏息静止 -> 环境回归
```

- 收窄是**降低或柔化远景环境声，不是完全抹除**（除非画面内有可听见的成因）；
- 转变必须由**注意力或画面内事件**驱动，禁止无由来的水下闷响、全静音或环境不可能产生的音效。

## 附录 B · 通用负面约束分类库（★ 2026-09-05 新增）

> 来源：从「影词精磨」style_patterns.md Negative Constraints 蒸馏，通用化改写。
> **分工**：**战斗段的负面约束权威源是 seedance-combat-prompt 外协提示词自带负面词 ∪ 负面四禁（契约见 `shared-fight-dispatch.md`）**，本附录只覆盖**通用/非打斗场景**；战斗段与本附录冲突时以外协负面词为准。
> 使用原则：① 先用正向句声明目标，负面词只作护栏；② 按场景风险取**最小可用集**，禁止堆叠长列表；③ 模型对负面语言不友好时，把结果关键的负面改成正向指令；④ 提示词接近时长对应字数上限、或用户要求极简、或场景风险低时，**省略或缩短**。

**通用核心（默认底座）**

```text
负面约束：不要字幕水印，不要背景音乐，不要脸部畸变，不要多余手指或肢体，不要卡通感。
```

（画面无可见手部或全身时，省略手/肢体类约束。）
