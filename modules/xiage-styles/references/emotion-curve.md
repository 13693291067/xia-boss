# 全片情绪曲线（自动计算与可视化 · 独立调度文件）

> 来源：前半程创作基准方法论蒸馏（★ 2026-09-03 集成）。**虾格"剧本理解分析"八项完成后、③影片基调方案推荐前，加载本文件自动执行一次。** 该图让用户直观看见全片呼吸、升级、高潮、反转和余震，是③基调拍板的定量依据，也是分镜线情绪段标注的数据源；它不是资产母板，不替代剧本确认。

## 1. 触发与范围

- **触发时点**：八项分析第③步（起承转合与高潮位置）完成后即具备原料；在向用户给出③基调候选方案**之前**完成计算与展示。
- **计算范围**：**整剧级**曲线算一次（短剧=全剧弧线）；分镜阶段按集取对应弧段消费（见 §5）。多季/多部续作各自重算。
- **不单独询问、不单独设确认门**：曲线与③基调候选方案一起展示、一起拍板（流程不加门）。
- 节拍实质变化（幕结构/转折/峰值/结尾改动）→ 自动重算新版；只改台词措辞且节拍不变 → 复用。新版本另存，不覆盖已展示版本。
- 计算失败 → 先给出文字节点表，不阻塞三步向导。

## 2. 曲线计算规则

一条复合曲线表示"**观众紧张度 / 情感冲击度**"，范围 0.0—10.0。

- 节点来自**真实戏剧变化**，不机械等于每场戏：外部威胁、重要决定、失败、真相揭露、身体危险、关系反转、假性安全、释放、余震都可成为节点。
- 常规 **8—14 个节点，最多 16 个**；过多时合并相邻且同方向的节拍。
- 按故事顺序从 1 开始连续编号；每个节点 = `序号. 短名称 + 一位小数强度`。
- 同时标记：**幕区段**（按剧本真实幕结构分区并写幕名）、**全片最高峰**、**重要反转**、**结尾余震**；开头与结尾不强制归零。
- **至少保留 1 个真实呼吸区**（紧张度明显回落的蓄力段）；没有文本依据时不凭空制造释放。
- **BGM 重点**只标需要推动/反转/连接/积蓄/释放情绪的节点，不把所有节点都列为音乐点。
- "呼吸区"和"BGM 重点"必须**复用主曲线节点的编号与短名称**，不新造未编号事件。

## 3. 呈现方式（按执行环境能力降级）

1. **首选**：执行环境自带可视化能力时，内联渲染 16:9 曲线图——深炭灰底、低对比灰网格、深灰蓝→低饱和琥珀→暗红的强度渐变曲线；含标题《{{项目名}}》全片情绪曲线 + 副标题（观众紧张度/情感冲击度 · 0—10）、纵轴刻度（平静/不安/窒息）、幕区分区、节点标签（`序号. 短名 数值`，最高峰/反转可加 ≤6 字小注）、底部三行（呼吸区 / BGM 重点 / 全片原则一句）。
2. **次选**：调用项目生图渠道生成同规格信息图（提示词按 §3 规格拼装，infographic-diagram 类，无人物无剧照无水印）。
3. **兜底**：Markdown 节点表 + 幕区/最高峰/呼吸区/BGM 重点/全片原则五项文字清单——**节点表在任何情况下都必须随文字交付**，图只是可视化增强。

## 4. 落盘契约（★ creation-direction.json 扩展）

```json
"emotion_curve": {
  "scale": "0-10 观众紧张度/情感冲击度",
  "acts": [{"name": "第一幕·建置", "node_range": [1, 3]}],
  "nodes": [{"no": 1, "name": "开场", "intensity": 3.5}],
  "peak": {"no": 8, "note": "全片最高峰"},
  "reversals": [{"no": 5, "note": "关键反转"}],
  "breathing_zones": [{"no": 4}],
  "bgm_focus": [{"no": 5}, {"no": 8}],
  "principle": "一句全片导演判断",
  "chart_image": "outputs/emotion-curve.png 或 null"
}
```

- 节点表是**权威数据**，图是呈现层；下游只消费节点表。
- 拍板后随 handoff 同步；分镜阶段经 `outputs/creation-direction.json` 读取，与 `tonal_direction`、奇观/克制清单同源同批。

## 5. 下游消费（只登记，不在本模块展开）

| 消费方 | 用法 |
|---|---|
| storyboard-cinematic §1.8 基调吸收 | Stage 1 节拍表"情绪段"标注按曲线强度分段（平缓/升温/高潮/回落 = 曲线斜率与绝对值）；段边界对齐节点；BGM 重点节点 → 该段声音设计/音乐取舍（其余留白） |
| xiajing-episodes 检查点 A（纪律 16） | 拆镜方案情绪段标注 + 基调轨划分引用同一份节点表，两线口径一致 |
| 全片原则 | 写入分镜交付文档顶部，作为节奏争议时的仲裁依据 |

## 6. 纪律

1. 节点强度必须有文本依据（该节点对应的剧情事件），禁止"看起来该有个高点"式编造。
2. 呼吸区无文本依据时，如实输出"无呼吸区"并在 principle 里给出结构风险提示（如"全片持续高压，观众疲劳风险"），由用户拍板是否调整剧本——**不改戏**。
3. 曲线与③基调一起拍板：用户确认基调即视为确认曲线；只对曲线有异议时，按 §1 重算规则处理。
