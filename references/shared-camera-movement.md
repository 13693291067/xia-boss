## 一、三轴判别法（辨任何一种运镜，先问三件事）

任何一种运镜，本质是回答"三轴谁在动"：

1. **机位（摄像机本体）动不动？** —— 沿轴向前/后 = 推/拉；水平平移 = 横移；垂直升降 = 升降；绕圆/弧轨 = 环绕。
2. **镜头（朝向/角度）动不动？** —— 水平转 = 摇移（极快 = 甩摇）；垂直转 = 俯仰；绕光轴滚 = 旋转。
3. **焦距动不动？** —— 只改焦距、机身不动 = 变焦（极快 = 急推）；机位动 + 焦距反向同动 = 希区柯克变焦。

三轴全不动 = **静态镜头**。抓住这三问就能把 15 手法各归各位，也不会把"推拉"和"变焦"搞混。

## 二、15 手法总表（中文名 · 三轴本质 · 适合叙事 · 易混警示）

> 概念层只定"是什么 / 怎么选 / 易混"，不写英文；**英文拼法统一见 §八对照表**。示例角色一律占位（角色A/目标）。

| 中文名 | 三轴本质 | 适合表达什么 | 易混警示 |
|---|---|---|---|
| 静态 | 三轴全不动 | 安静文戏、情绪/氛围定格 | 多数静态场景直接文生视频即可，别硬加运动 |
| 推镜 | 机位沿轴向前进 | 逼近目标、聚焦、压迫 | 是**机位在动**，不是变焦 |
| 拉镜 | 机位沿轴后退 | **宣告段落结束**、揭示环境 | 与变焦区分：拉镜改变空间关系 |
| 摇移 | 机位不动·镜头水平转 | 横向扫描、交代一批信息 | 机位不动；机位平移那是横移 |
| 甩摇 | 摇移·极快（动态模糊） | 高速接应、动感、时空跳转 | 本质是摇移的加速，可后期掐速 |
| 变焦 | 机位不动·只改焦距 | 放大缩小、空间感不变 | 机身不动，透视不变 |
| 急推 | 变焦·极快 | 情绪爆发的冲击一瞬 | 是变焦不是推镜（机身不动） |
| 横移 | 机位水平平移 | 跟着角色左右走、平行揭示 | 机位在平移，镜头朝向不变 |
| 希区柯克变焦 | 机位动 + 焦距反向、主体不变背景变 | 恐怖/眩晕/心理压迫 | 判断定义详见老白课 `§视高/透视 :114` |
| 旋转 | 机位固定·绕自身光轴滚 | 眩晕、失衡、空间错乱 | 绕自身轴；绕被摄那是环绕 |
| 环绕 | 机位沿圆/弧轨绕被摄 | 交代前后左右大量信息、人物关系 | 幅度/圈数有代价，见 §五 |
| 追踪 | 机位锁定跟随角色 | 追逐/奔跑的紧张感 | 跟拍运动主体，锁定不放 |
| 俯仰 | 机位不动·镜头上下看 | 角色气势、目标之高 | 镜头在转；整机上下那是升降 |
| 升降 | 机位垂直升降（摇臂） | 上帝视角、揭示全貌、渺小感 | 机位在升降；镜头上下看是俯仰 |
| 随机晃动 | 机位不规则抖动（手持感） | 心理不安、纪实、打斗激烈 | 幅度别盖过主体可读性 |

## 三、叙事目的 → 运镜反推（先定"要让观众感到什么"，再选运镜）

| 想让观众感到 | 选 |
|---|---|
| 安静定格 | 静态 |
| 段落收尾 | 拉镜 |
| 逼近 / 聚焦 | 推镜 |
| 恐怖 · 眩晕 · 心理压迫 | 希区柯克变焦 |
| 气势 · 目标之高 | 俯仰 |
| 交代大量空间 / 人物关系 | 环绕（幅度见 §五） |
| 追逐 · 奔跑紧张 | 追踪 |
| 心理不安 · 打斗纪实 | 随机晃动（手持） |
| 全局 · 渺小 | 升降（大俯角） |
| 情绪爆发冲击 | 急推 |
| 高速接应 · 时空跳转 | 甩摇 |

## 四、易混对比速查（防选错 / 防写错）

| 易混对 | 判据 | 结论 |
|---|---|---|
| 推拉 ↔ 变焦 | 机位动不动 | 推拉=机位移动（空间变）；变焦=机位不动只改焦距（空间不变） |
| 推拉 ↔ 希区柯克 | 是否两头反向同动 | 只动一头=推拉或变焦；机位+焦距反向同动、主体不变=希区柯克 |
| 摇 ↔ 横移 | 机位动不动 | 摇=机位不动镜头水平转；横移=机位整体平移、朝向不变 |
| 摇移 ↔ 甩摇 | 转速 | 慢=摇移；极快带动态模糊=甩摇 |
| 俯仰 ↔ 升降 | 谁在动 | 俯仰=镜头上下看（机位不动）；升降=机位垂直升降 |
| 旋转 ↔ 环绕 | 绕谁的轴 | 旋转=绕自身光轴滚；环绕=沿圆轨绕被摄 |

## 五、环绕幅度代价提示 + 打戏段边界（★）

**环绕幅度代价提示（借鉴打戏 R31 的普适观察，非禁令）**：满圈 360° 与螺旋上升易致观众方向感丢失、画面眩晕；交代空间与人物关系**优先 ≤180° 半圈或缓弧**，幅度小、速度慢、主体稳。**文戏段仍可自行选满圈，此处仅提示代价、不构成禁止。**

**打戏段边界**：战斗段（打斗/对决/追杀/突围/守护/群战，或用户点名）运镜由外协 `modules/seedance-combat-prompt/` 的 **R31** 管辖——R31 明确禁 360° 满圈与螺旋上升、仅对峙蓄力段（无攻防接触）可谨慎用 ≤180° 半圈、优先小幅度线性运镜。**本层在战斗段整体让位，R31 与打戏模块一字不改**；本层的中立"代价提示"不下沉为打戏禁令，打戏的"禁"也不上收为文戏禁令。混合段（战斗里穿插文戏反应镜）：只有登记进 `battle_segments` 的段受 R31，相邻文戏反应镜仍走本层。

## 六、兜底写法

主口径：运镜写成镜头内**自然的动作描述**（各方言文件的英文句式），而非句尾堆标签。
兜底：模型反复不配合运镜术语时，才把连续运动**拆成分秒指令**（如"1 秒向左 / 2 秒向上 / 3 秒向后"）。这是降级手段，非首选。
