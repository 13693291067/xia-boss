# 空间与人物连续性要求（独立调度文件）

> 来源：剧本转分镜方法论（§15），2026-08-21 并入虾镜。**做分镜脚本与制作时，对照本文件做连续性校验。**

## 0. 定位

所有分镜必须保持**严格连续性**——空间连续性以场景资产（scene-assets.md A 全景鸟瞰图）为据，人物连续性以角色资产（character-assets.md）为据。**制作/分镜验收时逐项核对**。

## 1. 人物连续性

- 人物外貌不变 / 年龄不变 / 发型不变 / 服装不变 / 道具携带位置不变。
- 受伤位置不变；污渍、雨水、破损和血迹状态连续。
- 人物进出画面方向合理；人物视线关系正确。
- 左右位置不能无原因互换。

## 2. 场景连续性

- 建筑结构不变 / 门窗位置不变 / 道路方向不变 / 家具和道具位置不变 / 光源方向不变。
- 时间变化合理 / 天气变化合理 / 地面干湿状态连续。
- 破坏状态逐步累积。
- 不得出现同一场景前后结构不同的问题。

## 3. 动作连续性

- 上一个镜头动作结束位置，应与下一个镜头动作开始位置一致。
- 人物手中道具不能无原因消失或换手。
- 人物奔跑、转身、开门、跌倒、攻击、躲避等动作方向必须连续。
- 正反打镜头应遵守视线和轴线关系。
- 除非为了表达混乱、眩晕或空间异常，否则不要随意越轴。

## 4. 调度方式

| 时机 | 谁 | 动作 |
|---|---|---|
| 拆分镜头 / 写分镜字段 | 虾镜（分镜脚本 Tab） | 加载本文件，镜头间连续性自检 |
| 制作首帧 / 视频 | 虾镜（制作 Tab） | 加载本文件，跨镜伤情/道具/服装/光源状态校验 |
| 验收 | 虾镜 | 逐项核对 §1/§2/§3，不连续则回退修正 |
