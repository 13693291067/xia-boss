# 固定风格提示词库（FS）规范

> 来源：剧本转分镜方法论（第一阶段补充，2026-08-21 并入虾格）。固定风格库 = 按「最终影片风格 + 剧本实际天气/时段」预建的**项目级**固定风格提示词库，供虾镜首帧提示词按编号调用，保证同一场景/同一时段的光线与色调跨镜头一致。

## 0. 定位（一句话）

**FS = 每个项目一套的"光线与色调的默认值表"**：虾格创作方向三件套拍板后，按剧本场景的天气与时段生成 12 类固定风格；虾镜每个镜头写首帧提示词时注明「调用 FS-XX」，风格段直接引用该 FS 的光源/色温/色彩/材质参数，不再逐镜重复设计光线。

**★ 数据纪律（强制）**：本文件（skill 内）**只存模板**——12 类编号 + 18 项参数清单 + 生成流程。**具体 FS 数值是项目产物**，写入项目 `outputs/fs-library.md`，**禁止写入 skill / 预设模板**（遵守虾集最高纪律：禁止项目数据污染）。

## 2. 每套 FS 必须包含的 18 项参数（固定框架，逐项填写）

| # | 参数项 | 说明 |
|---|---|---|
| 1 | 画幅比例 | 如 2.39:1 变形宽银幕 |
| 2 | 摄影机质感 | 真人实拍机型号/数字电影机质感 |
| 3 | 镜头质感 | 变形宽银幕镜头/球面镜头、焦外特征 |
| 4 | 曝光倾向 | 中曝光/暗调/明亮，倾向说明 |
| 5 | 主光源 | 光源类型 + 方向 + 动机（太阳/天光/月光/烛火/魔火/灵光…） |
| 6 | 辅光源 | 补光来源与强度 |
| 7 | 色温 | 具体 K 值（如 5600K / 6500K / 3200K 偏冷偏暖） |
| 8 | 色彩关系 | 主色 + 辅助色 + 强调色的关系 |
| 9 | 反差 | 高/中/低反差 + 明暗层次说明 |
| 10 | 黑位 | 暗部色相 + 保留的材质纹理 |
| 11 | 高光 | 高光形态与滚降（柔和/锐利） |
| 12 | 人物肤色 | 该光线下的肤色处理 |
| 13 | 空气状态 | 烟尘/雾气/灵气/魔气/水汽等 + 可见光柱 |
| 14 | 材质表现 | 场景主要材质的真实质感要求 |
| 15 | 颗粒 | 胶片颗粒强度 |
| 16 | 焦外 | 散景/椭圆焦外特征 |
| 17 | 炫光 | 镜头炫光类型与强度 |
| 18 | 禁止事项 | 该 FS 的负面约束（禁死黑/死白/廉价蓝橙滤镜/塑料 CG 等） |

## 3. 生成流程（虾格职责，★ 三件套拍板后、虾塘建资产前执行）

```
① 输入    最终风格三要素（style_instructions / avoid_instructions / style_tag）
          + 剧本实际场景清单（各场景的天气/时段/室内外）
② 分类    把剧本场景归入 12 类编号（只生成本项目用到的类，用不到的注明"本剧未用"）
③ 填充    按最终风格 + 每类天气时段的光源物理逻辑，逐项填写 18 项参数
          · 主光动机必须来自场景真实光源（太阳/天光/月光/烛火/魔火/灵光等），禁止无动机光
          · 色温/色彩关系/反差必须与最终风格三要素一致（风格决定调子，天气时段决定光源形态）
④ 落盘    写入项目 outputs/fs-library.md（禁止写入 skill / 预设模板）
⑤ 登记    项目 data.js 的 xiage 字段记录 fs_library（供虾镜引用与项目台展示）
```

**硬性要求**：
- 每个场景的**同一天气时段只能用同一 FS 编号**，禁止同一场景无原因跳变光线。
- FS 之间的差异必须来自"光源类型/色温/空气状态/反差"的真实物理差异，禁止为凑数编造。
- 首帧提示词引用格式：`固定风格：FS-XX`（如 `固定风格：FS-01`）。

---

## 4. 调度方式

| 时机 | 谁 | 动作 |
|---|---|---|
| 虾格三件套拍板后 | 虾格 | 按本规范生成项目 FS 库（outputs/fs-library.md） |
| 虾镜写首帧提示词时 | 虾镜 | 读取项目 FS 库，按镜头场景的天气/时段注明「调用 FS-XX」，风格段引用该 FS 参数 |
| 项目台展示 | xia-boss 总指挥 | build-data-js.py 读取 outputs/fs-library.md → data.js 的 xiage.fs_library |

**注意**：FS 是**项目级产物**，不是跨项目预设——每个项目因最终风格不同，其 12 类的具体数值不同；本规范（编号 + 参数项 + 流程）跨项目通用。

## 5. 写法示例（占位模板，非项目数据）

```
### FS-02 · 室外白天（压抑天光）
- 画幅比例：2.39:1 变形宽银幕
- 摄影机质感：真人实拍，ARRI Alexa 数字电影机
- 镜头质感：变形宽银幕镜头，柔和焦外
- 曝光倾向：中低曝光，阴天漫射
- 主光源：压抑天光（阴天云层漫射），无直射太阳
- 辅光源：地面反光，低强度冷青
- 色温：6500K 冷灰
- 色彩关系：<主色> + <辅助色> + <强调色>
- 反差：中反差，层次分明
- 黑位：<暗部色相>，保留<材质>纹理
- 高光：云层边缘柔和高光
- 人物肤色：冷调自然
- 空气状态：<烟尘/魔气/灵气> + 远处<阵营光色>
- 材质表现：<焦土/玄铁/碎石>真实质感
- 颗粒：轻微胶片颗粒
- 焦外：柔和
- 炫光：轻微
- 禁止事项：禁止死白天空、禁止塑料 CG、禁止廉价蓝橙滤镜
```
