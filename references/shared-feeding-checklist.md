# 投喂前必查清单 · 指针序列（横切单源）

> **★ 定位**：视频提示词**投喂生成前**的最后执行序列——六步按序过完，全部勾选才允许出稿投喂。本清单是**指针清单**：每步只列检查点并指向规范单源/脚本，验收标准以被指文件为准，本文件不复制正文（防双处维护漂移）。
> 来源：从投喂提示词必查清单蒸馏并适配 xia-boss 体系（2026-09-04 采纳）；其由来教训：仅按单一模板产出曾漏掉语速/气口/五要素/微步进等六处不达标。
> 与既有闸门的分工：**听风自检清单/check-fidelity 管"交付完整性"（AI 交付时），本清单管"点生成按钮前"（用户/工作台投喂时）**——时机不同，都要过。

## 执行铁律

1. **按序过检**：六步顺序执行，每步产出勾选结果，全过才投喂；
2. **语速卡不入正文**：语速自检卡是内部 QC 附件，随交付物输出，不写进投喂正文；
3. **脚本已机械校验的项以脚本输出为准**（check-fidelity/check-assets/check-scenes），本清单不重复判定；
4. **漏过任一步 = 该条投喂作废**，回补后重过全序列。

## 六步指针序列

### Step 1 · 时长预算与时间轴
- [ ] 段落路由与档位已标（`shared-duration-control.md` §九）
- [ ] 每组 ≤15s、组内时码 00:00 起零缝隙、两道账已核（duration-control §十）
- [ ] 高密度动作段已改微步进切片（0.5~1.0s/片，片数=时长）

### Step 2 · 空间与机位
- [ ] 段所属场拓扑图已登记且引用行末位正确（`shared-spatial-blocking.md`；场标识精确匹配）
- [ ] 每镜机位可归入某 CAM；越轴点已标三种合法手段之一
- [ ] 垫图与引用行一一对应（角色→场景→道具→拓扑图末位）
- [ ] **首帧可重建**：每镜开场状态齐全——有人物镜六项（主体/姿态/屏幕位置纵深/朝向/视线/持物）或空镜六项（布局/前中后景/物件状态/环境运动/主光源/景别机轴）（`shared-spatial-blocking.md` §十五）

### Step 3 · 镜头规格
- [ ] 每镜五要素齐全：景别·视角角度·运镜·跟随目标（虾镜 11 字段 / 听风 shot 字段）
- [ ] 中景/全景禁 90° 侧面正拍（30°~60° 斜角）
- [ ] 节奏铁律：同运镜≤2s / 同景别≤3s / 拐点 8~12s / 开局见肉 / 无静止段
- [ ] **表演未"贴情绪标签"**：抽象情绪已转译为可见节拍；长特写/情绪弧有时间轴；贯穿动作锚点未跨时间块重置（`shared-performance-realism.md` §七/§九~§十二；自检清单见其 §十六）
- [ ] **发现/揭晓段**已填角色知识四格账本，无预知脸、无重复解释，揭示顺序=证据→消化停顿→反应（`shared-evidence-control.md` §一/§六）
- [ ] **景别用中文九档**（对照表见 `shared-performance-realism.md` 通用纪律 §4），交付物不出现英文缩写

### Step 4 · 对白三查（有台词必过）
- [ ] 七维快速复核（`shared-dialogue-doctor.md`——重点辨识度/类型语感）
- [ ] 语速公式判定 ✅ + 语速卡随附（三档语速/金句气口 0.3~0.8s/超长拆镜）
- [ ] 金句后反应镜在位（跨段反应·三手法）
- [ ] **声线锚点已锁**：每个说话者的声线身份（年龄感/音域/质感/习惯语流）与临时状态（沙哑/疲惫/忍哭）已写且跨镜不漂移（`shared-dialogue-performance.md` §二）
- [ ] **可播放性审计已过**：局部语速/停顿/重叠/听者反应/结尾余韵不冲突——**字数不是判据**；时间紧张时按 1→5 顺序简化（删运镜→减手势→L-cut→保留重叠→才谈删词），未静默删除关键台词（`shared-dialogue-performance.md` §六）
- [ ] 抢话/重叠六要素齐全、保护性口误已加防顺滑说明、说话者身份与声音方向跨镜稳定（`shared-dialogue-performance.md` §四/§五）

### Step 5 · 战斗档语法（战斗段必过，★ 2026-09-07 v3 改指外协）
- [ ] 战斗段提示词 = seedance-combat-prompt 外协产出**整段回流**（非手工改写）——回流契约校验按 `shared-fight-dispatch.md`：负面四禁（武器形态漂移/动作接触失真/力量反馈缺失/慢动作滥用）在该段负面提示词行内；>15s 拆多单时段间衔接状态连续
- [ ] 兵器/功法招式细节由外协模块按其兵器技法资料库（含学习官回灌的新专项）加载，xia-boss 侧不补写招式
- [ ] 高危词已验证 `shared-compliance-lexicon.md`（词典转译发生在**分镜写作层**——本步只验证，发现违规**回改分镜源 → 重过 check-fidelity**，禁止直接改 video_prompt 破坏逐字保真）

### Step 6 · 出稿质检
- [ ] P0 清零 / P1 处置 / P2 记录（`shared-quality-gate.md` 三档定义；脚本项以脚本为准）
- [ ] 声音三层：对白 > 音效 > BGM（-6/-14dB 避让写进音效设计或 H3 soundscape）
- [ ] **声音锚点已选**：按 `shared-quality-gate.md` 附录 A 选取 2~4 个场景声音锚点（该附录管"选什么声"，§二 管"怎么混"）
- [ ] **光随动作**：画面有运动时光影同步变化，光源有物理来源（`shared-quality-gate.md` §三）
- [ ] **负面约束取最小可用集**：按 `shared-quality-gate.md` 附录 B 选通用类（战斗段以 seedance 外协提示词自带负面词 ∪ 负面四禁为准），非堆叠长列表
- [ ] 引用行图号连续、资产图就绪标记为真（image_ready 实际存在）

### 溢出处置 · 提示词压缩阶梯（★ 2026-09-05 新增）

> 来源：从「影词精磨」Prompt Compression 蒸馏。触发：最终提示词超出该时长档位的字数预算，或模型明显记不住主要动作因果时。

**按序执行，前一步做完仍然超预算才进入下一步**：

1. 删除重复的风格词与修饰语；
2. 合并全局环境描述（重复的"房间很暗"类合并为一句）；
3. 删除无生成价值的装饰性描述（不服务动作/情绪/连续性的形容词）；
4. 合并同义微表情（把三个近似的"抿嘴"合并为一个节拍）；
5. 压缩动作链与次要反应（保留主动作因果，砍旁观者的次要反应）；
6. 仍超预算 → **拆组/拆镜**（按心理阶段边界，禁止均分；跨组锁死接续状态）。

**绝对禁止删除的四类**（宁可拆组也不删）：

- 核心情绪转折与因果链；
- 关键台词（改变剧情或定义角色的那句）；
- 动作因果与空间方向（谁打了谁、往哪个方向）；
- 连续性锚点与结尾余韵（身份锚点/持物状态/声线/最后 1~2s）。

**反模式**：把超载内容塞进密集短句里以求"看起来不超字数"——应减少事件或拆组，而不是压缩表达密度。

> **★ 验证性扫描总则（★ 2026-09-05 修正，保真铁律优先）**：本清单 Step 4–6 的所有"扫/查"都是**验证**——发现问题的唯一正确动作是**回改分镜/beat 源层 → 重新过保真校验 → 再投喂**；**禁止在投喂环节直接手改 video_prompt**（逐字保真破约 = 与分镜源、SQLite、H3 同步三处不一致）。

## 输出契约

投喂提示词组每条自包含（引用行+正文+负面词+参数回填 duration/aspect_ratio）；本清单勾选结果随交付物存档（md 末尾"投喂前六步校验"表）。
