# 跨段母题注册表模板（storyboard-cinematic 附属工具）

> 用途：跨段反复出现的视觉元素（道具/服装/伤情/物件）标准化描述，防止同元素在 S01/S03/S09 出现时措辞漂移。示例全占位符。
> 依据：原文 Advanced Techniques「Cross-Segment Motif Tracking」（①分析期建注册表 ②每次出现描述语言标准化 ③光线/角度/构图跨段一致）。
> 术语说明：「描述锚句」为本模板的格式化术语（原文表述为 standardize description language），指该元素的标准描述句，跨段直接复制使用。

## 0. 跨集编号继承（★ 非首集）

- 编号**延续前集**连续编（前集最大 M<N> → 本集新增自 M<N+1> 起），禁止本集重新从 M1 编。
- 继承条目的规格**从前集登记表逐字搬入**；状态变化更新条目并注明「自本集起」。
- 新增条目走 §4 规格反查资产流程。

## 1. 建表时机

剧本通读后（原文 Stage 1 剧本分析与分段期间），把全剧本**跨段/跨场景会重复出现**的视觉元素列出；每段写分镜时，该元素一律用注册表中的标准描述，禁止临场换措辞。

## 2. 表结构

```
红色物件（跨 S01/S03/S09 出现）：
- 类别: 道具
- 标准名: 红色物件
- 颜色: 半透明红塑料，略微褪色
- 尺寸: 标准便携尺寸（约 7cm 长）
- 状态: 燃料将尽，打火齿磨损
- 打光: 永远背光或侧光，突出半透明质感
- 描述锚句: "半透明红色物件，微微褪色，握在掌心"
- 出现段: S01,S03,S09
- 进词片段: 半透明红色物件

角色A伤疤（跨段出现）：
- 类别: 伤情
- 位置: 左眉骨至下颌
- 状态: 结痂期（随剧情进展更新，但同一段内不变）
- 描述锚句: "一道浅疤从眉骨延伸到下颌"

角色A外袍（跨段出现）：
- 类别: 服装
- 标准描述: 灰褐色粗布外袍，右袖口破损，衣摆沾泥
- 状态变化: 第N段被扯破 → 后续段保持破损状态
```

## 3. 使用规则

1. 元素第一次出现时建条目（含锚句）。
2. 每段分镜用到该元素 → 直接复制锚句，禁改写。
3. 状态变化（破损/血迹/灰烬累积）→ 更新条目并注明"自第N段起"，后续段跟随新状态。
4. 视频提示词全文保真时，锚句随之进入，跨段一致性由"同一锚句"天然保证。
5. **★ 进词规则（2026-09-06 固化）**：每条母题必须填 **`进词片段`**（≤12 字的规格关键串，从规格/锚句中截取最不可能被改写的一小段，如"红缨自左向右缠""旧崩口朝左""左颊旧疤"）与 **`出现段`**（段号列表）。母题「出现段」含本段 → 本段**至少一镜**的画面描述必须逐字包含该进词片段。
6. **★ 机械校验**：`check-fidelity.py` ⑩母题 —— 出现段含本段但 `video_prompt` 无进词片段 → 报错；母题条目缺 `进词片段` 字段 → 同样报错（无法校验即视为未达标）。
   > 历史教训：母题表建得很细（规格、状态、出现段齐全），但**表与提示词之间既无注入步骤也无卡口**，实测规格进提示词 0/27 段——表建了等于没建。

## 4. ★ 规格反查资产（★ 2026-09-01 实战铁律：资产表是颜色/材质/形态的唯一权威源）

- 建条目时，颜色/材质/形态规格**必须从资产库对应资产的 prompt 反查锁定**，禁止凭记忆或创作直觉写色值。
- 确认风格改版后，旧色值一律作废（以资产库现行为准）。
- 动态演出状态（警示/激活/破损等）必须在资产规格的**色系内**表达，不引入资产外的新颜色。
- 与特效类元素（记忆闪回等非资产元素）的颜色区分开：特效色不属于任何资产，条目中注明「非资产元素·特效色」。
- 反面教材：某面板元素凭旧印象写了改版前的颜色 → 与资产图（新颜色）全面冲突，分镜/提示词/资产三方打架。

## 4. 本集必查项（示例）

- 道具类：红色物件、信纸、旧照片
- 服装类：角色A外袍（破损状态）、角色B披风
- 伤情类：角色A眉骨疤、角色B手掌烫痕
- 环境类：场景X的特定光斑/墙裂（跨段环境连续性）
