## 通用纪律：时码与组限（★ 与 shared-duration-control 的接口，必读）

**1. 时码是相对示意，落表必须换算。** 本规范所有时码（如 `0-1.5s`、`3-10s【认命】`）都是**单组内的相对区间示意图**，用于描述表演内部节奏。写进分镜表时一律按 `shared-duration-control.md` 换算：组内时码从 `00:00` 起排、首尾相接零缝隙、格式 `0.0–4.5s` 或 `分:秒–分:秒`。

**2. 单组 ≤15s 是 P0 硬约束，本规范的弧线模板可能超顶。** 本规范 §十 超近面部情绪弧（8~10s）、§十一 30s 心理阶段时间轴（20~29s）、§十二 一镜到底内部节拍，其时码是**表演弧的完整长度**，不是单组长度。弧线总长超过 15s 时**必须拆组**，拆组规则：

- ① **按心理阶段边界拆**，禁止按时长均分（每个阶段是一个完整心理任务，切断即丢失意义）；
- ② 组内时码重置为 `00:00` 起排，组间零缝隙；
- ③ 跨组用**接续状态**锁死三条：**情绪只推进不重置**（上一段停在"认命"，下一段从"记住"起，不重演"追问"）、**贯穿动作锚点继承**（手/道具的握持状态与位置延续）、**声线与临时状态继承**（沙哑/屏泪/呼吸节奏）；
- ④ 组尾留退场钩子或 1~2s 余韵，组首用换景别/换角度或 match-on-action 桥接（切法归 `shared-transitions.md`）。

拆组示例（占位符，29s 弧线 → 2 组）：

```text
组1（15s）：00:00-3.0s【追问】→ 3.0-10.0s【认命】→ 10.0-15.0s【记住·前半】  组尾：视线锁在对方脸上，呼吸屏住，退场钩子
组2（14s）：00:00-8.0s【记住·后半 + 惋惜】→ 8.0-14.0s【放手】  组首：极慢 Push in 承接上组末帧的 ECU，情绪从"屏泪"推进到"第一滴泪落下"
```

**3. §八 微表情时长刻度 ≠ 微步进片长。** §八 的 `0.25~2.0s` 是**单镜内部表演细节的时长粒度**；`shared-duration-control.md` 的"微步进 0.5~1.0s/片"是**打戏专用的时长控制工具**（片数即时长）。两者概念不同、不冲突：普通文戏不用微步进，按标准 3~4 镜排布。

**4. 景别术语以 xia-boss 中文九档为准。** 本规范为保持表演精度使用英文缩写，落分镜表时按此表换算（与 `modules/xiajing-episodes/references/storyboard-method.md` §景别 九档同源）：

| 中文九档（**分镜表必用**） | 英文缩写（本规范内部） | 画框范围 | 典型表演用途 |
|---|---|---|---|
| 极远景 | ELS | 环境为主 | 表演不可读，仅作情绪空间 |
| 远景 | LS | 全身 + 环境 | 身体姿态读情绪 |
| 全景 | FS / WS | 全身 | 大动作前的空间腾挪 |
| 中远景 | MLS | 膝上 | 接近/退避关系 |
| 中景 | MS | 腰上 | 对话基础景别 |
| 中近景 | MCU | 胸上 | **防御期**（争辩/解释/维持控制） |
| 近景 | CU | 胸上 / 头肩下缘 | 防御松动 |
| 特写 | BCU | 头肩 | **保护层裂缝**（承认/声音破裂） |
| 极特写 | ECU | 面部局部（眼/嘴/接触点） | **峰值**（那滴泪/那个笑/那次凝视） |

**落表规则**：分镜表「景别」字段与视频提示词交付物一律写**中文九档**；英文缩写仅用于本规范内部表述，不进交付物。

**5. 长特写与「镜级节奏铁律」的接口（★ 有条件豁免，双向咬合）。** 本规范 §九 长特写微表情时间轴（8s）与 §十 超近面部情绪弧（8~10s）要求**固定机位、无抖动、不切镜**，而 `shared-duration-control.md` §四「镜级节奏铁律」要求**同景别 ≤3s / 同运镜 ≤2s / 15s 内切镜 5~8 次**。二者表面冲突，按以下裁决处理：

| 铁律 | 立法目的 | 长特写是否适用 | 理由 |
|---|---|---|---|
| 同景别 ≤3s | 防视觉呆滞 | **有条件豁免** | 画面变化由**面部微表情**提供，而非景别切换；立法目的已通过其他方式达成 |
| 同运镜 ≤2s | 防镜头语言疲劳 | **不适用** | 固定机位无运镜，不产生"运镜疲劳" |
| 15s 内切镜 5~8 次 | 保持剪辑密度 | **不适用** | 该段为**一镜到底**（整段 1 镜），切镜密度指标无对象 |
| **无静止段铁律** | 完播率 | **仍然适用，不豁免** | 人物必须持续有可见生命运动（呼吸/眨眼/微表情/吞咽/泪液成形）；**画面"机位不动"≠"人物静止"**，人物静止即违规 |

**豁免的四个前置条件（缺一不可，否则回到 duration-control 铁律）**：

1. 剧情确需（微表情/情绪弧就是本段的全部内容），或用户明确要求长特写/一镜到底/情绪弧；
2. 该段**整段只有 1 镜**（若段内还有其他镜头，非特写部分仍须遵守同景别≤3s 与同运镜≤2s）；
3. 已写出**微表情时间轴或情绪弧波形**（§九/§十），证明画面在持续变化——没有时间轴支撑的长镜头 = 视觉呆滞，不豁免；
4. 人物持续有生命运动，**无静止段**。

**★ 风险提示（两个方法论的张力点，用户可裁决）**：duration-control 的节奏铁律是**完播率导向**（短视频切镜密度），本规范的长特写是**电影感导向**（情绪积累需要时间）。两者冲突时：

- **短剧/口播/完播率优先**的项目 → 以 duration-control 铁律为准，长特写压缩至 ≤5~6s 或拆为 2 镜（同景别但用插入镜、遮挡过渡或极慢 Push in 制造变化）；
- **电影感/情绪戏/氛围片**项目 → 可启用本豁免；
- 用户未指定时，**默认走 duration-control 铁律**（保守优先），启用豁免须在分镜表注明理由。

## 〇 最高律：心理动机单源

**禁止直接给角色「做表情」。** 先定一句话内在动机——角色此刻在做什么：解释、隐瞒、回忆、试探、说谎、后悔、装作轻松、压抑恐慌、还是正在努力不伤害对方。

然后让以下各项**全部从这一个动机推导出来**：

- 视线方向与眨眼时机；
- 嘴角/双唇/眉/下颌/喉结；
- 声音质感、语速、迟疑、停顿落点；
- 呼吸与关键词之后的小恢复；
- 笑意有没有抵达眼底。

示范（占位符）：

```text
角色A不是直接表现悲伤，而是在努力保持平静。说话前短暂低头，像在组织语言；抬眼时眼神没有完全对准镜头；说到关键处停顿半拍，嘴角轻微收紧；最后轻轻笑一下，但笑意没有完全到眼底。眼神、表情、语气和停顿都服务于"克制地解释一件自己在意的事"这个心理状态。
```

**禁止**：固定假笑、空洞凝视、突然表情跳变、夸张哭喊大笑、表情与台词含义不匹配、语气与表情脱节、无思考地直视镜头、无停顿像念稿。

## 一、按需选用强度（不要五模块全开）

> **模块口径**：源方法论的「六模块」中，**心理动机**已提升为本规范的**最高律（§〇）**，不再作为可选模块；因此本规范的可选表演模块为**五个**：§二 伴随动作、§三 生物联动、§四 接触重量、§五 环境响应、§六 摄影条件一致。§〇 心理动机单源律**任何场景都必须遵守**，不参与"按需选用"。

| 场景强度 | 建议用量 |
|---|---|
| 普通情绪对话 | 2~4 条精简活人感提示即可 |
| 长特写 / 手机纪实 / 写实测试 | 全开五模块（§二~§六）+ §〇 心理动机单源律 |
| 打斗戏 | 主要用 §三 生物联动 + §四 接触重量 + §五 环境响应 |
| 大场面 | 主要用 §六 摄影条件一致 + 一个人类锚点 |
| 产品/人物质感 | 主要用 §四 接触 + 光影 + 材质响应 |
| 古装/年代戏 | 主要用 §〇 动机 + §三 联动 + 衣料与光影响应 |

## 二、状态驱动的伴随动作

不要为了让画面「丰富」而加动作。让小动作**从角色当前状态、社交关系与说话目的里漏出来**。

严肃解释、迟疑、克制、关切类，用靠近身体或桌面的低幅度动作：轻微点头、小幅前倾、肩膀随呼吸放松、指尖摩挲杯沿、重新握住杯子、指尖停顿、整理袖口、极小的姿态修正、符合社交状态的碎发整理。

示范：

```text
动作动机要求：不要为了让画面丰富而加入明显动作。角色A正在克制地表达一件自己在意的事，因此肢体动作保持低幅度、低姿态、靠近桌面，主要表现为轻微点头、短暂停顿、身体小幅重心变化、手指与杯子的细微接触、整理袖口或碎发。动作像边说边想时自然流露出来的无意识反应。
```

**禁止**：突然托腮、大动作抬臂、摆拍式手势、夸张挥手、炫耀动作本身的动作、会意外改变角色情绪状态的动作。

## 三、人体生物联动（真人不分段运动）

一个部位动，相连部位必须跟随：

- 眼睛通常**先于**头部反应；
- 转头带动颈部与肩部补偿；
- 手动→前臂、手腕、手指、袖口与躯干小重心共同参与；
- 呼吸影响胸腔、肩膀、声音与停顿节奏；
- 点头不是只有脑袋动：眼焦点、颈、肩、呼吸都轻微参与。

示范：

```text
角色A抬眼前，眼睛先从桌面移开，随后下巴轻轻抬起，颈部自然跟随。说话时肩膀随呼吸有轻微起伏，身体重心有很小的前后变化。扶住杯子时，手腕、前臂和袖口产生细微联动，不要让手像独立物体一样移动。
```

**禁止**：孤立肢体运动、头动而肩颈冻结、僵直脖颈、悬浮手臂、无呼吸起伏、无肌肉衣料联动、机器人式关键帧位移。

## 四、物理接触与物件重量

接触写成**物理过程四段**：接触前 → 接触 → 受力/阻力 → 余后状态。

示范：

```text
指尖先轻轻靠近物件P边缘，短暂停住，随后拇指和食指扶住壁面。物件保持稳定，只出现极轻微的受力变化。手指在壁面上小幅摩擦时有停留和阻力感。袖口靠近桌面时产生轻微褶皱变化，手臂移动不要穿过物件P或相邻物件。
```

适用物件：杯、手机、信、戒指、袖口、桌沿、门把手、椅子、床单、剑柄、包、纸张、玻璃。
必须写出：重量、摩擦、压力、惯性、布料张力、反光/阴影变化。

**禁止**：手穿模、物件在接触前先动、悬浮道具、无重量无阻力、手指未贴合物件表面、衣物无褶皱响应、桌面与身体空间关系不清。

## 五、环境对人类动作的响应

角色不能像贴在背景上。小动作要激起小环境响应：

- 转头后碎发滞后半拍；
- 前臂移动时袖口褶皱变化；
- 手靠近时杯壁反光变化；
- 触碰时纸袋边缘轻微压缩；
- 前倾时暖光与阴影细微移动；
- 房间底噪、衣料声、杯声、呼吸、椅子轻响、手机振动随动作响应。

示范：

```text
角色A轻微前倾说话时，脸上的暖光和阴影有细小变化，额前碎发随头部移动轻微晃动后慢慢停住。手靠近杯子时，杯壁反光随手的位置发生细微变化。袖口贴近桌面产生轻微褶皱，纸袋保持稳定但有真实纸张质感。
```

**禁止**：角色贴片感、头发完全静止、衣物像平面贴图、光不随身体角度变化、物件无反光或阴影变化、无动机的大风、环境响应过大抢戏。

## 六、摄影、光、焦点与空间条件一致

先定**拍摄条件**（手机纪实 / 手持纪录 / 克制的电影剧情 / 年代烛光 / 低调罪案 / 商业产品），然后让景别、稳定度、焦点、光、皮肤质感、背景虚化、颗粒噪点、空间尺度**全部属于同一条件**。手机纪实只是选项之一，不是所有电影感提示词的默认。

示范（手机纪实）：

```text
画面像手机在晚上室内自然拍摄，半身近景，镜头略高于桌面，轻微手持晃动但不影响观看。暖色顶灯是主要光源，脸部和手部阴影方向一致。背景轻微虚化但仍能看出家庭空间，画面保留轻微噪点、压缩感和真实皮肤纹理。焦点稳定，但有非常轻微的自然呼吸感。
```

**禁止**：手机纪实场景出现广告级布光、声称自然家居光却是完美棚拍、塑料皮或重度磨皮、手持设定下镜头过分稳定、光影方向不一致、人物与背景尺度错、严重焦点漂移、无真实质感的过分干净画面。

## 七、情绪 → 微表情映射表（20 种，速查）

每种情绪取 3~5 个节拍，**不要全用**。抽象情绪标签一律转译为可见动作。

| 情绪 | 可见节拍（按顺序） | 典型写法（占位符） |
|---|---|---|
| **悲伤** | 眼神先失焦→下眼睑微颤、眨眼变慢→唇抿紧后松开→呼吸变浅、肩微塌→泪悬下睫毛（需要释放才落） | 眼神先失焦，随后下眼睑细微颤动；嘴唇慢慢抿住，呼吸变浅，泪水悬在下睫毛处却迟迟不落。 |
| **震惊** | 呼吸停一拍→眼睛微睁后僵住→瞳孔轻微扩散→下颌松开或锁死→手停半空 | 呼吸骤然停住，手停在半空，眼睛微微睁大后彻底僵住，瞳孔轻微扩散，像还没有理解这句话。 |
| **强忍哭泣** | 视线下降躲避被看见→死死抿唇、嘴角下压→喉结滚动一次→鼻息无声颤抖→（要遮声时）手掩口 | 迅速低下头，嘴唇死死抿住，喉结艰难滚动一次，鼻息破碎地颤了一下，却没有发出哭声。 |
| **愤怒克制** | 目光突然静止变锐→下颌绷紧、后槽牙咬合→鼻翼轻张→眨眼变少→手指无声扣紧物件/衣料 | 目光突然静下来，眨眼变少，下颌线绷紧，鼻翼轻轻扩张，手指无声扣紧杯沿。 |
| **悔恨** | 视线看向对方又迅速移开→眉心向内（非向上）收拢→嘴唇张开却无话→下巴下沉、身体内折→手伸出一半停下 | 看向对方又迅速移开视线，眉心向内收紧，嘴唇张开却说不出话，伸出的手停在半空。 |
| **愧疚** | 视线向下并向侧方闪躲→眨眼变慢变重→嘴角不对称绷紧→肩颈轻微后缩→关键语前音量下降或停顿 | 视线向下躲开，眨眼变慢，嘴角不对称地绷住，肩膀轻轻缩回，像不敢承受对方的目光。 |
| **羞耻** | 头比视线垂得更低→耳根/脖颈/面颊泛红（视觉允许时）→嘴收成很小的线→眼神无法保持接触→身体微转向侧 | 低下头，眼睛不敢停在对方脸上，耳根和脖颈慢慢泛红，嘴唇收紧成很小的线。 |
| **羞怯** | 视线抬起一瞬又逃开→抿唇后漏出一点笑→睫毛轻颤→手指触碰袖口/杯/发→呼吸变轻 | 怯怯抬眼看了一瞬又移开，睫毛轻颤，嘴角压不住地漏出一点笑意，手指无意识捏住袖口。 |

## 八、微表情动作库（模块化节拍，按需取 3~5 个）

**悲伤·震惊·冻结**：失焦转呆滞 / 眼睑颤动 / 笑容冻结 / 目光回避再抬起 / 泪水悬住 / 泪水滚落 / 嘴部失控 / 眼神彻底失焦
**麻木·疲惫·强装平静**：瞳孔恐惧涣散 / 眼睑高频颤动 / 闭眼滞停 / 情绪转平静 / 轻蔑冷笑 / 扬起下巴斜睨 / 冷哼鼻息 / 情绪转坚定
**惊喜·羞怯·柔软脆弱**：惊讶 / 眼神柔弯 / 羞怯含羞 / 脸红 / 压笑成浅笑 / 被发现心事的娇羞 / 抿唇咽口水 / 羞怯抬头 / 娇嗔偏头 / 气声软拒绝 / 躲开又偷看 / 压住笑意
**算计·阴狠·黑化**：笑意褪去 / 审视盘算 / 眼神变阴厉 / 嘴角阴冷勾起 / 本性毕露 / 眼神凶狠 / 面部绷紧 / 阴毒
**温柔·伪装·表演控制**：宠溺 / 笑意抽离 / 伪装剥落 / 阴冷笑起 / 本性暴露

**时长刻度**（与 shared-duration-control 微步进同口径）：

| 时长 | 适合承载 |
|---|---|
| 0.25~0.5s | 鼻息、咬肌收紧、眼神一闪、笑意抽动 |
| 0.5~1.0s | 视线变化、闭眼停顿、泪水成形、抿嘴、抬下巴 |
| 1.0~1.5s | 完整情绪过渡：笑意消失、强装平静、羞怯回望 |
| 1.5~2.0s | 复杂面具切换：温柔转算计、笑转阴狠 |

铁律：自然过渡，**禁止突然表情跳变**，禁止夸张哭喊与舞台式挤眉（剧情明确要求除外）。

## 九、长特写微表情时间轴

长头部/面部特写必须由**表情自身**撑住。写出从中性开始的渐进时间轴，不做突然跳变。

模板（占位符，时长按 shared-duration-control 分配）：

```text
0-2s：角色保持平静的表情，眼神轻轻低垂，嘴唇自然放松。
2-4s：情绪开始轻微变化，嘴唇慢慢轻轻抿住，嘴角开始一点点下压，眼神变得失落。
4-6s：难过逐渐明显但仍然克制，眉头轻轻皱起，嘴唇保持轻抿，眼神带着委屈和隐忍，眼眶微微湿润。
6-8s：稳定在隐忍难过的表情中，像在努力忍住眼泪。脸颊出现一两滴细小自然的泪滴或泪痕，但没有大哭，没有抽泣，情绪安静克制。
全过程表情自然过渡，微表情细腻，没有突然变化，没有夸张哭泣。
```

四种可替换的情绪波形（按场景替换情绪词）：

- **震惊冻结**：放松 → 笑意停住 → 眼神失焦 → 呼吸停止 → 下颌锁死
- **强忍哭泣**：平静 → 抿唇 → 眼眶泛红 → 泪线成形 → 无声呼吸颤抖
- **愧疚**：视线躲避 → 眨眼变慢 → 抿嘴 → 眉心内收 → 低头
- **愤怒克制**：目光静止 → 鼻翼扩张 → 下颌变硬 → 手指绷紧 → 眼眶湿润但不眨眼

镜头纪律：ECU/CU、固定或极慢 Push in、浅景深、背景最小运动；**不要叠加复杂调度**。

## 十、超近面部情绪弧系统（全程靠脸演的镜头）

适用于整段都由超近面部表演承担的镜头，**不限于哭戏**——可适配悲恸、羞怯、爱意、愧疚、恐惧、嫉妒、黑化、决绝、释然。

核心设定句式：

```text
电影级超近面部特写，固定镜头或极慢 Push in，柔和自然窗光或烛光在脸上投下淡淡阴影。人物服装与发丝保持简洁真实。前半段尽量无肢体动作，所有表演凝聚在眼神、瞳孔、下眼睑、嘴角、双唇、泪水和呼吸里。全段无台词。
```

通用规则：

- 主观镜头允许「镜头即某个人物」，例如 `镜头即她的心上人，她像正在与心上人面对面交流一样看向镜头`；
- 机位稳定：固定 ECU/CU，无抖动，无复杂调度；
- **情绪必须成波形**，不是平铺：认出 → 反应 → 掩饰 → 泄露 → 恢复或崩塌；
- 美感/身份型特写要定义发型、妆容、服装、配饰、光线与面部稳定性，但**不要变成时尚海报**；
- 无台词优先；台词只在故事需要时才加；
- 完整弧 8~10s；短片压缩为 4 个节拍。

### 模板 A · 复杂悲伤弧（8~10s）

```text
0-1.5s：失焦的双眼骤然聚拢，瞳孔微微扩散，下眼睑轻轻颤动，表现纯粹震惊与不敢相信。
1.5-2.5s：震惊凝固成冷意，嘴角一侧挑起极淡的、近乎嘲讽的冷笑，笑意不到眼底；目光下垂又抬起，带自嘲与疲惫的了然。
2.5-4s：冷笑渐渐加深成安静而微颤的微笑，像努力维持最后体面；眼眶泛红，泪水在下睫毛处聚满却不落。
4-6s：微笑彻底瓦解，双唇紧抿后开始轻颤；眼神彻底失焦，泪水终于大颗滚落，垂下眼帘，下巴微微抖动，无声哽咽。
6-7s：抽息余韵未散，缓缓低头，下巴轻收，胸腔里逸出极轻的叹息，肩膀微微塌下，像卸下最后的硬撑。
7-8s：深吸一口气，重新抬头，双唇奋力弯起一抹颤巍巍的温柔微笑；泪痕未干，眼底强撑出清透释然。
8-9s：抬手用指背小心擦泪，手触碰泪水瞬间，压抑的抽泣反扑，肩膀不受控抽动，微笑在泪水里失真，新的泪水顺着指缝滑落。
```

压缩版（4 节拍）：`震惊聚焦 → 冷笑自嘲 → 微笑瓦解落泪 → 强撑释然又被抽泣反扑`。

**禁止**：情绪逻辑未到就突然大哭、夸张抽噎或舞台式挤脸、前半段过多手部与肢体动作、磨皮到看不见泪与眼睑细节、把这套完整波形套进每一个悲伤场景（只留给重大情绪转折）。

### 模板 B · 羞怯爱意弧（8~10s，镜头即可为心上人）


非恋爱场景可套同一结构：`突然认出 → 情绪泄露 → 掩饰躲避 → 重新鼓起勇气`。

### 模板 C · 娇嗔软拒绝弧（4~6s，安全非露骨）


## 十一、30s 心理阶段时间轴（长情绪段专用）

20~30 秒的情绪主戏（告别/分手/表白/质问/重逢/道歉/原谅/接受/放手）**不要按时钟平均切分，按心理任务分段**。

阶段名用小动词或情绪任务：

```text
追问 -> 认命 -> 记住 -> 惋惜 -> 放手
试探 -> 防御 -> 被击中 -> 坦白 -> 余震
克制 -> 反击 -> 裂缝 -> 承认 -> 沉默
```

每段必须包含：① 阶段名/心理任务；② 可见的动作、表情、视线、呼吸、声音或身体证据；③ 一句短台词或有意义的沉默；④ 与上一阶段的明确差异；⑤ 泪/笑/视线/呼吸/姿态的时机决策。

工作稿里可以解释动作含义，**最终投喂正文只保留可见行为 + 一句防歧义的紧凑含义注**：

```text
工作稿可用："短促苦笑"不是开心，而是自嘲和认命；"重新看回对方"不是挽留，而是想最后记住他的样子。
投喂正文：3-10s【认命】：视线从对方脸上慢慢移开，望向旁边空地；眼睑低垂，嘴角牵起一抹很短的苦笑又落下，鼻翼轻收，胸口轻轻起伏一次，像把委屈咽回去。
```

**禁止**把最终正文写成情绪散文分析（"这个动作象征她内心的命运感、遗憾与复杂人生……"）。

### 相似表情必须区分

同一个可见表情出现两次时，必须定义情绪差异：前一个笑可能是自嘲/礼貌/防御/难以置信，最后一个笑可能是原谅/释然/祝福/疲惫的温柔；前一次凝视是在要答案，后一次凝视可能是在记忆、指控、原谅或告别。

```text
前一个笑是自嘲和认命，最后一个笑是温柔放手；不要把两个笑都生成成同一种甜笑或假笑。
```

### 眼泪时机（按事件控时，不按"悲伤"控时）

```text
眼眶泛红但不落泪 -> 眼泪被屏住 -> 第一滴泪在保护层松开后落下 -> 第二滴泪在最终台词或微笑中滑落 -> 结尾保留泪痕和呼吸
```

- 泪不得早于情绪触发点；
- 克制型角色需屏住数秒才落第一滴；
- 指明是哪一滴泪重要（第一滴/第二滴/泪痕/悬在下睫毛/滑到唇边）；
- 一两处精确的泪比全程哭更有力。

### 镜头推进绑定情感可及性

- 角色仍在防御时：稳定 CU/BCU 起幅；
- 停止防御或决定暴露脆弱时：极慢 Push in；
- **ECU 只留给峰值阶段**（那句台词、那滴泪、那个笑或那次凝视改变意义的瞬间）；
- 最后一帧要留够时间让观众读完表情（与 shared-duration-control 结尾余韵同口径）。

安静情绪场景**禁止**同时堆叠推进、环绕、手持抖、变焦。一次有动机的推进或固定机位通常就够。

**压缩与拆组规则**：

- 20~24s：减为 4 个阶段；
- 10~15s：不套此完整模式，改用 §九 微表情时间轴；
- **★ 29s 级别的完整弧线必然超过单组 15s 上限（P0 硬约束），必须按「通用纪律 §2」拆成 2 组**——本节的时码是**表演弧的完整长度**，不是单组长度。拆组按心理阶段边界切（禁止均分），组内时码重置 `00:00` 起排，跨组锁死「情绪只推进不重置 / 贯穿动作锚点继承 / 声线与临时状态继承」三条接续状态。

## 十二、导演表演链（强情绪对抗/告白/背叛/重逢）

构建顺序锁死：

```text
内在冲突 -> 生理反应 -> 微表情 -> 贯穿动作锚点 -> 决定性行为
```

示范逻辑（占位符）：

```text
角色内心渴望靠近，却表面死守边界；因此眼睑颤动、咬肌绷紧、喉结干咽；手指持续绞紧衣料；当防线崩塌时，手先松开、悬停，最后才完成靠近或触碰。
```

**贯穿动作锚点**——选一个小动作或道具承载情绪连续性：握紧再松开床单/袖口/杯/信/戒指/门把手/手机/剑柄/椅沿；手伸到一半冻住、收回、最终完成；呼吸反复停住又重启；视线躲避、回来、最终锁死对方。

铁律：**锚点必须随情绪演进；禁止在时间块之间重置手、道具或姿态**（与 shared-spatial-blocking 持物手连续、shared-production-facts 状态链三处同一口径）。

### 大动作前先给画面腾空间

从 ECU/CU 要进入大肢体动作（站起、跌倒、翻身、拥抱、推开、全身对抗、投掷、大幅衣料运动）之前：

```text
镜头拉开或快速后撤 -> 留出身体运动空间 -> 再跟随动作改变机位/构图
```

禁止让 ECU 镜头在没有景别过渡的情况下突然展示复杂全身动作。

### 动作-光-声绑定（一次事件，一处后果）

同一个动作同时绑定视觉与声音后果，形成**一个**可读事件而不是三条无关描述：

- 身体穿过百叶/窗光 → 光斑条纹在皮肤上断裂移动；
- 手松开布料 → 衣料张力与摩擦声改变；
- 翻身/跌倒在床或地面 → 床垫、床单、地面、灰尘、家具响应；
- 物件接触 → 一次清晰的撞击声 + 可见的环境响应。

### 由表演驱动的运镜（禁止无动机运镜）

| 表演 | 运镜 |
|---|---|
| 视线转移 | 轻微 Pan |
| 低头/抬头 | Tilt Down/Up |
| 情绪性靠近 | 缓慢 Push in |
| 突发全身动作 | 快速 Pull back 或放宽重构图 |
| 跌倒/下坠 | 受控 Tilt down |
| 后退 | 后拉跟拍 |

### 一镜到底也要有内部节拍

一镜场景仍分 2~4 个内部戏剧段：`压抑建立 -> 关系刺激 -> 防线松动 -> 决定性行为 -> 余韵`。保持机位连续，但让景别、距离、视线、动作锚点、光与声在每段演进。

## 十三、行为伏笔回收系统（不含解释台词的结尾证明）

四步环：

```text
建立行为 -> 重复或让它吃力 -> 转变其含义 -> 结尾完成/停止/反转/移交
```

可选锚点：等待姿态或反复望向某个入口；反复伸出、停住或收回的手；杯子/戒指/门/照片/外套/椅子/空位；不可触碰的边界或固定身体距离；整理/照料/保护/回避的习惯；重复后含义变化的一句短语。

五种回收型：

| 型 | 含义 |
|---|---|
| **完成** | 未完成的动作最终触及 |
| **停止** | 重复行为停止，证明释怀或接受 |
| **反转** | 做出与开场习惯相反的动作 |
| **移交** | 一方起手又停下，另一方替他完成 |
| **重述变义** | 同一句台词或动作带着不同情绪含义回归 |

示范（占位符）：

```text
开场她每次紧张都会抓住门框；中段手指逐渐松开；结尾听见真相后，她没有再次抓门框，而是主动跨过门槛。人物状态变化由行为完成，不再追加解释台词。
```

铁律：回收必须**物理连续且可读**；**禁止**在结尾临时引入一个全新的象征动作并称之为解决。

## 十四、附录：非人类角色表演（妖兽/灵兽/机关/化形）

适用于非人类角色的**表演**（招式/特效/世界观规则归 production-facts 世界规则与打戏外协模块，见 `shared-fight-dispatch.md`）。

按物种翻译情绪，不要套人类表情：

- **解剖**：情绪经由该物种实际拥有的结构表达（耳/尾/羽/鳞/吻/触须/甲壳张合/发光纹理），而非人类的眉眼嘴；
- **感官**：以嗅觉、听觉、震动感知、热感应等该物种主导感官为先导反应；
- **运动**：情绪影响步态、重心、速度、停顿、身体姿态与群体距离；
- **年龄与能量**：幼体/老体/伤体的幅度与恢复速度不同；
- **接触**：与人或环境接触的重量、摩擦、压迫与后果要符合体型与材质；
- **恢复**：情绪平复过程按该物种节律（喘息、抖毛、鳞片复位、光纹暗下去）。

**禁止**：把人类的哭、笑、挑眉、手势直接映射到非人类角色身上——除非该角色的设定明确支持（如已化形为人、设定中会流泪的灵兽）。

## 十六、自检清单（写表演字段/投喂前）

- [ ] 心理动机一句话已定，所有表演项从它推导（无"贴情绪标签"）；
- [ ] 抽象情绪已按 §七 转译为 3~5 个可见节拍；
- [ ] 伴随动作有状态动机，不是为让画面热闹；
- [ ] 有人体联动与呼吸（非机器人位移）；
- [ ] 接触写出重量/阻力/余后（无穿模、无悬浮）；
- [ ] 环境对动作有响应（发丝/衣褶/反光/光影）；
- [ ] 摄影条件统一（光/焦点/质感/尺度属同一模式）；
- [ ] 长特写有时间轴，无突然跳变；
- [ ] 强情绪段有贯穿动作锚点且未跨时间块重置；
- [ ] 大动作前有景别腾挪；
- [ ] 运镜有表演动机（无炫技堆砌）；
- [ ] 情绪弧成波形（认出→反应→掩饰→泄露→恢复/崩塌）；
- [ ] 结尾有行为回收或明确的余韵处理；
- [ ] 非人类角色按物种翻译，未套人类表情。
