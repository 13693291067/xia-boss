# 认知与证据控制 · 可执行规格（横切单源）

> 适用：xia-boss 一切含「发现/揭晓/悬疑/隐藏身份/重逢/迟到认知/背叛揭示/调查推进」的环节——剧本创作（screenplay-gate）、分镜表演字段（虾镜/听风）、视频提示词组装、打戏非战斗表演段。
> 性质：通用方法论，禁止出现任何具体项目数据；示例一律占位符（角色A / 角色B / 物件X）。
> 来源：从「影词精磨」（cinematic-video-prompt-engineer v1.5.0）style_patterns.md Character Knowledge and Evidence Control 章节蒸馏，通用化改写（2026-09-05 采纳）。
> 分工：本规范管「谁知道什么、何时知道、怎么让观众看见『知道』」；shared-performance-realism.md 管「知道之后怎么演」；shared-spatial-blocking.md 管「机位在哪」。三者互不替代。

## 〇 核心原则

角色只能对「剧本已让它获知的信息」做出反应。预知脸（角色对尚未获知的信息提前表露情绪）与镜头重复解释（画面反复向观众确认已知信息）是同一根因的两面：**没有把「角色知识」和「观众知识」当成两条独立的账**。

## 一、角色知识四格账本（每场开工前填）

对每个重要角色，内部强制追踪四个状态，顺序锁死：

```text
已知道什么 -> 本场新观察到/听到什么 -> 可合理推断什么 -> 必须保持未知什么
```

**表演必须严格跟随这个顺序**。三条红线：

1. 角色只得知「某人失联」时，不能演出「确认死亡」级别的悲恸——悲恸强度不得超过证据强度；
2. 角色未收到识别性证据（信物/相认暗号/照片）前，不能「认出」未来的亲人/仇人；
3. 角色不能因为「编剧知道真相」就向他人解释时间跳跃/真凶/关系/牺牲——解释必须有信息来源（物证/口供/目击/推断链）。

推荐认知推进链（按需取用，不必全走）：

```text
常规假设 -> 注意到异常 -> 核查证据 -> 形成试探性假设 -> 情感代价高昂的确认 -> 基于部分认知采取行动
```

若角色始终拿不到完整铁证，最终行为应体现「合理的部分认知」，而不是虚假的确定。**未完成的确认是合法结局**，但必须让行为与证据强度匹配（见 §五）。

## 二、观众-角色信息差三态（每场标注其一）

同时控制两个平行问题：

- **角色问题**：此人此刻想弄明白什么？
- **观众问题**：观众怀疑什么、先知道什么、还需要确认什么？

| 信息差状态 | 观众 | 角色 | 效果 | 镜头纪律 |
|---|---|---|---|---|
| **悬念** | 先知道 | 不知道 | 替角色着急、预期违背 | 允许观众看见角色看不见的东西；角色反应必须滞后于观众认知 |
| **共情** | 同步 | 同步 | 一起经历发现 | 发现过程完整呈现，反应镜给足 |
| **惊奇** | 不知道 | 先知道 | 反转冲击 | 画外信息保持克制；揭晓前禁给观众可拼出真相的插入镜 |

一段 20-30 秒的强戏可以让核心问题演进（不要在原地重复同一个谜）：

```text
这是谁/什么 -> TA怎么会知道这件事 -> 他们之间发生过什么 -> 这个真相现在逼出什么选择或情感
```

身份或机制一旦对观众足够清楚，立即把问题升级到更私人的层面；**同一个谜底不允许被镜头重复解释**。

## 三、角色定义式提问（关键台词过滤）

角色「选择问什么」应当暴露其价值观、关系与世界观——这是台词层面最便宜的认知控制：

- 保护型角色先问「对方活下来了吗」，再问自己遭遇了什么；
- 悲恸型角色问「TA等过我吗」，而不是索要一段背景说明；
- 面向未来的爱人问「这一生值不值」，而不是追问事件机制。

**关键台词过滤测试**：如果任何普通角色都能说出这句台词而不改变场面，就必须按该角色的优先级重写。禁止「方便向观众交代剧情」的投机性提问（与 shared-dialogue-doctor 维度5「信息效率」、维度2「潜台词」同律，双处同一口径）。

## 四、证据经济与反应优先呈现（核心呈现规则）

用**最少且清晰**的证据让推断可信。然后按「哪个更重要」选择呈现方式：

- 事件的**物理机制**重要（怎么做到的/接触了什么/换了什么状态）→ 直接展示动作；
- **意识到**更重要（角色明白了什么/情绪代价）→ 镜头留在观察者身上，用以下五种手段证明画外事件：

1. 一声精确的画外音效（接触声/物件倒地/语音关键词）；
2. 视线移向看不见的声源；
3. 物件震动、反光、影子、灯光或环境响应；
4. 迟到的呼吸/瞳孔/姿态/手部反应；
5. 稍后的一次确认（替代即时的解释性插入镜）。

**禁令**：不要为了「证明每个名词」就切到手机、门把手、手部、钥匙、脚印或物件特写。只有当物件的物理状态、可读信息或后续连续性依赖「看见它」时，才允许插入镜。

示范句式（占位符）：

```text
角色A先准确说出角色B下一秒会做的习惯动作；镜头不切手部，只留在角色B脸上。画外传来两次细小接触声，第二次之后角色B的视线极短下移，呼吸停住，再重新抬眼。观众通过声音与反应完成确认。
```

## 五、预测-验证节拍（悬疑/高概念钩子专用）

紧凑的可信证明结构：

```text
断言/预测 -> 短暂等待间隙 -> 画外或可见的验证 -> 观察者反应 -> 修正假设
```

- 验证必须**具体到排除巧合**，又**小到不破坏悬念**；
- 证明落地后**禁止立即解释机制**——解释权留给后续段落；
- 验证完成后角色按新假设行动（接 §一 推进链的「基于部分认知采取行动」）。

## 六、揭示时机顺序（写进分镜表演字段）

发现类戏的镜头顺序锁死为：

```text
证据出现镜 -> 消化停顿（0.5~1s） -> 反应镜
```

- 反应不得早于证据；
- 消化停顿不可省（它是「正在理解」的可见过程，也是 shared-performance-realism.md 情绪保护层的时间入口）；
- 反应镜的表演强度按四格账本的「新获得证据」档位执行，禁止跳档。

## 七、接入点与咬合

| 环节 | 消费方式 |
|---|---|
| shared-screenplay-gate（创作） | **Gate 3 · Beat Sheet（场景因果节拍表）**写「角色知识锚点」：每场/每集结尾各角色处于四格账本哪个格子，跨场跨集不得无故重置；**Gate 2 · Structure** 的分集卡点钩子（Cliffhanger）不得让角色在获得证据之前提前反应 |
| 虾镜/听风分镜 | 发现类镜头的「角色演绎」字段前置：先填四格账本，再写表演；反应镜按 §六 顺序 |
| shared-performance-realism | 本规范定「知道什么/何时知道」；该规范定「知道之后脸上怎么变」——两者在「消化停顿」处接口 |
| shared-transitions 二式·反应镜头切 | 重击/揭晓瞬间切反应镜——本规范约束反应的**时机与内容**，该式管**切法** |
| shared-dialogue-performance | 听者反应轨的「哪个词落地」即证据到达时刻；双方同一口径 |

## 八、自检清单（发现/揭晓类场景交付前过一遍）

- [ ] 每个重要角色的四格账本已填写，表演强度未超过证据强度；
- [ ] 本场信息差状态（悬念/共情/惊奇）已标注，镜头纪律符合对应行；
- [ ] 无预知脸：角色没有对未获知信息表露情绪；
- [ ] 无重复解释：同一谜底没有被镜头第二次向观众确认；
- [ ] 反应优先原则执行：默认镜头停在观察者身上，插入镜仅用于物理状态/可读信息/连续性必需；
- [ ] 关键提问通过「角色定义式」过滤，无投机性交代台词；
- [ ] 揭示顺序完整：证据 -> 消化停顿 -> 反应，无提前反应；
- [ ] 悬疑段验证后未立即解释机制。
