# 分镜场景一致性看守（scene-consistency）

> 子 skill：虾镜分镜流程上的**场景一致性闸门**。每次做分镜内容（规划/拆镜/11 字段/交付自检）时强制执行本流程，步骤不可跳、产物不可缺。

## 0. 定位与职责边界

| 本子 skill 管 | 不归本子 skill 管（归 continuity.md） |
|---|---|
| 每镜**场景归属正确性**（这镜动作/台词/道具发生在哪个场景，原文依据） | 同一场景**内部前后结构一致**（门窗/光源/干湿/破坏累积） |
| **场景资产完备性**（本集所需场景资产是否齐全，缺的补建） | 人物/道具/动作连续性（服装/伤情/视线/越轴） |
| 换景是否有**叙事依据**（场景切换的转场说明） | 时间天气连续性（由折线图辅助，主判定在本 skill） |

一句话：**scene-consistency 产出"空间真相"（每镜应在哪个场景），continuity.md 校验"场景内部前后一致"。先有真相，再查一致。**

## 1. 六步流程（强制顺序，一步不可跳）

### ⭐ 依赖链（★ 2026-08-31 用户拍板，最高纪律）

> **小说内容 → 场景资产图**；**小说内容 + 场景资产图 + 分镜内容 → 空间拓扑图** → 分镜 scene 从图取景。三向互参，不是平行孤立。

```
小说原文 ──→ ① 场景资产图（场景 prompt 必须按小说内容写，禁通用空镜）
小说原文 ──→ ② 空间真理图（原文空间证据 + 推断）
虾料空间链表 ──→ ② 空间真理图（★ 2026-09-03 集成：outputs/scene-chain.md 的主要空间/方向/因果直接引用，命名与场景资产规范名对齐）
场景资产图 ──→ ② 空间真理图（拓扑图提示词参考对应场景图外观/结构）
分镜内容 ──→ ② 空间真理图（哪些镜头用什么空间 → 拓扑图移动路径/分区）
空间真理图 ──→ 分镜 scene（第 2 步从图取景）
```

### 第 1 步 空间真理图（checkpoint A / 规划阶段必做）

0. **上游输入（★ 2026-09-03 集成）**：若项目存在 `outputs/scene-chain.md`（虾料空间链表），先读——本集涉及的主要空间、跨场景走向与因果衔接直接引用该表（空间命名与场景资产规范名对齐），不重复从原文推断跨场景关系；室内布局仍按本步 1-5 从原文建图。链上有而场景资产库缺失的空间 → 直接进补建清单。

1. 通读本集剧本原文，**逐段提取空间描写**（行号 + 原句），形成「原文空间证据清单」。
2. 原文有空间词 → **引用原句**，不得改写空间含义。
3. 原文沉默（没写空间）→ 按**动作语义推断**（躺床睁眼→卧房；从里屋追出→堂屋；看窗外→窗边），推断依据**必须写进图注**，可追溯、可反驳。
4. **参考对应场景资产图**（外观/结构/道具）→ 拓扑图的锚点（灶台/鱼筐/门/窗）与场景图一致；**参考分镜内容**（哪些镜头用什么空间）→ 拓扑图的移动路径/分区覆盖实际拍摄需求。
5. 产出《本集空间拓扑图》：各场景物理布局 + 角色初始位置 + 空间关系（床在哪/门在哪/屋与院关系/灶台在哪）。
6. 与场景资产库比对 → 缺的场景进「补建清单」（标注待补场景，**新场景 append 尾部，禁止插中间**，防图号连锁）。
7. 空间真理图**经用户确认后才生效**，它是本集唯一空间权威源。

模板见 `references/空间真理图模板.md`。

### 第 0 步 场景资产图按小说生成（★ 2026-08-31 用户拍板 · 前置规则，建场景资产时必做）

> 场景资产图不是"通用空镜"，是"**小说里的那个场景**"。xiatang 建场景资产 / 重生成场景图时执行：

1. 读该场景在**小说原文**中的全部描写（行号+原句）：结构（<墙体/屋顶/围合方式>）、关键道具（<原文明确的标志道具逐项>）、朝向（<门朝哪/主要外景在哪侧>）。
2. 场景 prompt **必须融入上述小说特定内容**，禁通用空镜模板（如"a few clay pots / a low wooden fence"——★ 某集实例教训：通用空镜与拓扑图多处对不上）。
3. 场景图与空间真理图互相校验（见第 6 步）——先有小说特定场景图，拓扑图参考它，两者一致。


### 第 2 步 从图取景（拆镜 / 写 11 字段时）

- 每镜填 scene 前必答：**"这镜机位在空间图哪个位置拍的？"** 答不出 → 回第 1 步补图。
- 不凭感觉、不默认第一个场景、不机械引用资产名。
- 人物位置/姿态在 visual/action 写清（站/坐/躺/走动，屋内/院中/门槛/窗边）。

### 第 3 步 三份可验证产物（全量交付前强制产出，缺一不可）

1. **原文-场景对照表**：每镜 scene + 原文依据（行号+原句）或推断依据（图注）。
2. **场景连续性折线图**：镜序 × 场景，沿时间轴画折线，场景跳变可视化（肉眼扫跳变合理性）。
3. **矛盾扫描报告**：跑 `scripts/check-scenes.py` 输出（**四查**：A 矛盾词 / B 场景不在资产库 / C 换景无转场依据 / **D 引用行完整性**——shot 带 video_prompt 时校验首行含「空间拓扑图」引用且在最后一位（顺序：角色→场景→道具→拓扑图）+ 含本段场景图引用）。

> 三份产物是**给用户独立复核的材料**，不是"AI 检查过的证明"。产物存在 = 错误无法藏进交付物。

### 第 4 步 独立空间审核（交付前单独跑一轮）

- **只审空间、不看剧情**，用 `references/场景一致性检查清单.md` 的问题清单单独过一遍。
- 单独一轮 = 不与镜头语言/金句/运镜等自检混查，避免"查剧情顺手扫一眼场景"的粗心。

### 第 5 步 闭环兜底

- 缺资产 → 第 1 步暴露 → 待补标注 → 规划阶段随检查点 A 一并给用户确认补建 → 资产就位后回填图号。
- 补建受阻 → **显式上报"本集空间不完整"**，禁止用近似场景静默硬压。

### 第 6 步 场景资产图一致性检查（★ 2026-08-31 新增 · 拓扑图确认后、首帧/视频制作前必做）

> 管"场景资产图 ↔ 空间真理图"这条链：拓扑图定了空间真相，**场景资产图必须与它对齐**，否则首帧/视频引用的场景图空间会错。

1. 遍历本集用到的每个场景资产图（xiatang scenes），对照空间真理图核对**关键锚点**：
   - 朝向要素：院门/屋门朝哪、窗朝哪、海/街在哪一侧（是否画出来）
   - 关键道具：剧本原文明确逐项列出（<道具1/道具2/道具3…>）
2. 发现缺失/不符 → **按剧本特定信息重写该场景资产 prompt**（融入拓扑图锚点 + 原文道具）→ 重生成该场景图。
3. **铁律：场景资产图必须与空间真理图对齐**；"通用空镜"不能替代"剧本特定场景"——★ 某集实例教训：场景图为通用空镜（缺关键地标/道具/朝向特征），与拓扑图多处对不上（通路缺失/灶台形态位置/标志道具缺失/围合方式不符）。
4. 重生成完成前，不得用旧场景图做首帧/视频（会带错空间）。


## 2. 铁律（违反即退回）

1. 原文有空间词必引用原句，不得改写空间。
2. 原文沉默的空间必须推断并标注依据，**禁止默认填第一个场景**。
3. 每镜 scene 必须能答出「空间图位置 + 原文/推断依据」两问。
4. scene 只能选自资产库真实场景；缺场景资产必须先补建，**禁止近似场景硬压**。
5. 三份可验证产物缺一不可交付。
6. 补建场景 append 尾部，禁止插中间（防图号连锁）。
7. 换景必须有叙事依据（角色移动/时间跳转），依据写入 narrative。
8. **最高纪律：本文件及 references/ scripts/ 禁止出现任何具体项目数据**（项目名/角色名/场景名/世界观词），示例一律用占位符（角色A / 场景X / {{项目名}}）。
9. **空间问答以权威源为准（★ 2026-09-01 事故固化）**：任何「某场景/某宅院的方位布局」描述性回答、生图提示词复述，**必须先读该集空间拓扑图定稿（space_map_prompt / 空间真理图）再答，禁止凭印象复述**——凭印象会把「东西三段式」说成「南北两段式」、把分间/门窗朝向说反、发明不存在的通路，用户照此生图即废；项目台生图按钮读的就是定稿字段，优先引导用户用按钮生成。

## 3. 与父流程（虾镜）衔接

| 阶段 | 动作 |
|---|---|
| checkpoint A 规划 | 第 1 步空间真理图 + 补建清单 → 随检查点 A 一并给用户确认 |
| 拆镜 / 写 11 字段 | 第 2 步从图取景 |
| 全量交付前 | 第 3 步三产物 + 第 4 步独立审核 |
| 场景资产就位后 | 第 5 步回填图号（append 尾部） |

## 4. 交付前自检（逐项打勾）

- [ ] 每镜 scene 在空间真理图中有对应位置
- [ ] 每镜 scene 有原文依据或推断依据（可追溯到行号/图注）
- [ ] 原文-场景对照表 / 场景连续性折线图 / 矛盾扫描报告 三产物齐
- [ ] 矛盾扫描报告问题镜 = 0，或已逐条给出处理结论
- [ ] 相邻镜场景跳变有转场依据（narrative 写明）
- [ ] 缺场景资产已补建，或已显式上报给用户确认
- [ ] **场景资产图与拓扑图对齐**（第 6 步：本集用到的场景资产图含拓扑图关键锚点——朝向/门/窗/原文道具，缺失已重生成）
