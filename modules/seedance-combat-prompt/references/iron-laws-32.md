## 七、切镜流畅度三法则
### 法则1：运动方向衔接
上一镜角色向右运动 → 下一镜角色也从左侧入画继续向右，保持运动矢量连续；需要越轴时，必须借反应镜/空镜/走位三步过渡，禁止硬切导致方向凭空反转。
### 法则2：动作弧线衔接
上一镜攻击动作的发力弧线未走完 → 下一镜沿同一条弧线延续（挥拳的回旋、踢腿的下落轨迹顺势接住下一招），让观众感觉"劲没断"；禁止在动作弧线中途硬切造成断劲、招式各打各的。
### 法则3：景别阶梯衔接
景别按"特写→近景→中景→全景"阶梯逐级过渡，禁止跨两级跳级（如特写直接切全景会丢失空间锚点）。近景→远景必须经中景过渡；远景→近景可两步压缩（突进/身法贴脸本身自带速度感）。

| **R28** | **闪避大幅化法则** | **闪避动作禁止小幅平移（如"侧身一让""微微侧移"），必须是大幅度身体运动：下潜贴地/后仰弯腰≥45°/后空翻/旋转闪避（身体360°旋转）/大幅度横移跳开等。闪避不是"不打了"，闪避是另一种形式的视觉动作——小幅度闪避=画面停滞，大幅度闪避=视觉亮点。爆款验证：白鸽Negativa极低位闪避标指（从站姿到贴地，高度差近1米），飞驰影漫社+废话军师联合改造后确认效果极好** | **P7·近景对招 / P4·三段运镜 / P2·力道优先** |
| **R29** | **招式复用规则** | **对战双方发生变化时，招式可以复用（因为对手不同，同一招打出来的视觉和节奏完全不同）；对战双方未发生变化时，招式禁止与之前重复（观众看同一组对战出现相同招式就是糊弄）。判断标准：两组提示词的"角色A VS 角色B"中A和B完全一致=同一对战，必须零重复；A或B任一不同=不同对战，允许复用** | **P6·攻防即叙事 / 角色辨识度** |
| **R30** | **镜头规格强制法则** | **提示词中每一次镜头描述必须包含完整规格：[景别]+[拍摄视角]+[角度]+[运镜方式]+[跟随目标]。景别必须明确（全景/中景/近景/特写四选一），拍摄视角必须明确（正/侧/斜/俯/仰五选一），角度必须具体（如"30°仰""90°侧""45°斜俯"），跟随镜头必须写明跟随目标（跟随哪个部位/哪个角色/哪个肢体）。禁止模糊镜头描述如"镜头拉远""镜头靠近""跟随拍摄"——必须写成"中景·45°斜拍平视·跟拍跟镜跟随芭乐腰部横向平移"。镜头必须有目的性：①正常速度对招→中近景侧面带移动感（聚焦手法变化）②蓄力大前摇→仰视慢推（突出威力）③快速攻防→斜角+方向移动（镜头配合显速度）④特写→破绽/转折点过渡（情绪标点）。⚠️空间感铁律：中景及以上（看到两人完整身子）禁止使用侧面90°正拍（=格斗游戏无空间感），必须用30-60°斜角制造纵深** | **P3·节奏呼吸 / 完播率·运镜丰富度** |
| **R31** | **旋转运镜禁令** | **成品提示词中禁止使用360°环绕运镜和螺旋上升运镜。这类旋转运镜在实际生成中极易导致画面眩晕、观众失去方向感，尤其在三人同场时更严重。近景对招段应优先使用小幅度线性运镜：急速横移跟拍/急速推镜/跟拍跟镜/震镜/快切/慢镜头随动；终结爆发段应优先使用急速后拉跟镜→定格定镜或低仰推镜→定格，不要用螺旋上升。环绕运镜仅在对峙蓄力段（无攻防接触时）可谨慎使用半圈（≤180°），禁止满圈360°。用户实战反馈：线性小幅度运镜的画面清晰度和打击感远优于旋转运镜** | **P3·节奏呼吸 / 完播率·运镜丰富度** |
| **R32** | **特效服从角色主色法则** | **招式库中录入的特效建议（如金棕/土黄/深棕/金光等）是该武学的原始配色，仅作参考。当角色绑定该武学后，生成提示词时所有特效必须服从角色主色，禁止混入与角色主色冲突的颜色。例如：白鸽=紫黑色气焰，少林旋风地堂腿原始配色是土黄/金棕，但白鸽使用时必须全部替换为紫黑系（紫黑新月腿风、紫黑弧刃、紫黑旋转光柱等），禁止出现金棕/土黄/金光；红茶=橙红火焰，太极=黑白阴阳，凛羽=冰蓝银白霜雾，雷电=纯紫/银紫电弧。判断标准：提示词中任何一个特效颜色必须能在角色卡"劲气颜色"一栏找到归属，找不到归属的颜色一律删掉** | **角色辨识度 / 视觉统一性** |
