# 对白表演时序 · 可执行规格（横切单源）

> 适用：xia-boss 一切有台词的表演环节——质问、反驳、表白、分手、道歉、审讯、法庭压迫、家庭对峙、语音留言、电话、以及任何「一句台词击穿情绪防线」的段落；虾镜 shots[] 台词字段转写、听风分镜、H3/视频提示词、打戏喊话段。
> 性质：通用方法论，禁止出现任何具体项目数据；示例一律占位符（角色A / 角色B / 台词示例）。
> 来源：从「影词精磨」（cinematic-video-prompt-engineer v1.5.0）style_patterns.md 蒸馏——Dialogue-Driven Performance Control System / 30s Psychological Stage Timeline / Interrupted and Overlapping Dialogue / Dialogue Playability Audit（2026-09-05 采纳，通用化改写）。
> 分工（台词三兄弟，互不替代）：
> | 规范 | 管什么 |
> |---|---|
> | shared-dialogue-doctor | 台词**好坏**（七维诊断与重构） |
> | shared-duration-control | 台词**长短**（语速公式与时长预算） |
> | **本规范** | 台词**怎么演**（表演时序、声线连续性、抢话重叠、听者双轨） |
>
> 三者同一口径：doctor 维度 6 的「语速/气口」一律走 duration-control 公式；本规范的「可播放性审计」是**表演可行性审计**，不覆盖公式结果，只在其基础上检查表演能否落地。

**★ 通用纪律（与 shared-duration-control 的接口）**：本规范所有时码示例（如 `3.5-12.0s`）均为**单组内相对区间**，落分镜表时按 duration-control 换算（组内 `00:00` 起排、首尾相接零缝隙、格式 `0.0–4.5s`）；**单组 ≤15s 是 P0 硬约束**——密集对白若撑满 15s 仍装不下，按情绪阶段边界拆组而非均分，跨组锁死「情绪只推进不重置 / 贯穿手势与关系边界继承 / 声线与临时状态继承」，并让台词用受控 `L-cut/J-cut` 跨组桥接（见 §九）。

## 〇 三层提示结构（写复杂对白戏前先分层）

1. **全局控制层**：时长、地点、人物、身份锚点、服装、声音模式、整体视觉风格、平台约束。
2. **镜头时间轴层**：哪个镜头覆盖哪几秒、观察谁、何时换视角/焦点、为什么换。
3. **表演控制层**：这句台词里角色要什么、情绪怎么变、哪个词触发变化、停顿呼吸落在哪、眼脸身体如何响应、哪个反应**不能**提前发生。

**禁止让第 1 层吃掉整条提示词的预算**。平台已提供风格预设时，风格保持紧凑，把字数花在表演控制上。

## 一、场景级表演契约（写面部节拍之前先定一句）

用一句话定义表演逻辑——这是**契约**，不是主题：

- 每个角色此刻要从对方那里得到什么；
- 哪种保护性行为让他们还能继续运转（愤怒/礼貌/否认/幽默/照顾/控制/语速）；
- 若停止说话或失去这层保护，他们害怕发生什么；
- 这些如何塑造声线、视线、停顿、距离与伴随动作。

示范（占位符）：

```text
这不是舞台式展示悲伤。角色A越说越快，不是为了攻击对方，而是害怕一停下来就再也说不完；角色B保持礼貌和低声，不是冷漠，而是用照顾对方来阻止自己当场瓦解。后续台词、眼神、呼吸和动作都服务于这组心理机制。
```

契约**只说一次**，之后通过可见行为表达；禁止在每个节拍下重复解释。

## 二、声线身份与临时声音状态（连续性锚点）

声音是角色连续性的一部分，**不是通用音效**。

**锁定稳定声线身份**（对白戏必写）：声线年龄感与性别呈现；音域/音区、质感、共鸣与习惯语流；口音/方言仅当用户要求或设定必需；每个说话者的相对音量与空间位置。

**临时声音状态**与永久身份分开记：疲惫、沙哑、刚哭过、喉咙堵塞、气短、疾病、冷空气、压抑恐慌；以及压力下声音如何改变——音域变窄、语速加快、辅音变硬、气息失守、句尾失去支撑。

铁律：这些锚点**跨镜与跨续写段保持**。禁止声音在无意间变年轻、变干净、变响、换口音或变成棚录质感（与 shared-performance-realism §六 摄影条件一致同律；与 shared-evidence-control 的知识账本无关但同属连续性族）。

## 三、嵌套时间与双表演轨

**先建镜级时间轴**，只把承载密集对白/多个触发词/重大情绪裂缝的那一镜细分为表演节拍。

- 主级时间轴回答：哪一镜、谁的脸、为什么换视角；
- 次级时间轴回答：这一镜内部表演如何发展；
- 简单反应镜保持简单，**禁止把每镜都机械切成半秒指令**；
- 所有次级区间必须落在父镜头范围与台词时长预算内（以 shared-duration-control 为准）。

```text
SHOT 2（3.5-12.0s）：角色A肩后越肩近景，承担主要反击与防线破裂。
3.5-7.0s【反击】：...
7.0-9.5s【自证】：...
9.5-12.0s【裂缝】：...
```

**说话者/听者双表演轨**：

| 轨 | 内容 |
|---|---|
| **说话者轨** | 意图、保护性情绪、触发词、声音、面部、呼吸、手势、句后残留 |
| **听者轨** | 哪个词真正命中、延迟的生理/面部反应、是否尝试打断、压抑了什么 |

- 听者内心变化推进故事时才给反应镜；说话者仍占戏剧中心时保持克制；
- **禁止写"他沉默"这类空泛反应**——应写出可见序列：防御 → 试图回应 → 吞咽 → 视线回避 → 意识到；
- 三种触发类型按需混用：**说话者触发**（某词改变说话者自己的表情/声音/呼吸/意图）、**听者触发**（听到某词后延迟反应）、**打断触发**（听者预判句子走向，在未说完前进入）；
- 听者**不得**在相关词或含义到达之前显示最终反应（与 shared-evidence-control §六 揭示顺序同一口径）。

## 四、抢话与重叠对白规格

适用于争吵、恐慌、亲密对峙、家庭冲突、审讯、医疗急救，以及任何「话轮本身承载情绪」的场景。

每次重要打断/重叠必须定义这六项控制表演的要素：

1. **进入触发点**：让第二说话者进入的那个词、未完成的音节、手势或被推断出的意图；
2. **进入动机**：否认、安抚、害怕失去说话机会、纠正、自我保护、试图阻止一句痛苦的话；
3. **重叠层级**：谁先开始、谁是前景、相对音量、第二声音是支撑/竞争/温和接管；
4. **让出行为**：谁退让、在下方继续、改口、还是再也要不回话轮；
5. **被打断者状态**：保留未完成的口型、屏住的呼吸、失败的吸气、视线，或正在进行中的手部动作；
6. **声音空间连续性**：说话者身份、左右位置、距离、房间反射与口型动作各自独立且稳定。

示范（占位符）：

```text
角色A听见对方说到"我已经决—"便意识到他要结束关系，未等尾音完成就低声抢入："你先听我说。"两人声音自然重叠约半拍；对方的声音不会突然静音，而是在角色A台词下方失去力度后停住，嘴仍保持未完成口型。角色A不是提高音量压过他，而是因害怕失去表达机会而加快；随后对方退让，目光落下。
```

**规则**：
- 优先用**语义触发**与自然的近似重叠，不要做百分之一秒级的微观管理；
- 禁止把重叠变成干净的轮流对白、等音量齐说，或一方非自然静音；
- 切镜后禁止双方各自重说完整句子——跨镜切分必须显式写成「起句片段 + 延续片段」；
- 重叠要克制到说话者身份与口型仍可读。

## 五、保护性口误（有意的不流畅）

以下不流畅是**表演信息**，不是生成缺陷：结巴或重复代词起头；嘴里有形却无声的词；说话前失败的吸气、吞咽或喉咙闭合；自我修正、放弃句式、改说更安全的句子；被打断后无法干净重启；因停下来会导致情绪崩塌而短暂加速。

使用时必须写明**心理原因**与**可见/可听证据**，并明确保护它不被自动顺滑、重排、补全或改成棚录式干净表达。

示范（占位符）：

```text
说"我—我本来……"时并非喜剧口吃：第一个"我"有声音，第二次只形成口型并伴随失败吸气，喉结轻动后吞咽；放弃原句，改成更安全的"你别担心"。不要补全被放弃的句子，不要机械等间隔重复。
```

**禁止**：喜剧化口吃、节奏化循环、音频故障、嘴部冻结、无动机的重复音节；每句都带吞咽/眨眼/失败呼吸/重复词；流畅表达更贴人物时仍强行加口误。

## 六、台词可播放性审计（表演可行性，非字数审查）

**前置声明（与 `shared-duration-control.md` 语速公式的优先级）**：语速公式（三档语速 + 判定区间 + 金句气口）是**时长的最硬约束，优先于本审计**——台词必须先过公式判定 ✅，本审计只在其**通过之后**检查"这段表演能不能自然演出来"。

台词字数与平均语速是**风险信号，不是硬上限**。当急促、打断、重叠、情绪紧迫就是预期表演时，不要自动删减密集对白。本审计反对的是**一刀切的全局字/分钟删减法**——`shared-duration-control.md` 的三档语速（标准/慢速重音/快速爆发）本身就是分档而非一刀切，与其同一口径。

审计实际可播放时间线：

- 每个短语的局部语速，包括有意的加速与减速；
- 同时说话，以及重叠真正省下的墙上时间；
- 停顿、失败起句、呼吸、吞咽、哭泣与沉默；
- 必须保留可见的听者反应；
- 需要上镜的口型关键句；
- 换镜、调度、手部动作与结尾余韵在抢同一段时间。

若台词顺序、口型、情绪转折、反应与结尾仍能自然演出，则**完整保留对白**；禁止把情绪紧迫的交流归一化成一个全局字/分钟值。

**时间紧张时的简化顺序**（删台词是最后一步）：

1. 删除装饰性运镜与非必要换镜；
2. 减少次要手势、重复微表情与环境动作；
3. 用受控的 `L-cut/J-cut` 让台词跨反应镜延续；
4. 保留有动机的重叠与局部加速；
5. 此时若仍有冲突，才说明风险并建议拆分或请求用户批准改词。

- **禁止静默删除改变剧情或定义角色的台词**；
- 反之，也**不得因为用户想要每一句就宣称可以播放**——慢速、长停顿、多次失败起句、复杂调度与反应保持造成真实冲突时，必须指出风险并建议拆分。

## 七、场景优先级阶梯（有冲突时按此取舍）

只在有助于解决指令冲突时写一句短阶梯：

```text
对白主导：台词顺序、说话者身份、口型、抢话与声音表演 > 听者反应 > 连续手势与视线 > 镜头装饰与环境细节。
动作主导：动作因果、空间方向、接触和重量 > 身体反应 > 镜头跟随 > 台词与环境装饰。
情绪特写：心理变化、微表情和呼吸 > 声音与泪水时机 > 光影连续 > 背景运动。
```

两条指令冲突时，简化**低优先级**的那条。优先级阶梯**不是**忽略连续性、安全红线或用户明确必需要素的许可。

## 八、连续手势与关系边界

用一个反复出现的手、道具、姿态或距离变化作为关系的**连续表演线**：

```text
右手跨三个镜头完成"抬起 -> 悬停 -> 失去力量 -> 落下"，切镜后不得重新抬手。两人始终相距约一米；不触碰不是普通禁令，而是当前关系无法靠近的可见边界。
```

必须锁定：谁可以进入谁的空间、是否允许触碰、靠近/退后/克制接触各自意味着什么。**禁止**模型自行加入拥抱、牵手、亲吻或和解从而改变场面的关系状态（与 shared-performance-realism §十二 贯穿动作锚点同源，与 shared-spatial-blocking 空间距离约束咬合）。

## 九、跨镜台词与语义剪辑点

让台词与剪辑共用一套情绪语法：

- 台词可以作为画外音跨反应镜延续；当听者的脸比说话者的嘴更重要时，使用有动机的 `J-cut`、`L-cut` 或声音桥；
- 跨镜保持声音方向、房间反射、距离与说话者身份一致；
- **按语义事件切镜**：触发词落地、句子含义改变、声音第一次破裂、听者被击中、脆弱的短语被咽回去；
- 句子结构暗示了更强的剪辑点时，**禁止按时长均分**对白镜头；
- 不牺牲口型清晰度：口型承载节拍时让说话者在画内；只有当听者反应承载更多戏剧信息时才转为画外。

## 十、有意未完成的台词

当角色无法继续、被打断、放弃句子或故意拒绝说出最后想法时，未完成的台词可以是**完整的戏剧动作**。

安全用法：

- 标明台词停止的心理或人际原因；
- 说明最后的声音是渐弱、被另一个声音切断、失败呼吸后消失，还是只留下口型；
- **禁止模型补全或说出缺失的词**；
- 用保持住的口型、呼吸、视线、听者反应、手部状态或沉默呈现后果；
- 留出足够可读的余波，让结尾显得有意而非技术性截断。

**禁止**用最后一个时间戳上的破折号充当结尾。若表演后果没有跟上，就把台词提前说完或重设计结尾。

## 十一、景别随防御层级递进

让景别随角色心理防线的打开而收紧：

- 角色仍在争辩、解释或维持控制时（**防御期**）：保持**中近景 MCU / 近景 CU** 或越肩构图；
- 只有当保护层出现裂缝、承认隐藏真相、声音破裂或最脆弱那句开始时，才进入**特写 BCU / 极特写 ECU**；
- 场景后期还需要视觉升级时，**禁止**起手就用最紧的景别；
- 每一次推进或收紧，都必须绑定一个具体的情感可及点，而不是笼统的"强度"。

（景别英文缩写与 xia-boss 中文九档的对照表见 `shared-performance-realism.md`「通用纪律 §4」；**分镜表与交付物一律写中文九档**。）

**情绪保护层**——禁止从愤怒直接跳到哭泣、从自信直接跳到崩溃、从讽刺直接跳到坦白：

```text
愤怒保护悲伤 -> 声音破裂 -> 攻击消退 -> 脆弱出现
讽刺保护羞耻 -> 笑容僵住 -> 视线落下 -> 道歉成为可能
平静保护恐慌 -> 呼吸变短 -> 语速变慢 -> 身体冻结
礼貌保护怨恨 -> 停顿变利 -> 嘴角收紧 -> 直接指控
```

提示词写法：`先写保护性情绪，再写保护层出现裂缝，最后写真实情绪暴露。不要让愤怒、悲伤和落泪同时从第一秒出现。`

## 十三、自检清单（对白戏交付前）
