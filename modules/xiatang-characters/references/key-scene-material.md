# 关键场景素材规范（画面素材 · 独立 Tab · 独立调度文件）

> 来源：虾塘「关键场景图片提示词规范」+ 剧本转分镜关键场景图片提示词（§14），2026-08-21 提取为独立文件。**产出关键场景素材提示词时，加载本文件。**

## 0. 定位（★ 素材，不是资产）

**关键场景 = 画面素材【不是资产】**：它是**剧情画面素材**（名场面/转折点/高潮/结尾的代表性画面），供创作参考、封面海报、宣传物料使用。

- **独立于角色/场景/道具资产**：不参与资产引用体系（不被分镜当锚定图引用）。
- **可含人物**：不受场景空镜铁律约束（场景空镜铁律只约束"场景域"资产）。
- **独立 Tab**：在虾塘资产区有独立 Tab「关键场景」展示素材卡片（图 + 12 字段提示词 + ★ 海报候选标记 + 关联镜头）。
- 每集/每章产出 3-10 张。

**挑选规则**：每集/每章从以上 11 类中挑选 3-10 张（同一画面可对应多类，选覆盖度最高的）；**必须覆盖**开场、主角登场、高潮、结局四类基础项。

## 2. 12 字段提示词结构（★ 每张关键场景按此结构产出）

1. 风格与质感（画幅/机型号/镜头/颗粒/整体真实）
2. 镜头参数（景别/焦段/光圈/机位高度/距目标/平仰俯/景深/焦点）
3. 构图（三分/对称/中心焦点/引导线 + 用途）
4. 色彩（主色/辅助色/强调色/色调/光源）
5. 光源（主光/辅光/轮廓光 + 动机）
6. 场景空间（场景名 + 空间描述 + 元素位置）
7. 人物位置与动作（谁在哪/什么姿势/视线）
8. 情绪（画面情绪/人物状态）
9. 前中后景（前景/中景/后景各是什么）
10. 材质/天气/空气（材质质感/时间天气/空气状态）
11. 负面限制（不改变人物形象/不出现文字/不用廉价滤镜/不过度锐化等）
12. 关联镜头（对应分镜镜头编号，供回溯）

## 3. ★ 海报候选标记

适合做海报/封面/宣传物料的画面标注 **★ 海报候选**，Tab 卡片角标高亮、优先展示。

## 4. 数据契约

- 数据落点：`outputs/key-scenes/*.json`，每文件一个素材，字段：`name`（素材名）/ `desc`（描述）/ `prompt`（12 字段提示词，可为对象或字符串）/ `image`（图 URL）/ `poster`（布尔，true=★海报候选）/ `shot_ref`（关联镜头编号）。
- build-data-js.py 读取为 `xiatang.key_scenes`（自动补 image/image_ready 按 `project/assets/key-scenes/` 文件存在判定），前端虾塘「关键场景」Tab 展示（素材卡：图 + 名称/描述 + ★ 标记 + 关联镜头 + 12 字段提示词一键复制）。
- 图片落盘：`project/assets/key-scenes/`（上传/生成后自动标记 image_ready）。
