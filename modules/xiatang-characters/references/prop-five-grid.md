# 道具五宫格模板（道具参考图固定格式 · 独立调度文件）

> 来源：虾塘「道具资产五宫格模板」+ 剧本转分镜关键道具资产图规范（§12），2026-08-21 提取为独立文件。**产出道具参考图提示词时，加载本文件。**

## 0. 定位

每个道具参考图按 **5 宫格** 生成：一张图含 5 个视图，排列 **上 2 下 3**。同一道具五格结构、比例、材质、细节完全一致。

## 1. 五宫格布局（固定，上 2 下 3）

```
┌─────────┬─────────┐
│  ① 正面  │  ② 背面  │  ← 上排 2 格
├─────────┼─────────┼─────────┤
│③ 左侧面 │④ 右侧面 │⑤ 材质特写│  ← 下排 3 格
└─────────┴─────────┴─────────┘
```

- **五视图**：① 正面（主视角，正对镜头）② 背面 ③ 左侧面 ④ 右侧面 ⑤ 材质细节特写（结构/材质/纹路/使用痕迹）。
- 禁止仅给俯视/仰视；禁止只给单图。

## 2. 道具资产 10 项硬性要求（★ 每张道具资产图必须全部满足）

1. **纯中性背景**：无场景、无氛围装饰。
2. **无人物**：画面中不得出现任何人物（含手持/佩戴演示）。
3. **无无关物体**：除道具本体外不出现任何无关物体。
4. **无文字**：不出现任何文字、标注、标签。
5. **无水印**：不出现水印、logo、签名。
6. **比例统一**：五格中道具比例一致，透视合理。
7. **结构明确**：结构清晰完整、可辨认，功能部件可见。
8. **材质真实**：材质表现真实（金属/木质/布料/宝石等各有质感），无塑料感。
9. **功能逻辑合理**：结构符合功能逻辑（能装、能开、能握的部分在图中自洽）。
10. **使用前后状态连续**：使用前/使用后状态一致（如"完好的剑 → 崩口的剑"在材质细节特写格体现变化轨迹）。

**禁止**：不得出现与时代、地域或世界观冲突的设计（如仙侠世界的道具出现现代工业元素）。

## 3. 道具条目结构（沿用原结构）

道具设定 = 名称 + 功能/叙事作用 + 关键状态（+ 使用前后变化轨迹）。

- **制作优先级**：⭐⭐⭐ 主角核心道具/反复出场/特写多；⭐⭐ 重要配角道具；⭐ 背景道具/一次性/远景即可。
- 同一道具被多角色使用 → 只建一个道具条目，所有角色【关联道具索引】指向同一编号（防一把剑被设计成两个样子）。
- **识别/连续性锚点（★ 2026-09-03 集成）**：每条 ⭐⭐ 及以上的道具登记锚点字段 `continuity_anchors`（数组）——缺口/划痕位置、文字或图案及其**方向**、左右非对称结构、绑带/握持/接触点、颜色分布等**跨镜头必须对得上的识别信息**；锚点值必须进入提示词中文描述段（如"刀身近护手处一道斜向崩口、缠绳自左向右"），禁止只写"有磨损"这类不可定位描述。
- **剧情锁定状态（★ 2026-09-03 集成）**：条目标注 `story_state`——该道具在当前生产节点处于状态轨迹的哪一档（如"完好" / "已崩口" / "已转手"）；出参考图按**当前档状态**生成，状态推进时登记新档并按需补图，**禁止用终态图冒充早期状态**（与状态变化轨迹规则同构，跨镜连续性由锚点保证）。

## 4. 提示词结构（★ 固定「产品特写」写法，2026-08-19 用户拍板 + 五宫格扩展）

道具提示词结构 = **英文风格段 + 「产品特写，」开头的中文描述段 + 负面段**（FORBIDDEN + 中文控噪「无乱码文字水印」）。

- **英文风格段**：画幅/摄影机质感/镜头质感/胶片颗粒/材质真实/整体真实。
- **中文描述段**（「产品特写，」开头）：五宫格布局（上 2 下 3：正面/背面/左侧面/右侧面/材质细节特写） + 五视图内容（材质/结构/光效/氛围） + 镜头参数（正面/背面/侧面 50mm f/4 或 35mm f/2.8，材质特写 85mm f/1.8，主光源带色温）+ shot on Sony A7R V。
- **负面段**：FORBIDDEN 内容 + 中文控噪「无乱码文字水印」。
- 提示词内**必须显式写出视角词**（正面/背面/左侧面/右侧面/产品特写），禁止不指定视角让模型自由发挥。
