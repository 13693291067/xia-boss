# 90秒情绪节拍强制结构与情绪递增规则

## 一、最高执行原则：情绪优先，剧情承载情绪

每一集都必须以一个明确的"核心情绪"作为牵引。

核心情绪可以是：委屈 / 压迫 / 心疼 / 愤怒 / 羞辱 / 恐惧 / 不甘 / 窒息 / 失望 / 愧疚 / 怀疑 / 背叛感 / 绝望中的希望 / 希望再次破灭 / 被逼到极限后的反击。

创作时必须先明确：

1. 本集主要让观众替谁难受
2. 本集主要让观众恨谁
3. 本集让观众最期待什么
4. 本集在哪一刻给观众希望
5. 本集在哪一刻打碎希望
6. 本集最后留下什么情绪

所有剧情、动作、台词和反转，都要服务于本集核心情绪。

禁止：
- 只堆事件、不产生情绪
- 人物争吵很激烈，但观众不知道为什么要在意
- 只有大喊、大哭、大动作，却没有人物关系、现实代价和情感刺点

## 二、核心执行目标（每集必须同时做到）

1. 前3秒直接出现强冲突
2. 前10秒建立观众情绪立场
3. 每10秒至少发生一次情绪变化
4. 每次情绪变化必须由具体事件触发
5. 情绪必须逐步递增，不能原地重复
6. 冲突必须影响人物关系、利益或命运
7. 人物必须通过行动和选择推动剧情
8. 台词必须短、准、狠、有潜台词
9. 动作和微表情必须具体可拍
10. 结尾必须达到本集最高情绪点
11. 不出现剧情断层
12. 不出现AI味、模板味、口号味
13. 不用无意义反转欺骗观众
14. 不让人物为了推进剧情突然降智

每一集不能只是剧情概述，必须写成真正的可拍摄剧本。

## 三、90秒情绪节拍强制结构

"有效情绪变化"不是换一个人说话，而是以下内容发生改变：人物关系改变 / 主动权改变 / 信息改变 / 风险改变 / 希望出现或破灭 / 人物立场改变 / 人物被迫作出选择 / 代价进一步增加 / 某句台词刺中软肋 / 某个动作暴露隐藏情绪 / 某件物证改变现场判断。

### 3.0 颗粒度三档（先选档，再填内容）

| 档位 | 段数 | 换挡次数 | 适用 |
|------|------|----------|------|
| **混合颗粒度（默认推荐）** | 9 段 | 9 次 | 绝大多数循环；开场密、中段宽、结尾最碎 |
| 15 秒档 | 6 段 | 6 次 | 纯文戏 / 纯奇观 / 纯高手博弈 / 120 秒以上长循环 |
| 10 秒档 | 9 段 | 9 次 | 快剪打斗 / 高密度爽点段 |

**混合颗粒度节拍表（默认）**：

| # | 时间 | 时长 | 节拍功能 |
|---|------|------|----------|
| 1 | 0—3 秒 | 3 | 强冲突爆开（抓人生死线，不变） |
| 2 | 3—12 秒 | 9 | 情绪立场（给反应留半拍） |
| 3 | 12—27 秒 | 15 | 压迫升级（大场面/群像铺陈） |
| 4 | 27—42 秒 | 15 | 关系刺痛（微表情与停顿需要呼吸） |
| 5 | 42—55 秒 | 13 | 主角行动（动作连贯性） |
| 6 | 55—65 秒 | 10 | 短暂希望（希望不能拖） |
| 7 | 65—75 秒 | 10 | 希望反压 |
| 8 | 75—83 秒 | 8 | 代价选择（选择要快，收紧） |
| 9 | 83—90 秒 | 7 | 最高情绪点（最碎，快切+特写堆叠） |

**为什么这样分**：10 秒档的痛点是"装不下"——VFX 长镜需 3~4 秒完整展示、一轮完整台词交锋需 5~6 秒、微表情沉淀需 2 秒，硬塞进 10 秒必然超载。全线改 15 秒的痛点是"换挡少了 3 次"，密度掉 33%，开头结尾松垮。混合颗粒度两头都不丢：中段多出的 5 秒正好补上可拍性缺口，开场 3 秒与结尾 7 秒反而更紧。

**分档可混用**：同一集内不同循环允许不同档位（如快剪循环 10 秒档、文戏循环 15 秒档、奇观循环混合）。以下功能说明按节拍列，不绑定具体秒数。

### 0—3秒：强冲突爆开

直接出现本集最刺眼、最伤人或最危险的瞬间。必须让观众立刻产生至少一种情绪："凭什么？" "怎么会这样？" "他怎么能这么做？" "她接下来怎么办？" "这件事还有隐情。" "赶紧反击。"

禁止温和进入。

### 3—10秒：建立情绪立场

迅速让观众知道：谁正在被伤害 / 谁掌握主动权 / 主角为什么不能直接离开 / 这件事对主角意味着什么。

优先通过动作、物件、关系和现场反应表达；不能用大段台词解释前因后果。

### 10—20秒：第一次压迫升级

反派或现实规则进一步压缩主角空间。升级方式：当众羞辱 / 拿出规则 / 亮出身份 / 切断退路 / 牵连亲人 / 扣上罪名 / 提高代价 / 逼签字 / 逼承认 / 让旁人开始怀疑主角。

这一阶段必须比开场更难处理，不能只是继续争吵。

### 20—30秒：人物关系刺痛

让冲突从"事情"进入"关系"。例如：最信任的人沉默 / 亲人没有替主角说话 / 爱人选择自保 / 配角为了利益倒向反派 / 主角发现自己被提前放弃 / 一句旧承诺被现实打碎 / 对方用主角最在意的人施压。

这一段要让观众产生心疼、失望或愤怒。

### 30—40秒：主角第一次行动

主角不能一直被动挨打，必须作出第一次有效行动：拒绝签字 / 抢回关键物品 / 当场追问漏洞 / 保护弱者 / 拿出部分证据 / 利用规则反问 / 拆穿一句谎话 / 阻止反派继续伤害 / 主动承担某种代价。

这次行动不一定成功，但必须体现人物性格和能力。禁止主角只说狠话，不做任何实际行动。

### 40—50秒：短暂希望或局势松动

现场必须出现一次"似乎有转机"的变化：有人开始相信主角 / 一份证据被找到 / 反派的话出现漏洞 / 关键人物赶到 / 某个目击者开口 / 主角暂时夺回主动权 / 对方被迫停手 / 某项规则对主角有利。

让观众短暂松一口气，但希望不能持续太久。

### 50—60秒：希望被反压

反派必须做出聪明、合理且有效的反制：证据被判无效 / 证人临时改口 / 反派拿出更完整的材料 / 主角的弱点被抓住 / 主角行动牵连无辜 / 对方利用规则反锁主角 / 主角信任的人被迫站队 / 关键物品被调包 / 主角发现自己早已在局中。

反派不能靠吼叫压住主角，必须有利益、有准备、有手段。这一阶段的情绪必须比前面更沉。

### 60—70秒：情绪撕裂或真相加深

本集最重要的人物关系或内心矛盾必须在这里被撕开：主角知道亲人隐瞒了什么 / 反派说出一部分真实动机 / 主角发现自己保护的人并不信任自己 / 一个善意选择造成严重后果 / 某人终于承认自己曾经放弃主角 / 主角必须在两个人之间作出选择 / 主角若反击就会伤到无辜者。

这一阶段不能只增加信息，还要增加情感代价。

### 70—80秒：主角被逼作出不可回避的选择

主角必须面对一个有代价的选择：保住自己还是保护别人 / 保住关系还是揭开真相 / 暂时低头还是承担后果 / 交出证据还是失去亲人 / 说出秘密还是继续被误解 / 接受条件还是彻底翻脸。

选择必须符合人物设定；不能为了制造爽点让主角毫无代价地解决问题。主角作出选择后，局势必须发生明显改变。

### 80—90秒：最高情绪点与强结尾

最后10秒必须达到本集最高情绪强度。结尾必须是以下之一：

**强视觉**：门被撞开 / 血迹出现 / 文件被当众展开 / 屏幕弹出新的判定 / 关键物品从包里掉出 / 灯光突然熄灭 / 监控画面开始播放 / 某人摘下面具或露出身份 / 危险人物出现在门外 / 主角亲手毁掉某件重要物品

**强冲突**：主角当众拒绝 / 亲人关系彻底撕开 / 反派下达最终命令 / 主角被当场带走 / 两个重要人物正式站到对立面 / 主角承担选择带来的第一重代价 / 某人公开指认主角 / 主角将证据摆在所有人面前

**强悬念**：真相只揭开一半 / 证据指向另一个熟人 / 人物说出一句改变局势的话 / 主角发现真正的目标不是自己 / 某个已经离开的人突然出现 / 物证上的名字与预想不同 / 主角发现事件比本集冲突更大

结尾必须来自本集已经铺垫的矛盾。禁止为了悬念临时塞入毫无铺垫的新人物、新身份或新设定。

## 四、情绪递增硬规则

### 4.1 每10秒的情绪不得重复

错误示例（无效情绪）：生气 → 继续生气 → 更加生气 → 大吵 → 继续争吵。

正确示例：
- 0—10秒：措手不及
- 10—20秒：被当众羞辱
- 20—30秒：最信任的人沉默
- 30—40秒：主角压住委屈反问
- 40—50秒：证据出现，燃起希望
- 50—60秒：证据被反派反用
- 60—70秒：主角发现亲人参与隐瞒
- 70—80秒：主角被迫做出选择
- 80—90秒：选择引发爆炸性后果

### 4.2 情绪必须有因果关系

每一段情绪必须由上一段剧情推动。不能突然：从悲伤变愤怒 / 从怀疑变信任 / 从敌对变和解 / 从懦弱变强硬 / 从绝望变自信。必须有具体触发点。

示例：△ 她原本还想解释，直到看见母亲也在那份放弃声明上签了字。——这一动作才可以推动她从"委屈"进入"被背叛后的冷静"。

### 4.3 情绪升级必须提高代价

后面的冲突必须比前面的冲突更严重。升级顺序可以是：

言语压迫 → 身份压迫 → 关系背叛 → 利益损失 → 亲人受牵连 → 主角被迫选择 → 选择产生不可逆后果

禁止整集只围绕一句话反复争论。

### 4.4 情绪不能只靠哭和喊

情绪优先通过以下方式呈现：把话咽回去 / 手停在某件物品上 / 下意识护住某个人 / 悄悄收起证据 / 不敢看对方 / 把称呼改掉 / 把原本递出去的东西收回来 / 擦掉某个名字 / 明知受伤仍然保持礼貌 / 在所有人沉默时独自站出来 / 对方离开后才松开攥紧的手 / 嘴上答应，动作却暴露真实选择。

哭可以出现，但必须有前面积累。大喊只能用于真正的情绪爆发点，不能从头喊到尾。

## 五、情绪钩子设计要求

每集至少要设置以下三类钩子：

### 1. 开场钩子

让观众立即产生情绪和问题。例如："为什么所有人都在逼她签字？" "这个父亲为什么不敢认自己的孩子？" "医生为什么明明有床位却不救人？"

### 2. 中段钩子

在30—60秒之间打破观众原有判断。例如：原以为帮助主角的人其实参与了设局 / 原以为是钱的问题，实际是身份问题 / 原以为证据能救主角，实际证据本身就是陷阱 / 原以为反派只是恶，实际反派掌握真实把柄 / 原以为主角被冤枉，实际主角确实隐瞒了一部分事实。

中段反转必须改变情绪方向，不能只增加一条无关信息。

### 3. 结尾钩子

让观众产生强烈的继续观看需求。结尾应让观众想知道：主角会如何承担选择代价 / 某人为什么背叛 / 真正的幕后者是谁 / 关键证据到底证明了什么 / 主角是否会失去最重要的人 / 反派的下一步会造成什么后果 / 主角刚刚做出的决定是否正确。
