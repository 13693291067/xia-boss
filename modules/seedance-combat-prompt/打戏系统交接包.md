## 5. 角色核心铁律

### 5.1 540°方向R540°必须写成：

```text
水平旋身 / 如陀螺横转 / 水平面旋转
```

禁止写成：

```text
竖向翻腾 / 后空翻式旋转 / 垂直翻转
```

### 5.2 凛羽70/30法则

凛羽不是纯柔术家。

```text
形意拳+八卦掌 = 主旋律70%
擒拿/柔道/合气道/柔术 = 破招插入30%
控制是中间态，不是终招。
```

凛羽正确逻辑：

```text
形意/八卦打进去 → 对攻中抓机会破招 → 破招后立刻衔接形意/八卦继续攻击
```

### 5.3 R29·招式复用规则

```text
对战双方变了 → 招式可以复用。
对战双方没变 → 招式禁止重复。
```

判断标准：

```text
“角色A VS 角色B”中A和B完全一致 = 同一对战，必须零重复。
A或B任一不同 = 不同对战，允许复用。
```

### 5.4 冰女 vs 凛羽冰系区分

```text
凛羽 = 霜雾弥漫型：雾、薄霜、寒气微粒、渗透。
冰女 = 硬冰冻结型：冰晶、冰刺、冰壁、冰甲、冰锁。
```

简记：

```text
凛羽=雾，冰女=冰。
```

### 5.5 芭乐核心逻辑

芭乐是灵巧降服型，不是旧版玫红火焰全能型。

```text
形意直线爆破 + 蔡拳密集手法 + 跆拳道高位踢技 + 巴西战舞翻转换位 + 柔术地面降服
```

战斗维度：

```text
站立 → 翻转 → 地面
```

特效性格：

```text
浅粉 → 深粉，越打越深，越打越烈。
轻时浅粉飘散如花瓣，重时深粉炸裂如花开。
```

### 5.6 芭乐 vs 红茶核心差异

```text
红茶 = 火焰灼烧型，一上来就全力炸裂。
芭乐 = 花瓣绽放型，越打越深越打越烈。
```

## 6. 镜头系统核心规则

### 6.1 R30·镜头规格强制法则

每次镜头描述必须包含：

```text
[景别] + [拍摄视角+角度] + [运镜方式] + [跟随目标]
```

景别四选一：

```text
全景 / 中景 / 近景 / 特写
```

视角五选一：

```text
正 / 侧 / 斜 / 俯 / 仰
```

角度必须具体：

```text
45°斜拍平视 / 30°仰视 / 60°俯视 / 侧面90°平视
```

跟随类运镜必须写明跟随目标：

```text
跟随芭乐腰部横向平移
跟随白鸽右腿旋风踢弧线
推进至红茶拳面命中点
```

### 6.2 镜头目的性四原则

| 场景 | 镜头原则 | 目的 |
|---|---|---|
| 正常速度对招 | 中近景/近景，侧面，带移动感 | 聚焦手部招式变化 |
| 蓄力大前摇 | 仰视、慢推、合理构图 | 突出威力，让观众感到“大事要发生” |
| 快速攻防 | 带角度斜拍+方向性移动 | 手部看不清时，用全身和镜头移动显速度 |
| 特写 | 抓破绽、转折点、命中瞬间 | 作为情绪标点，0.2-0.5秒后立即切走 |

总纲：

```text
景别、镜头、运镜都要有目的。
先问这个分镜要表达什么，再决定镜头怎么写。
```

### 6.3 空间感铁律

```text
中景及以上，只要看到两个人完整身子，禁止侧面90°正拍。
```

原因：

```text
中景/全景侧面90°正拍非常像格斗游戏，没有空间纵深和对决压迫感。
```

正确规则：

```text
中景/全景必须用30-60°斜角。
只有近景/中近景/特写才允许侧面90°。
```

### 6.4 精品镜头8种黄金模式

| 模式 | 名称 | 适用场景 | 核心 |
|---|---|---|---|
| A | 低仰蓄力 | 终结技前摇/压迫感 | 15-30°仰视，攻击方占画面2/3 |
| B | 轨迹拖尾 | 踢技/腾空/大幅攻击 | 拖尾长度≥角色身高1.5倍 |
| C | 接触点双色咬合穿透 | 关键命中/破绽 | 进攻方特效刺入防守方特效体内 |
| D | 全景冲击波 | 大招对撞/终结命中 | 以碰撞点为圆心，地面裂纹辐射 |
| E | 不对称特效压迫 | 展示力量差距 | 一方特效铺满半屏以上 |
| F | 翻摔全肢展开 | 过肩摔/过胯摔 | 被摔者身体成连续弧线 |
| G | 元素对称对峙 | 力量对等悬念 | 双方特效面积/亮度/密度接近 |
| H | 角色签名地面 | 地面降服/终结收束 | 地面被胜者特效染色 |

### 6.5 冷暖色彩对抗铁律

```text
同色系特效打架，不如互补色/冷暖对比好看。
```

例子：

```text
白鸽紫 vs 冰女蓝白 都是冷色，容易打不起来。
可以把白鸽紫加深到偏暖品红边缘，让暖紫刺入冷青蓝。
```

## 8. 新角色创建流程

当用户说：

```text
创建角色 / 新增人物 / 绑定技法 / 我要做一个新角色 / 帮我设定角色
```

必须先进入创建角色引导流程，不能直接拍脑袋生成角色。

### 8.1 第一步：展示技法-招式总览

提示用户从技法库选择3-6个技法，推荐4-5个。

### 8.2 第二步：询问角色信息

询问模板：

```text
你要创建的新角色，想绑定哪些技法？建议选4-5个。
你可以直接回复：角色名 + 技法组合 + 特效颜色/形态 + 胜负倾向。
例如：创建角色青岚，绑定八卦掌、形意拳、柔道、风系青绿色气焰，定位灵动破招型。
```

### 8.3 第三步：按层级分配技法

| 分配项 | 规则 |
|---|---|
| 主战技法 | 1-2个，约70%，负责多数对攻画面 |
| 破招技法 | 1-2个，约20%-30%，用于破防/摔投/锁控 |
| 终结技法 | 1个，选择视觉爆点最强的技法 |
| 距离覆盖 | 至少覆盖近身/中距/空间变化中的2类 |
| 动作维度 | 尽量覆盖站立/腾空翻转/地面控制中的2-3类 |
| 特效性格 | 颜色只是基础，必须定义动态性格 |

## 11. 当前系统还缺什么，下一步优化方向

飞驰影漫社+废话军师联合改造后确认“打戏系统交接包”优先级很高。本交接包完成后，建议下一步按这个顺序继续升级：

### 11.1 提示词反向质检器

生成后自动检查：

```text
1. 开局1.5秒是否有攻防接触。
2. 是否至少1段近景对招。
3. 是否有情绪拐点。
4. 是否有终结技三幕结构。
5. 镜头是否都有景别+视角+角度+运镜+跟随目标。
6. 中景/全景是否避免90°侧面正拍。
7. 是否触发R29重复风险。
8. 字数是否≤2000。
```

### 11.2 失败案例库

记录模型误解与修正写法，例如：

| 问题 | 错误表现 | 修正 |
|---|---|---|
| 540°错误 | 生成竖向翻腾 | 写水平旋身如陀螺横转，非竖向翻腾 |
| 中景侧拍 | 像格斗游戏 | 改45°斜拍平视 |

| 对招太糊 | 特效遮住动作 | 连打过程零特效，收尾重击带特效 |
