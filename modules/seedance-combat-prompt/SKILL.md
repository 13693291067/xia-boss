3. **场景引导**：用户未定场景或问场景问题 → 列出 20 个默认场景供选择；只给风格没给地点时按风格推荐 2-4 个。见 `references/output-style-scene.md`。

## 完播率公式（最高指导原则）

```
完播率 = 开局冲击(20%) × 节奏呼吸(30%) × 运镜丰富度(25%) × 情绪拐点(25%)
```

- **开局冲击**：1.5 秒内必须出现攻防接触，0.5 秒内出现冲突最激烈的点（两种极端招式正面硬撞+微慢镜定格），禁止全景铺垫
- **节奏呼吸**：快慢交替，同节奏连续 ≤5 秒
- **运镜丰富度**：同运镜 ≤2 秒，同景别 ≤3 秒，重磅招式三段式
- **情绪拐点**：至少 1 次让观众情绪翻转的瞬间（9-12s 位置）

## 15 秒节奏骨架

开局突进硬撞 → 近景对招（至少 1 段 2-3s，逐击写清招式链+落点+防守反馈，必须含肘击）→ 空间维度变化 ≥2 次 → 情绪拐点 → 终结技三幕（破局→绽放→余震），以高潮收尾、禁止收尾帧。

## 32 条执行级规则（核心摘要 R1–R32）

| # | 规则 | 核心要求 |
|---|------|---------|
| R1 | 开局无试探 | 远程突进/身法贴脸，1.5s 内攻防接触 |
| R2 | 连招按武学合理组合 | 左右交替/多变区域 |
| R3 | 角色要"动"起来 | 大幅身体变化，避免站立对轰 |
| R4 | 强招重描述 | 越强力越详细：姿势+特效+运镜+打击点 |
| R5 | 角色只是载体 | 武学库灵活运用，不限定单技法 |
| R6 | 手部攻击多元化 | 拳/掌/指/肘/爪/腕/肩/背/头 ≥3 种 |
| R7 | 观赏性身法必须出现 | 空翻/撑地旋转/毽子转体/倒立撑地等 |
| R8 | 踢击部位多样化 | 脚背/脚掌/脚尖/脚跟/脚刀/膝盖/小腿 |
| R9 | 镜头最多持续 2 秒 | 15 秒内 6-8 次镜头切换 |
| R10 | 情绪拐点必选 | 9-12s 位置，压制型或逆转型 |
| R11 | 终结技前呼吸帧 | 0.3-0.5 秒极慢/定格 |

| R13 | 终结技三幕结构 | 破局→绽放→余震 |
| R14 | 攻防转换要有"化"劲 | 引开对方来力+顺势反击 |
