# 首帧/尾帧图片提示词 5 段式规范（独立调度文件）

> 来源：剧本转分镜方法论（§8 首帧图片提示词格式），2026-08-21 并入虾镜。**生成 firstframe_prompt 或 tailframe_prompt 时，加载本文件。**

## 0. 定位

`firstframe_prompt` 与 `tailframe_prompt` **均按本 5 段式规范**输出 = **顶部资产引用行 + 5 段式正文**，可直接用于图片生成模型。

- **顶部资产引用行**（虾镜三层结构保留）：`角色A=图1，示例大殿=图2`（按角色→场景→道具编号，`图N` 占位待换参考图，只引用虾塘资产库真实资产）。
- **正文 5 段式**（严格按以下顺序组织，无中文标签）。
- **首帧**：优先表现"动作开始前的稳定状态"，避免把一整个动作过程塞入单张首帧图片。
- **尾帧**：表现动作终点/反应后的状态（动作结束位置、结果、人物反应），保证与视频动作终点一致。

## 1. 风格与质感（第一段 · 英文）

包含：画幅比例（如 2.39:1 变形宽银幕）/ 真人实拍或动画类型 / 摄影机质感（机型号）/ 镜头成像特征 / 胶片或数字摄影响应 / 材质表现 / 高光滚降 / 暗部层次 / 颗粒 / 焦外 / 炫光 / 整体真实度。

## 2. 镜头（第二段 · 英文）

包含：景别 / 焦段 / 镜头类型（球面/变形）/ 光圈 / 摄影机高度 / 摄影机角度（平/仰/俯）/ 摄影机与主体距离 / 构图（方式 + 叙事作用）/ 焦点位置 / 景深 / 前景遮挡情况。

## 3. 色彩（第三段 · 英文）

包含：主色 / 辅助色 / 强调色 / 冷暖关系 / 主光源（类型+方向+动机）/ 辅光源 / 环境光 / 人物轮廓光 / 暗部与高光控制（暗部保留材质层次、高光柔和过渡）。

## 4. 画面内容（第四段 · 中文，与英文画面段对应翻译）

包含：场景 / 时间 / 天气 / 人物姓名 / 人物位置 / 人物动作开始前状态 / 视线 / 表情 / 道具 / 前景 / 中景 / 后景 / 建筑和道路关系 / 场景材质 / 空气状态 / 与前后镜头的空间连续性。

> ★ 首帧优先表现"动作开始前的稳定状态"；尾帧表现"动作终点/反应后的状态"——均避免把一整个动作过程塞入单张图片。

## 5. 限制（第五段 · 负面词）

包含必要负面约束，例如：
- 不改变人物形象 / 不增加无关人物 / 不增加无关道具 / 不改变服装 / 不改变场景结构 / 不改变天气 / 不改变时间
- 不出现文字 / 不出现水印 / 不出现多余手指 / 不出现肢体畸形 / 不出现漂浮物体 / 不出现错误透视 / 不出现不合理光源
- 不出现全局死黑或死白 / 不使用廉价蓝橙滤镜 / 不使用塑料 CG 材质 / 不过度锐化 / 不过度磨皮
- 不让背景随机变化 / 不破坏前后镜头的空间连续性

## 6. 与虾镜三层结构的对应（★ 融合规则）

| 虾镜三层结构 | 对应 5 段式 |
|---|---|
| 顶部资产引用行 | 不变（角色A=图1，示例大殿=图2） |
| 第一层 英文通用风格段 | = ① 风格与质感 + ② 镜头 + ③ 色彩（英文纯净） |
| 第二层 中文画面描述段 | = ④ 画面内容（中文，保留镜头/动作/表情/光影，可带中文锚点/色调标注） |
| 第三层 负面提示词 | = ⑤ 限制（FORBIDDEN/Negative + 中文控噪） |

- **首帧提示词不得再次完整重复人物外貌设定**，只需写人物姓名，默认调用已确定的人物资产。
- 引用 FS 固定风格库编号（如"调用 FS-01"）时，①~③ 的风格/镜头/色彩参数以该 FS 为准。

## 7. 调度方式

| 时机 | 谁 | 动作 |
|---|---|---|
| 生成 firstframe_prompt | 虾镜（制作 Tab） | 加载本文件 → 顶部资产引用行 + 5 段式输出（动作开始前状态） |
| 生成 tailframe_prompt | 虾镜（制作 Tab） | 加载本文件 → 顶部资产引用行 + 5 段式输出（动作终点/反应状态） |
| 引用固定风格 | 虾镜 | ①~③ 按项目 FS 库（虾格产出 outputs/fs-library.md）对应编号填充 |
