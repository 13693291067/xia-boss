# 题材 → 视觉参考映射表（三步向导·第二步推荐源）

> 用途：虾格三步向导「② 视觉参考」的推荐来源。用户选定风格类型后，按题材/世界观匹配参考作品组，每组给出 3-5 部成熟影视作品。
> 性质：**通用方法论**（纯参考知识，零项目数据）。本表只做推荐池，用户可自定义或补充；选定结果写入项目，不写回本文件。

## 使用规则（强制）

1. **参考 ≠ 复刻**：只提取参考作品的**视觉语言**（光线方向与色温 / 色彩体系 / 材质质感 / 构图与调度 / 氛围气质），**禁止照搬**其角色、世界观、剧情或 IP 元素。
2. 每步推荐 **3-5 组**，与第一步已定风格匹配；每组 = 作品名 + 一句"可取之处"。
3. 方案之间必须差异明显（如：暗紫魔气系 vs 素白灵光系）。
4. 推荐结果写入项目（handoff-xiage.md 的 `visual_references`），不落 skill。
5. 参考作品引用须转化为**可执行视觉描述**（如"参考其低照度高反差与暗部层次"），而非简单报片名。
