# Seedance 2.0 视频生成提示词 · STYLE LOCK 导演模板（独立调度文件）

> 来源：剧本转分镜方法论（§9），2026-08-21 并入虾镜。**生成 video_prompt 时，加载本文件。**

## 0. 定位

每个镜头的 `video_prompt` 按本模板输出一段**独立、完整、可直接复制**的 Seedance 2.0 视频生成提示词。顶部仍带虾镜**资产引用行**（角色A=图1，示例大殿=图2——见虾镜纪律 6.1），其后按「STYLE LOCK 风格锁 → 分镜画面 Shots → 声音设计 → 关键约束」四段组织。

## 1. 硬性写作规则

1. 所有摄影/影视专业术语（景别、构图、运镜、焦段、机位、投影、转场、速度等）必须**"中文+英文"并写**，如"中景 medium shot""后退跟拍 dolly-back tracking"。
2. 动作描述用**纯客观、纯视觉的第三人称**，细节丰富、可被镜头看见；情绪 = 客观表情变化 + 主观情感词。
3. 颜色一律给 **HEX 色值**并声明"严格按色卡执行、不可偏离"。
4. 只描述画面里能看到/听到的东西，不写抽象观感。

## 2. 【STYLE LOCK 风格锁】

- **画面质感 Look & Texture**：胶片/镜头/摄影师/流派美学参考 + LUT + 颗粒/质感 + "实拍非渲染"声明。
- **画幅 Aspect Ratio**：如 16:9 anamorphic 宽画幅。
- **运镜基调 Camera Operation**：全段主导的相机运动方式（handheld 微抖 / steadicam dolly / 固定机位 / 甩摇 whip pan / 急推 crash zoom / 希区柯克变焦 dolly-in + zoom-out…）+ 稳定度描述。⚠ 运镜**选型、三轴辨误、环绕代价、战斗段让位 R31** 见中立层 `../../../references/shared-camera-movement.md`（本文件只登记 Seedance dolly 口径的英文方言词）。
- **环境·大气锚定 Atmosphere Anchor（全段持续）**：风/热浪 heat-shimmer/雪沫/雨/尘埃等贯穿性大气元素 + 对布料、头发、空气的可见影响。
- **人物表演基调锚定 Performance Lock**：每个角色的整体气质/表演风格总纲（区别于分镜里的具体动作）。
- **光线·色温锚定 Lighting**：主光颜色+HEX、阴影色+HEX、整体影调。
- **参考图锚定 Anchors**：
  - 人物图（按上传的人物数量，逐个角色单独指定一张锚定图，一人一图一对应，禁止混用）：
    - `@[人物图1]` 作为【角色A名】的视觉锚定（注明"严格按图渲染·不可改造"或"仅气质锚定"）
    - `@[人物图2]` 作为【角色B名】的视觉锚定（有几个角色就列几条，多余的不写）
  - `@[场景图]` 作为场景锚定
  - `@[色卡图]` 作为色卡锚定 + 严格按色卡 N 色执行·不可偏离色板

## 3. 【分镜画面 Shots】

[先声明模式] `one continuous unbroken take 一镜到底` ／ `multi-shot with hard cuts 多分镜（内含 N 个硬切）` + 总时长。

- **若一镜到底**：按时间轴 beat 推进（0–2s / 2–5s …），逐段写"镜头设计 + 剧情动作 + 呈现效果"，强调动作的连续因果。
- **若多分镜**：每个分镜写为一个小节 `【镜头N · 景别 · 一句主题（约X秒）】`，含以下 5 项：
  - **镜头设计 Shot Design**：景别 shot size + 构图 framing + 焦段 lens(mm) + 镜头投影 projection(rectilinear/anamorphic) + 机位高度与角度 camera height & angle + 运镜 camera move + 人物在画面中的位置 + 持续时长。
  - **画面剧情 Action & Story（本板块着墨最多，按"起因→过程→细节→反应/内心折射"展开）**：
    - 人物在画面中的位置
    - 人物详细动作（客观纯视觉、逐动作可见）
    - 人物台词（若有）
    - 人物情绪：客观表情变化 + 主观情感词（台词与情绪合并写）
  - **背景 Background**：环境/景深/虚化关系
  - **画面呈现效果 Visual Result**：一句客观概括本镜最终画面。
  - **声音（本镜）Sound**：本镜出现的音效/台词/环境音。
  - **镜头衔接 Transition**：末段如何切到下一镜（hard cut / match cut 方向延续）。

## 4. 【声音设计 Sound Design 全段统一】

- **环境底噪 Base Ambience**：全程持续的底噪（风/雪/环境）。
- **按镜头顺序 Per-shot**：依次罗列各镜音效、台词效果、拟音的强调。
- **空间·距离感 Spatial Audio**：近景/远景声音的响度与遮蔽关系。
- **BGM 声明**：通常 `sound design only, NO background music`（除非另有要求）。

## 5. 【关键约束 Hard Constraints】

- **色卡铁律**：严格按色卡 N 色执行·不可偏离。
- **人物锚定铁律**：每个角色严格对应其指定的人物锚定图，一人一图不可混用、不可串脸、不可自行改造外形/服装/发型。
- **运镜/机位铁律（逐镜锁定）**：每镜机位、焦段、角度不可变。
- **硬切/转场铁律**：hard cut only，禁止 transition（唯一例外注明 match cut）。
- **动作轴线铁律**：谁在轴线左/右，全程不越轴 180° axis，打击落点与站位自洽。
- **跨镜连续性铁律**：伤情/血迹/道具/服装/兵器状态跨镜连续、不穿帮。
- **表情铁律**：真人微表情传达，禁止夸张龇牙瞪眼。
- **速度铁律**：real-time normal speed，NOT slow motion / NOT 子弹时间 / NOT speed ramping。
- **风格铁律**：NOT 3D / NOT CGI / NOT 游戏感 / NOT 塑料感；无字幕无水印 no subtitles no watermark。
