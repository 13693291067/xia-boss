# 镜头衔接三手法六式 · 可执行规格（横切单源）

> 适用：听风 Stage 2 转场逻辑、虾镜拆镜镜头组合、分镜表"衔接式"字段——凡写"镜与镜怎么切"的环节。
> 性质：通用方法论，禁止出现任何具体项目数据；示例一律占位符。
> 来源：从《"三手法六式"镜头衔接与电影级视听省略体系》蒸馏（漫剧老李 V6.5 规范体系，已通用化改写，2026-09-04 采纳）。
> 咬合：`shared-duration-control.md` 分镜表"衔接式"字段的本体规范；`shared-spatial-blocking.md` 越轴三手段中的"中立镜过渡"由本规范二式/五式承担执行。

## 〇 核心理念

切镜不是强行拼贴，而是**视线引导与动力学传递**——彻底废弃生硬的首尾帧画面拉伸或动作粘连，把切接点定义为有动机的机位转换与景别跳跃。

## 一、衔接三手法（切镜的三类动机）

1. **换机位（Angle Shift）**：保持时间与动作连续，切入不同角度（攻方 45° 过肩切受击方 90° 侧面），呈现攻防因果——机位变化受 `shared-spatial-blocking.md` 轴线同侧约束；
2. **切景别（Scale Shift）**：大幅度跳跃景别（全景大动作切特写要害命中），避免微小景别跳切（近景切中近景导致画面颤动）；
3. **跨段反应（Reaction Cut）**：重击发生瞬间切入旁观者/对手的微反应（瞳孔骤缩/倒吸凉气/汗珠飞溅），借反应放大冲击力——与虾镜"金句后必跟反应镜"铁律同源。

## 二、切接六式（六种具体切法，写"衔接式"字段时选式标注）

| 式别 | 衔接方式 | 视听原理 | 适用场景 |
|---|---|---|---|
| **一式：动作连续切** | 动作发起在中景，击中瞬间切至近景/特写 | 视线顺着肢体运动方向自然过渡 | 重拳冲锋、腾空下劈、兵器劈砍 |
| **二式：反应镜头切** | 重击命中瞬间，切至防守方瞳孔骤缩或旁观者惊呼 | 借他人视线与情绪放大危险程度 | 破防绝杀、致命伤口产生、杀招初现 |
| **三式：景别跳切** | 极近景微距（滴血/眼神）骤切大全景（地裂/烟尘） | 视觉尺度极大反差产生戏剧冲击 | 终结技爆发、蓄力后的瞬间释放 |
| **四式：视线引导切** | 上一镜运动末端焦点在右侧，下一镜入画点严格承接在右侧 | 观众视线无需满屏搜索，视觉极度流畅 | 高速连环对招、多目标穿插追击 |
| **五式：遮挡过渡切** | 角色躯干/障碍物/武器快速擦过镜头切入下一镜 | 利用运动模糊与暗影无痕转场 | 巷道追逐、**室内外场景切换**（scene-consistency 换景清单的转场镜首选写法） |
| **六式：动势匹配切** | 上一镜向右翻滚的惯性，由下一镜向右滑步的冲势承接 | 物理动量在镜头切点之间守恒 | 被击飞撞墙、借力打力反击 |

**字段写法**：分镜表/听风分镜的"衔接式"填 `式别名 + 动机一句话`（如"五式·遮挡过渡：角色A躯干掠镜，切院内"）——只写式名不写动机 = 未完成。

## 三、视听省略法则（切点的高级留白）

- **省略冗余过程**：拔刀动作发起后，直接切刀尖染血归鞘，略去中间无戏剧价值的挥砍过程——与剧本门控"过场戏果断省略"、时长控制"并（同类动作合并）"同源；
- **环境代击打**：通过震落的落叶、震碎的窗玻璃、水面波纹表现隔空劲力，实现高级视听留白。

## 四、与既有体系的对齐（防两套说法打架）

| 既有说法 | 归入 |
|---|---|
| 听风 Stage 2「match-on-action」 | 一式·动作连续切 |
| 听风 Stage 2「视线匹配」 | 四式·视线引导切 |
| 听风 Stage 2「180° 轴线」 | 不属衔接手法——是机位侧别约束（shared-spatial-blocking.md），与六式并行生效 |
| scene-consistency 换景清单「转场镜」 | 五式·遮挡过渡切（默认），或六式 |
| duration-control 组间接续状态 | 六式·动势匹配切是"接续状态"的画面写法（动量守恒=状态继承） |
| 越轴"中立镜过渡"（spatial-blocking） | 二式（反应/特写中立镜）承担切入中立位的写法 |
