> 面向使用者（主理人/工作室成员）的操作手册。想看内部实现与编排规则，读 `SKILL.md`；本文只讲「怎么用」。
> 更新：2026-09-02（对应模板 v20260901 系列：听风电影集成、航拍系视距、👀 切换视角等均已内置）

## 一、这是什么

**xia-boss（虾集·总指挥）= 一条「小说 → 短剧成片」的 AI 流水线 + 一个本地 HTML 项目台。**

你只需要给一条小说路径，AI 会按流程推你走完全部环节；每个关键节点停下来等你拍板，你确认后才进下一步。所有产物都沉淀进项目台网页，图片提示词一键复制去生图，视频提示词一键复制去生视频。

内置模块：

| 模块 | 干什么 |
|---|---|
| 📜 虾料 | 摄入小说、梳理世界观、生成知识图谱 |
| 🎨 虾格 | 创作方向确认门：风格类型 → 视觉参考 → 影片基调（三步拍板） |
| 🎭 虾塘 | 资产库：角色（证件照主图+身份两图制）、场景（多视角/视距/航拍/拓扑图）、道具、关键场景 |
| 🎬 虾镜 | 传统分镜线：场景一致性闸门 → 分镜脚本 → 制作（首帧/尾帧/视频）→ 故事板 |
| 🎬 听风电影 | 电影化分镜线：戏剧节拍分段 + 五层结构 + 提示词逐字保真（独立数据，与虾镜隔离） |
| ✅ 场景一致性看守 | 虾镜线的强制闸门：空间真理图 → 三份可验证产物 → 独立审核 |

## 二、30 秒上手

1. 对 AI 说：**「小说路径：<你的小说目录>」**
2. AI 自动跑 **虾料**（世界观+知识图谱）→ 停下等你确认
3. 确认后走 **虾格三步向导**（每步 3-5 个候选，选一个）→ 三件套拍板
4. 进 **虾塘** 建资产（角色/场景/道具，提示词全给你，生图归你）
5. 虾塘完成后 AI 会问：**「本集走 🎬 听风电影 还是 🎬 虾镜？」**——选一条线
6. 按线做分镜 → 打开**项目台**逐镜出图出视频

> ⚠️ 三条铁律：每个确认门 AI 不许替你拍板；风格一经确认全部资产跟随（换风格=资产重做）；提示词 AI 必须给全，生图/生视频执行归你。

## 三、HTML 项目台

### 启动

- 双击 `project/启动项目台.bat`（纯 ASCII，自动清端口）；异常时右键 `启动项目台.ps1` 用 PowerShell 跑
- 浏览器打开 bat 提示的地址（端口以 bat 为准：模板当前 8320，旧项目可能是 8317/8318）
- 也可以双击 `index.html` 纯浏览（不能上传/生成）

### 页签一览

| 页签 | 里面有什么 |
|---|---|
| 📜 虾料 | 世界观、知识图谱（可拖拽/缩放/点击） |
| 🎨 虾格 | 风格列表 + 三要素展示 + 预设图；新风格可传图反推或指定名称生成 |
| 🎭 虾塘 | 角色 / 场景 / 道具 / 关键场景 四个子页 + 批量生图 |
| 🎬 虾镜 | 分集 → 分镜脚本（表格/拖动重排/重置）/ 制作（11 字段+首帧尾帧视频）/ 故事板 / 调度图 |
| 🎬 听风电影 | 分集 → 分镜脚本（镜号/时间段/景别/运镜/画面/音效）/ 制作（S 段故事板拼板 + 逐段生视频 + 拓扑图 + 批量生视频） |
| ⚙ 设置 | 渠道（开箱自带 888）、图片默认尺寸（5 类）、生视频模型（Seedance / MiniMax-H3）、🧭 分镜主力线 |

底部常驻**任务队列面板**（并发 5 / 排队上限 60），右上「📥 下载」可打包资产。改过提示词点「💾 保存提示词」会持久化。

### 场景页（功能最密集的页面）

每张已生成的图上有三个小按钮：**× 删除（右上）、👁️ 视距（左下）、👀 切换视角（右下，蓝色）**。

| 功能 | 入口 | 说明 |
|---|---|---|
| ✨ 生成 / 批量生图 | 每张图位 / 列表页按钮 | 主图、身份图、四视图卡、场景、道具全覆盖 |
| ↔ 切换视角（👍 核心功能） | 图片上的 **👀** | 打开窗口勾选 7 视角（正面/左侧/右侧/背面/斜侧/俯视/45°俯视全景）。**参考图 = 你点 👀 的那张图**（主图、任意视角图、甚至航拍结果都行）；**已生成的视角也能勾选重生成（替换旧图）** |
| 👁️ 视距 | 图片上的 **👁️** | 推拉：前移/后移 1-10 米；**航拍系：航拍 / 45°航拍 / 高航拍 / 45°高航拍**。可多选批量；航拍结果上可继续叠视距 |
| 👁 上帝视角 | 场景工具栏 | 自动引用 正面(或主图)+背面+45°俯视全景 → 平面布局（9:16）→ 自动接线稿 |
| 删除 | × | 删文件+数据，不可恢复 |

> 提示词全部固定模板不可修改（用户钦定）；视角/视距产物不占历史，重生成直接替换。

### 角色页

- 主图 = 证件照式标准像（3:4，锁脸基准）
- 身份 = 两图制：①身份定妆照（正面全身）+ ②四视图角色卡（上下两段式）；四视图自动拿身份定妆照当参考
- 身份图可挂服装参考（图2），脸永远锁图1

## 四、两条分镜线怎么选

| | 🎬 听风电影 | 🎬 虾镜 |
|---|---|---|
| 风格 | 电影化：戏剧节拍分段，每段 ≤15s，五层结构（承接头/镜头拆解/戏剧动作/退场钩子/元数据） | 工作台化：逐镜 11 字段 + 场景一致性闸门 + 故事板 6/9 格 |
| 适合 | 追求镜头语言与连续性、直接产视频提示词 | 需要逐镜精细管理、首帧/尾帧/故事板全流程 |
| 项目台 | 「听风电影」页签（独立数据，与虾镜互不干扰） | 「虾镜」页签 |

- 默认走哪条线看 **⚙ 设置 → 🧭 分镜主力线**；但**每集开工前 AI 都会再问你一次**，口头指定优先于设置
- 两线数据完全隔离，随时可换线，互不污染

## 五、听风线做一集（简明流程）

1. **Stage 0 前集衔接**（非首集）：衔接决策书 / 母题编号继承 / 资产盘点两查 / 系列位置
2. **Stage 1 五表**：节拍表、空间锚点表（→ 本集专属拓扑图提示词）、轴线约定表、母题登记表、资产引用表——缺表不进 Stage 2
3. **Stage 2-3**：逐段分镜（每段 ≤15s、2-4 镜、承接=上段钩子），每批 5 段
4. **Stage 4-5**：视频提示词 = 分镜全文逐字（保真铁律）→ 三重审计（完整性/连续性/保真）
5. 项目台「听风电影」页：生拓扑图 → 逐段生视频 → 故事板拼板 → 批量生视频

## 六、虾镜线做一集（简明流程）

1. **场景一致性闸门**：先出空间真理图（原文证据+推断标注）→ 你确认
2. 分镜脚本（11 字段，逐镜场景从拓扑图取）→ 拖动重排/编辑/重置
3. 制作页：逐镜 首帧 → 尾帧 → 视频；画面标注辅助
4. 故事板：勾选分镜生成 6/9 格

## 九、纪律速记（AI 侧）

1. 确认门不代决——每个决策点必须用户显式选择
2. 风格单一源——生图/生视频提示词动态读确认风格，禁止硬编码
3. 数据只进项目目录——skill 与模板零项目数据
4. 提示词全量交付——AI 出全部提示词，生图生视频归用户
5. 新功能前后端成对——落库分支+落库行、入口+路由+重绘、正则两处同改

## 十、2026-09-03 集成：前半程创作基准（用户侧速览）

> 来源：前半程创作基准方法论蒸馏（2026-09-03 集成），分布式注入虾料/虾格/虾塘。只对**写实线**项目生效的部分已标注。

| 新能力 | 你会看到什么 | 在哪一步 |
|---|---|---|
| 生产事实六项 | 世界观确认材料里多出：国家年代地域、季节时间轴、语言声音文化、威胁规则、人物小传（含声音气质）、状态母题；推断项有四级标注，提案必须你拍板 | 虾料 → 知识图谱/世界观确认时 |
| 空间链表 | `outputs/scene-chain.md`：剧情穿越的主要空间+方向+因果；场景真理图自动引用 | 虾料产出；scene-consistency 消费 |
| **全片情绪曲线** | 虾格给你看一张 0-10 分的起伏图（8-16 个节点+呼吸区+BGM 重点），③影片基调**看着图拍板**；分镜阶段每集的情绪段标注自动对齐它 | 虾格八项分析后自动出，不问你 |
| **P1 写实基线**（仅写实线） | 一套摄影色彩声音基准：参考片+借鉴维度、摄影机/镜头/画幅帧率、全片风格锁定段、环境色彩策略、人物声音气质、环境声+音乐圣经；之后首帧/视频的风格段以它为母本 | 虾格①风格拍板后自动追加 |
| **角色依赖门禁** | 有血缘/变异/换装/受伤/年龄关系的角色，先出基础版、确认后自动解锁衍生版（只继承 2-4 项家族特征）；变异程度只问一次（H1/H2/H3） | 虾塘建资产时 |
| 角色提示词增强 | 写实线提示词多出骨相锁定段（防网红脸）、命运气质、身份细节锚点（含左右方向）、哑光压高光 | 虾塘出定妆/身份图时 |
| 道具锚点 | 重要道具登记缺口/文字方向/左右结构等识别锚点（逐条进提示词）+ 剧情锁定状态（防"断剑变完整"） | 虾塘道具清单 |

**不需要你多做任何操作**——这些能力在对应步骤自动生效，只有"四级标注的提案"和"变异程度（未明确时）"两处需要你拍板。
