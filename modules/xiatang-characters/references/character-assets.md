# 人物资产图规范（角色资产图全集 · 独立调度文件）

> 来源：虾塘「身份图锁脸铁律 / 角色图像规格铁律 / 资产图通用要求 / 真实感提示词 / 妆造设计」+ 剧本转分镜人物资产规范（§11，2026-08-21 整合为独立文件）。**产出任何角色资产图提示词（主图 / 身份图两图）时，加载本文件。**

## 0. 角色资产图构成（★ 2026-08-21 用户拍板）

```
主图（定妆照·证件照式）── 定"脸"（辨识度锚点 + 锁脸 ref 基准）
身份图 = 两图制（每个身份 2 张）：
  ① 定妆照 ── 该身份造型的正面基准图（证件照式，同面容锁脸，含该身份妆造设计）
  ② 四视图角色卡 ── 上下两段式定妆参考板（上 1/3 正脸+侧脸特写 / 下 2/3 放大正面服装展示+完整背面全身），
     提示词固定为用户钦定中文模板（见 character-sheet-4view.md §A），生成时自动引用该身份定妆照作参考
```

- **不采用多视图清单制**（如"每角色 8 张视图"）；**身份图 = 两图制（定妆照 + 四视图角色卡）**（★ 2026-08-21 用户拍板，恢复两图制；四视图卡提示词固定为用户钦定模板，不做单独的造型卡自由发挥）。
- 同一角色的所有身份图必须与主图**同一面容**（仅妆造/服装/配饰/气质变化，面部结构不变）。

## 1. 主图（定妆照）= 证件照式标准像（★ 用户拍板）

**3:4 竖版**画幅，**证件照（ID/passport style）**——正面、头部居中、正对镜头、中性表情、纯色背景（无环境元素）、均匀棚拍光（无侧光阴影）、双肩端正**无姿态动作**（禁叉腰/举手/侧身/手持道具/戏感表情）。以五官/发型/发色/妆容/肤色/眼神等辨识度特征为核心。

**渲染介质词按风格族分支（★ v3.2.0，防风格漂；族定义见 `modules/xiage-styles/references/render-medium-library.md`）**：
- 写实族 → 镜头 `85mm f/1.8`（写实族专属）。
- 3D 国漫 CG 族 → 从族A 取 CG 固定介质词组整段前置：`guoman CG character render, stylized painterly 3D animated-feature look, cel-influenced soft shading with volumetric rim highlights, idealized smooth skin, visibly CG not photographic`；眼睛用 `anime-styled eyes`。
- 二维赛璐璐族 → 族C 词组 `2D cel-shaded anime render …`。
- **CG 族正向段禁出现 §5 写实质感词**（film grain / realistic skin pores / subsurface / 85mm / f/1.8）。

- **构图硬性要求**：**正面肩以上头像构图，画面只到肩膀上沿**——不露肩/锁骨/手臂/胸部/皮肤裸露；衣领高度自然覆盖肩颈。提示词必须含：`head-and-shoulders composition, frame ends above shoulders, collar naturally covers neck and shoulders`。
- **禁写腰以下细节**：提示词不得包含腰线以下的服装/配饰描述（腰带、腰佩、裙摆、裤子、鞋、护腕、手部动作等）——证件照画面根本看不到。
- **负面词必含**：露肩，露锁骨，短袖，手臂入镜，胸部入镜，半身构图，胸像构图（bared shoulders, exposed collarbone, short sleeves, arms in frame, chest in frame, half-body composition, bust composition）。
- 提示词必须含：`3:4 portrait, ID/passport-style front-facing standard headshot, neutral expression, plain solid background, even studio lighting, no pose` + **主图介质锚按族**（写实族 `85mm f/1.8`；3D 国漫 CG 族 `guoman CG character render`；二维赛璐璐族 `2D cel-shaded anime render`）。
- **CG 族必带"正向主动风格化锚"（★ v3.2.0）**：只靠负面 `FORBIDDEN: photorealism` 消极约束压不住写实漂移（事故：指纹句在、仍出真人感）；正向 body（STYLE_HEAD 首句之外）必须含 `cel-influenced / not photographic / anime-styled` 至少一个——check-assets 第⑥项 CG 分支硬校验（剥 STYLE_HEAD 首句后查）。
- **禁写腰以下诱导词（补反例，★ v3.2.0）**：主图不得写 `metal clasp / 胸口交领刺绣 / 腰封 / 佩剑` 等把模型往半身、往写实材质带的词（事故：写了 metal clasp → 模型露胸口成胸像）。
- **子串陷阱（★ v3.2.0）**：正向段禁写含 banned 子串的词——`non-photorealistic` 因含 `photorealistic` 会被 `ID_REALISM_BAN` 判违规，改写 `not photographic`。

## 2. 身份图 = 两图制（① 定妆照 + ② 四视图角色卡，★ 2026-08-21 用户拍板）

- **① 身份定妆照 = 正面全身定妆照基准（★ 2026-08-21 用户拍板：按 02-storyboard-master 全身基准，非证件照式）**：主图已锚定"脸"，身份/造型定妆照负责锁定**角色的完整造型**——
  - **正面全身站姿**：正面朝向镜头、双臂自然垂放、完整呈现全身造型（**不画多角度、不画转面、不画动作**）；
  - **一次定死**：面容 / 发型 / 体型 / 服装（材质+剪裁+颜色）/ 鞋子 / 随身物件——该身份的全部造型细节在此锁定，作为该身份后续所有生成（含四视图卡）的基准；
  - 含该身份的**妆造设计描述**（英文段，见 §4）；与主图同一面容（锁脸指令 + 主图作 ref）；
  - **镜头与光**：85mm 人像镜头 f/1.8 浅景深，单一主光源柔和均匀正面光（正前方偏上，色温 5600K），简洁中性背景（浅灰/白）；
  - **遵守 §3 资产图通用要求**（纯中性背景 / 无场景 / 无其他人物 / 无文字 / 无尺寸标注 / 无说明标签 / 无水印 / 自然中性站姿 / 身体比例统一 / 年龄发型面部服装鞋履道具统一 / 材质真实 / 正侧背视图结构一致 / 禁服装漂移 / 禁左右道具错位 / 禁多余手指和肢体畸形）；
  - **★ 支持服装参考图（2026-08-21 用户拍板）**：用户上传服装参考图时（前端「🛍 服装参考」，第 2 张参考图，**图1=主图（images[0]，锁脸）、图2=服装参考图（images[1]）**），**提示词整体替换**为固定的「服装通用参考版」模板（详见 character-sheet-4view.md §B2）——发型/妆面/服装全部以参考图（图2）为准、脸锁主图（图1）、对任何身份通用；**不是追加段**（杜绝与身份专属服装文字冲突）；移除参考图后恢复标准版；
  - 提示词模板与"资产图 vs 定妆照"理念差异详见 `character-sheet-4view.md` §B。
- **② 四视图角色卡**：上下两段式定妆参考板（上 1/3 = 正脸特写 + 侧脸特写；下 2/3 = 放大正面服装展示图 + 完整背面全身图），**提示词固定为用户钦定中文模板（`character-sheet-4view.md` §A，逐字复制，不得改写）**；**生成时自动引用该身份定妆照作参考**（三级锁脸：主图 → 定妆照 → 四视图卡）。
- **背景 = 纯色（★）**：两图背景必须是**纯色**（白/浅灰/角色主色），**禁止场景/环境元素**——参考图是"造型展示"，不是"剧情画面"。定妆照提示词必须含：`plain solid background`；四视图卡模板已含"摄影棚灰背景"。
- 与主图同一面容（锁脸指令 + 主图作 ref），带 raw photo 质感段。

## 3. 人物纯背景资产图通用要求（★ 所有角色资产图必须符合）

- **纯中性背景**：无场景、无其他人物、无文字、无尺寸标注、无说明标签、无水印。
- **结构一致**：正/侧/背视图身体比例统一；年龄、发型、面部、服装、鞋履、道具统一；材质真实。
- **禁止**：服装漂移、左右道具错位、多余手指、肢体畸形。
- 人物采用自然中性站姿（主图按证件照式；身份图按两图制）。
- 与时代/地域/世界观不冲突的服饰道具设计。

## 4. 妆造设计提示词（★ 定妆照必须符合本规范）

为每位角色设计妆造时，必须遵循：

- 在**完全保持角色面部结构不变**的前提下（脸型轮廓、三庭五眼比例、五官结构不动），为原创角色设计一整套妆容造型；妆造设计服务于角色本身的气质定位。
- 重点在**妆面细节**做出变化：底妆呈现的质感、眼妆的层次感、眉形的调整方向、腮红的位置与晕染范围、唇色与唇形的表现方式。
- 同时设计**发型、服装搭配、配饰选择、整体色彩基调**，让角色形象更具辨识度和记忆点。
- 整体妆造自然真实，避免过度夸张；**避开网红脸式的雷同感和廉价影楼照的既视感**。

## 5. 真实感提示词（去 AI 感，★ 所有人物资产图遵循）

- **正向**：电影级写真人像，真实活人质感，去除AI感，场景包含体积光(Volumetric Light)、空气悬浮微粒，带有自然胶片颗粒感（Film Grain），背景层次丰富有真实氛围感，眼部具备清晰的眼神光（Catchlight）与自然对焦效果，面部带有微妙情绪表情，眼神灵动不呆滞；肢体具备真实重量感，动态动作体现现实的力度传导，衣物衣角随身体动作随性自然摆动，姿态松弛舒展；皮肤呈现原生真实质感，可见自然毛孔、微细血管，肤色自然红润，保留真实微小皱纹。
- **负面（排除AI感通病）**：干净无层次的背景，眼神空洞无神，面部表情僵硬，肢体僵硬漂浮，动作不符合物理逻辑，塑料感皮肤，陶瓷般光滑肌肤，过度磨皮，无瑕假脸，AI失真感，过度完美的不真实质感。
- **AI 人像提示词结构（5 模块 · 可直接套用）**：①人物身份（年龄/气质/构图/景别）→ ②皮肤状态（毛孔/轻微泛红/肤色变化/唇纹）→ ③光影关系（自然窗光/侧光/高光/脸颊阴影）→ ④镜头质感（原相机感/抓拍感/浅景深/RAW）→ ⑤反向限制（不要磨皮/不要塑料皮/不要网红脸/不要CG感）。**公式：主体 + 皮肤 + 光影 + 镜头 + 负面词**。

## 6. 锁脸铁律（★ 强制，跨模块）

**身份图与主图必须是同一张脸——AI 生图每次随机出新角色，必须用主图作 ref 锁定面部五官。**

- 身份图 prompt 必须含锁脸指令（同一人物面容、与主图同一脸）；生成时必须传主图作为参考图（images[0]）。
- **两图制锁脸链（★ 2026-08-21 用户拍板）**：主图 → 身份定妆照 → 四视图角色卡，三级递进：
  - 身份定妆照生成时**主图作 ref**（images[0]）；
  - 四视图角色卡生成时**该身份定妆照作 ref**（前端「四视图」按钮内置：自动引用 `{角色}-{身份id}.png`）；
  - 三级均保持同一面容（仅妆造/服装/配饰/环境/姿态变化，面部五官零差异）。
- **不遵守的后果**：身份图与主图"不像同一个人"——五官错位、骨骼不同、发际线/眉眼/鼻唇不一致，整套角色资产废掉。
- **prompt 锁脸模板**（追加在身份图 prompt 末尾）：
  > **严格保持参考图中人物的面部五官与主图完全一致（眼型/鼻形/唇形/脸型/骨骼/发际线零差异）；only change outfit / accessories / environment / pose, NOT face. Same face as the reference image, identical facial features.**
- **前端自动垫图**（虾集项目台内置）：身份图弹窗打开时自动读 `assets/characters/<角色名>.png` 作为 ref 图加入 images 首位；用户无需手动上传。

## 7. 英文纯净 + 自动校验（★ 强制）

- **英文纯净**：以上所有资产提示词必须**英文纯净**——中文六要素设定段只存在 `six_elements` 字段（元数据），**不得拼进提示词正文**；提示词只含英文画面描述 + 质感/风格段。
- **构建脚本必须用证件照模板**：`build_xiatang.py` 等构建脚本的 `make_portrait_prompt()` 必须输出证件照式标准像（head-and-shoulders / ID-passport / no pose / 纯色背景 / 禁腰以下细节），**禁止沿用旧「全身定妆照」模板**（full body shot / neutral standing pose / dark gradient background）。脚本产出后立即运行 `<本包>/scripts/check-assets.py <项目根>` 自检（英文纯净/证件照/四视图/场景空镜等），全部通过才算完成。

## 9. 角色别名 aliases（★ 2026-08-22 用户拍板，防"称呼对不上资产名"）

**问题来源**：角色资产名常带职称/全称（如「服务生小王」），而分镜 characters 字段/台词用简称（「小王」）——首帧/尾帧生图自动引用角色资产时按完整资产名包含匹配会失败（漏引）。

**规则**：
- registry `characters` 每项补 `aliases`（数组）：该角色在分镜/台词里的常用称呼（职称+名类 → 简称；律师类 → ["X律师","老X"]；老板类 → ["X总"]；群演类 → ["路人","围观"…]；无别名留空数组）。
- build 透传 `aliases` 到 SQLite characters；前端角色匹配 = **资产名或任一别名** 出现在镜头文本。
- **匹配优先级**：先完整资产名，再别名（别名命中同样引用该角色资产）。
- 注意：别名不能与其它角色名/别名冲突（避免误匹配）。

## 10. 提示词增强字段（★ 2026-09-03 集成，前半程方法论蒸馏；对既有模板做增量，不替代既有要素）

> 以下字段**追加**进主图/身份定妆照提示词的对应位置；check-assets 既有要素（证件照 9 要素 / 正面+全身要素 / 三要素内联 / 锁脸指令）仍必须全部齐备。

### 10.1 骨相锁定段（★ 仅写实线注入，写实时最高优先级）

- **适用**：项目渲染介质为真人实拍/写实 CG 时；动画/风格化 3D 跳过（CG 角色骨相由美术风格定义，写实骨相词会造成介质混乱）。
- **写实线判定来源（★ 2026-09-03）**：读 `outputs/creation-direction.json` 的 `p1_cinematic_baseline.enabled`（true=写实线）；字段缺失时按风格 style_tag 介质词判断（photorealistic/live-action/film 类=写实，3D/cg/anime/cel-shad 类=非写实，与 check-assets `detect_style` 同款逻辑）——判定结果本批次内一致，不得逐条漂移。
- **内容**：按虾料生产事实登记的种族/族裔与地域，写明**眉弓、眼窝、鼻梁、下颌、颧骨**的骨相方向，并**同步排除相冲突骨相**（如"低眉弓深眼窝"就排除"高眉弓浅眼窝"写法）；**位置：STYLE_HEAD 渲染介质句（风格三要素首句）之后、人物描述段最前**，优先级高于五官细节——提示词全局最前仍归风格介质句（注入模式纪律，见本 SKILL「资产提示词注入模式」）。
- **目的**：防"人人都长网红脸"——先按族裔地域定骨，再谈五官；与 §4 妆造设计"保持面部结构不变"一致。
- **锁脸兼容**：骨相段写的是"方向与程度"，与 ref 锁脸不冲突（ref 靠垫图，骨相靠文字锚定方向）。

### 10.2 命运气质段

- 用"**年龄 + 职业/命运/长期生活方式形成的气质**"描述整体气质（如"长年户外劳作形成的粗糙感"），并**排除偶像感/明星感**措辞；替代"气质出众/气场强大"这类不可执行空词。

### 10.3 身份细节锚点

- 写出**最能体现身份的一处面部或肢体细节**（如指节老茧、眉间旧疤、常年握桨的手型），作为身份辨识锚点；细节须与人物小传（虾料 production-facts ⑤）对齐，不得凭空发明。
- 涉及左右分布的细节（单侧耳饰/单肩磨痕/单手茧）**必须写明左右方向**，并登记进 registry（作为左右非对称锚点，跨图保持同向）；四视图卡与后续身份图沿用同向。

### 10.4 哑光压高光与固有色

- 皮肤/嘴唇/头发/服装/金属件：**压低尖锐镜面反光与油亮高光，呈真实哑光**；眼睛保留极小柔和眼神光，金属只保留小面积柔光反射。
- 保持固有色与自然明暗关系——**中性影棚光下不引入戏剧环境色**（P1 环境色彩策略只进场景/分镜，不进资产确认稿）。

### 10.5 千人千面禁模糊词
