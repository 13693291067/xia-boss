# 生产事实六项的分镜线消费规范（横切纪律 · 单一规范源）

> ★ 2026-09-03 集成（前半程创作基准方法论蒸馏）。**虾镜与听风两线共用本文件**，禁止在各自 SKILL.md 复制正文；各线差异点见 §3。虾塘资产侧消费不在本文件（见 xiatang SKILL.md §5 输入契约）。

## 1. 输入

虾料 handoff 的 `production_facts`（六项 + 四级事实标注：剧本事实/强推断/导演提案/待定冲突，落 `docs/`）+ `outputs/scene-chain.md`（空间链表）。**存在时必读**；缺失时降级为原文判断，不阻塞开工。

## 2. 六项 → 分镜消费映射

| 生产事实 | 分镜消费 |
|---|---|
| 国家、地域与年代 | 画面与道具**时代正确性**（服装/建筑/交通/通讯不得越界）；FPS 基线下的年代氛围 |
| 季节与剧情时间轴 | FS 光照时段参考（天气/昼夜/光线随剧情变化） |
| 语言与声音文化 | 台词**表演基调**（口音/语速/阶层措辞影响语气演绎） |
| 世界与威胁规则 | 异象/力量画面的**边界**——禁止画出规则外的能力表现；死亡与伤害规则约束画面烈度 |
| 人物小传（含声音气质、资产依赖） | 表演细节与**身份细节锚点**复核（与虾塘 §10.3 锚点同源） |
| **状态链与视觉母题** | **连续性核对项**：换装/伤势/变异/道具转手在对应镜次必须处于正确状态档——与虾塘道具 `story_state`、角色 `dependencies` **同源对齐**（同一条状态链：虾料登记 → 虾塘执行 → 分镜核对）；母题入分镜镜头语言 |

## 3. 两线差异点（各线 SKILL.md 保留）

| 线 | 差异点 |
|---|---|
| **虾镜** | 状态链核对并入质检⑦连续性；FS 光照时段按季节时间轴取用；检查点 A 一并交确认 |
| **听风** | 状态链/母题为 Stage 1 **表 4 母题登记表**的初始来源（出现段登记 + 状态变化规则）；空间链为 **表 2 空间锚点表**上游输入 |

## 4. 空间链的通用规则

`outputs/scene-chain.md` 存在时：本集涉及的**跨场景走向、空间衔接与因果**直接引用该表（空间命名与场景资产规范名对齐），不重复从原文推断跨场景关系；**室内布局仍按原文逐段提取**（虾镜归空间真理图、听风归空间锚点表）；链上有而资产库缺失的空间 → 进补建清单/提醒。
